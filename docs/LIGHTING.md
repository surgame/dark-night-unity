## 光源与状态归属

手电仍是YYGC Definition／ObjectInstance／Behaviour道具，持有和开关唯一归ActorState，四格库存是引用依据。HeroLightPresentation只装配冻结展示值；光照方向与攻击方向独立，矿镐冻结挥击意图不冻结照明。客户端各自计算光照，不同步纹理、材质或阴影。

LightEffect是View子组件，组合LightEnvironmentEmitter与LocalLightFill。环境分支读取真实灯口、方向和已加载地形；补光只作用明确绑定SpriteRenderer，不写环境光场或作者颜色。两分支可分别禁用，总开关关闭两者。死亡、登船、移除、地图退休和会话退出按原生命周期撤除表现／资源，不留下幽灵工具。

## 预设、Definition 覆盖与原生挂载

| 资源／配置 | 归属 |
| --- | --- |
| `LightProfile` | 可复用单灯预设：光效模板引用、环境光与目标补光开关、方向性、灯形、颜色、强度、柔影、返光模式／光形／入射亮度匹配及补光参数 |
| `FlashlightToolConfig.Profile`／`Overrides` | 物体 Definition 保存可选预设 Addressables 引用和逐项覆盖；Starter 仍只控制新角色配发 |
| `Flashlight.prefab` 的 `FlashlightView.Emitter` | 物体外观和光效安装位置、Rotation、Scale；原生 Prefab 为可编辑来源 |
| `LightEffect.prefab` | 环境光与局部补光的结构模板及明确组件绑定；数值不再由模板组件拥有 |
| `SceneLightingProfile`／`RandomLevelTemplate.Lighting` | 关卡引用默认光效模板、全局渲染资源、后端、底光、共享墙体受光深度／上限／层次及设备灯预设引用 |
| `UrpEnvironmentLight.prefab`／`UrpTerrainShadow.prefab` | 原生 Light2D 及分块 ShadowCaster 模板 |

Definition 工坊的「照明道具能力」可选引用 LightProfile，所有参数均可直接编辑。未覆盖项显示并持续使用预设值；无预设时读取 Core 的 LightProfileDefaults 内置基线。实际修改某项时，一次操作同时保存该项的覆盖位与物体值，只写入当前 Definition；蓝点表示该项已覆盖，其他项继续跟随来源。点蓝点或在参数行右键选择恢复，立即回到当前预设或内置基线；换预设及清空预设均保留已覆盖项和 Starter。输入相同值和只读刷新不产生覆盖；把已有覆盖改成与来源相同的值仍保留覆盖，显式恢复才重新跟随。引用目标须是保存的项目资产，选择时加入既有 Addressables 分组，不以路径或物体名作为身份。

无预设时，光效结构取自 SceneLightingProfile.DefaultEffectTemplate，迁移绑定现有共用 LightEffect.prefab；内置基线、预设和物体覆盖使用同一冻结解析及实例生命周期，不建立第二套运行模型。工坊逐字段绘制，由 Overrides 字段的属性抽屉承接整块面板，避免 Addressables 的 Profile 字段抽屉接管。

运行链路为：Definition 配置 → `LightProfileResources` 预加载预设 → `LightProfileResolver` 合成冻结参数 → `HeroLightPresentation` 创建 YYGC 工具视图 → `FlashlightView.BindLight` → `LightEffectBinding` 从预设模板自动实例化到 Emitter → 环境光场及目标补光。手电 Prefab 不再手工内嵌 LightEffect；重复绑定复用一个实例，模板变化先退休旧实例，视图释放时撤除注册和受光引用。Runtime 配置用 AssetReference，具体 View 类型和合成由 Entry 桥接，不造成 Runtime 反向依赖 View。

Worker、Spearman、Archer继续明确绑定灯口、补光锚点和受光精灵，角色根及玩法占地保持。Rotation／Position／Scale 在物体 Prefab 的 Emitter 上制作；Scale 不作为照距的隐式倍乘，照距由 Range 控制。共享光效不保存某个角色的受光目标、开关或瞄准角。

手电原6×3像素确定性素材、100 PPU、Point、无mipmap／压缩及原字节保留。显式迁移菜单为 `Dark Nights → Tools → 迁移持久光照配置`：创建 `Profiles/FlashlightLighting.asset`，复用或补齐 `DeviceLighting.asset`、`PinewatchLighting.asset`，绑定 Definition 和含 RandomLevelTemplate 的关卡，保留原 GUID、灯口及人工资源。迁移读取保全的旧作者值；未绑定的既有手电候选、人工光效或未保存场景拒绝覆盖，失败记录和备份保留。先修复场景配置后仍可续接完整迁移。

关卡模板必须持久引用有效的 `SceneLightingProfile`，启动前校验默认光效、设备光预设和渲染资源。缺失时可显式执行 `Dark Nights → Tools → 修复关卡光照配置`：仅补缺失的设备／场景资产和关卡引用，保留已有有效配置、手电的可选预设及覆盖值；无引用变化的场景不保存。设备灯沿用原8.375格、0.45强度及暖色，场景参数使用既有配置合同默认值。未保存场景或 Prefab Stage 阻止修复，错误包含关卡路径。普通启动、调参及构建不创建或保存这些资产，新 meta 由 Unity 生成。

## 光照配置制作规范

1. Profile 为可选预设。无预设时，未覆盖项使用内置默认值；有预设时，未覆盖项持续读取该 Profile 的最新值，不把预设数值复制成长期独立配置。
2. 覆盖按参数独立产生。直接修改当前生效值即记录覆盖及作者值，保存在物体 Definition；其他参数继续跟随预设或内置默认值。蓝点可点击恢复，参数行也提供右键恢复。
3. 修改预设后，未覆盖项更新、已覆盖项保留；切换或清空预设同样保留覆盖位及作者值。取消某项覆盖后，该项立即恢复跟随当前来源。
4. 工坊的物体覆盖保存在 Definition，影响使用该 Definition 的实例。调试台修改独立运行时副本，只影响选中的本地手电；确认保存到 Definition 或共享预设后，才按该资产的引用范围生效。
5. 内置基线、预设和覆盖共用同一解析及光效生命周期。光效结构由预设模板或场景默认模板提供，物体无需额外手工挂光效；Position／Rotation／Scale 继续归物体灯口。
6. 工坊和调试台共用字段、范围、覆盖合同及冻结解析；工坊蓝点表示 Definition 覆盖，调试台蓝点表示临时覆盖。未覆盖参数显示当前来源值，刷新不制造历史或覆盖尚未提交的输入；覆盖位与数值一起撤销／重做，一次拖动保留一次历史。

## 灯形和贡献

原环境距离14格、锥角90度、强度1.35及暖色保持。Aperture Width默认0.375格，等于当前岩壁原生密度的3像素；灯口是垂直照射方向的有限截面，边界从两端展开，距离从真实中心计算，远端保留圆弧衰减。贴墙时按挂点至灯口真实坡形几何限制有效位置，取样点到中心的路径也验证遮挡。

PrivateField的环境底光、定向直射、近身散光和有限反射分开计算；空气柔影采用有限光源采样，墙内补光独立限深／限强。未知格和加载区域外保持遮挡；有限反射是有约束的艺术照明，不能声明真实全局光照。

原近身补光2.2格／0.55转入指定对象补光，环境近身散光默认0，避免重复计入光场。每精灵最多合成4个局部补光贡献，保留其他材质属性；关闭或退休清理贡献，MaterialPropertyBlock首次主线程合成时创建。

## 墙段连续漫反射

返光属于单灯：`LightProfile` 和 `LightOverrides` 拥有下表参数及单点 `Bounce`，Entry 合成到冻结 `LightEmissionRules.Bounce`。场景设置仅保存后端、底光及共享 `WallDepth / WallStrength / Relief`，不提供单灯返光的全局覆盖。PrivateField 按灯索引上传并读取模式与参数，同帧可混合不同返光模式、WallBand／SoftBlob、增益和范围。

每灯的 `BounceMode` 为互斥的 `LegacyPoint=0`、`Off=1`、`Continuous=2`。未配置的单灯使用内置 LegacyPoint 基线，`Bounce` 默认0.12且仅用于单点模式。Off 不查询该灯的候选或返光遮挡；所有灯均关闭连续返光时，不捕获新边界、不上传候选、不执行 Profile。Continuous 的零增益／零深度也走该灯的直接光路径。URP 2D 保留原行为，调试面板明确提示能力差异。

| 连续模式参数 | 首版默认值 | 合同 |
| --- | --- | --- |
| DiffuseGain | 1.0 | 乘同灯真实入射；Intensity=0 不产生新增返光 |
| DiffuseNearDistance / DiffuseFarDistance | 1.5 / 6.0 格 | 以入射质量加权的真实灯口距离计算，远端必须大于近端 |
| DiffuseMaxReach | 3.2 格 | 法向深度乘平滑距离门控 |
| DiffuseLateralSpread | 0.65 | 沿墙扩展随受光长度、离墙距离变化 |
| DiffuseVisibilityProbes | 2，最多4 | 仅近似可见性，不参与亮度 profile 或无遮挡光形 |
| DiffuseOcclusionMode | ProjectedShadow | 原始切边／墙体遮罩／切边向外羽化；只影响PrivateField的连续返光 |
| DiffuseFeatherWidth | 1.5 格，范围0—4 | 只在向外羽化模式生效；0恢复原切边，不改变径向半径 |
| DiffuseShape | WallBand | WallBand 沿墙扩散；SoftBlob 使用受光线段的径向软核积分，形成圆滑光团 |
| DiffuseMatchIncident | false | 开启后 profile 使用同灯直接入射亮度，斜照角度只影响候选质量／加权测距；关闭保持按入射角压暗 |
| DiffuseCornerRadius | 0.8 格 | 相邻墙面受光足迹到共同端点的连接距离及沿墙模式圆滑端部半径；0关闭连接 |

Entry 注入纯 `LightBoundaryBuilder`。冻结格经 `TerrainShapeGeometry` 提取整格、12 种坡面／天花板的真实外露边，仅保留朝向已知空气的边；共线同向连续边在建八格空间索引前合并，门洞／转角分段。源实例、源退休标志、缓存生命周期／代次、加载区域和 GeometryRevision 共同约束后台安装；移动和转灯不重新捕获地图。整图工作台仍仅冻结相机附近至多128×128格，正常局部流沿用已加载区域。

同源地图更新时暂留旧边界并后台重算；每帧 Profile 使用当前 GPU 格再次验证墙内／空气侧和入射遮挡，挖掉或未知的旧边立即失去照度，未变化的边保持可用。换源立即撤除缓存；世界 epoch 变化和后端切换退休旧光场，迟到任务不安装。无需改变地图同步协议或恢复业务状态。

每灯最多64个空间候选，先按真实圆形照距和有限灯口锥束裁剪长墙。GPU 选两个受光组，每组最多四条相邻物理边；各边保持原法线和坡形，不压成平均直线。连接必须有共同物理端点、同侧已知空气，且两条受光足迹均接近该端点；连接半径不允许跨门洞或平行薄墙。每边先以0.125格为目标间距（最多128区间）确定受光首尾，再在裁出的范围重新计算33节点／32线性区间的真实入射，投影阴影保留零照度。容量仍有界，超出组内四边的复杂碎坡面仍需人工观察。空间候选溢出按长度／距离的保守质量排序保留，丢弃数独立记录。

WallBand 将三角核积分的照度和覆盖分开，按实际覆盖归一化局部目标，避免端部重复压暗；相邻端部以有限径向核圆滑连接。SoftBlob 对连续线性密度用每区间两点高斯积分，核仅按到受光线段的距离衰减，不限制固定出射方向，也不把节点或遮挡探针画成独立点光。其半径由 DiffuseMaxReach 与原距离门控控制，DiffuseLateralSpread 只影响 WallBand。SoftBlob 即使关闭端部连接仍保留每条受光边的圆滑光形。

默认原始切边的首探针取最近表面，第二探针向受光段内部平滑移动，额外探针覆盖两侧，结果按到目标的距离加权；探针不参与密度或无遮挡光形。这样避免两端探针均被坡角挡住却漏掉中间可见区域。返光的空气光路使用有界格 DDA 与坡形解析求交；目标是岩壁时，仅容许最后一段进入 WallDepth 限定的薄表层，进入岩体后再遇空气立即拒绝。该默认规则继续拒绝未知格、中途实墙和墙后空气，最终墙内 RGB 沿用 WallStrength 同比限幅；另外两种规则的差异见下文。

未被局部支持覆盖或局部密度为零时，新增照度为零。按同灯直射与近身贡献 `D` 计算平滑正余量；最多八边的贡献用 `H*(1-product(1-a_i/H))` 融合，`H` 为本点最大正余量，`a_i` 为含覆盖／遮挡／距离衰减的各边增量。两边时退化为原两段公式，交换顺序不改变数学结果且总增量不超过H。最后一次乘同灯 Linear 色；返光不写方向 moment，Relief 只按直接光的亮度占比作用。低分辨率重建仅合成同侧且短路径无遮挡的样本，薄坡角不依赖中点采样。

对比入口为手电光照调试台的单灯参数：选当前运行手电或 Definition／预设，在手电参数中选择 Continuous 并切换漫反射形状 WallBand／SoftBlob；场景配置选择 PinewatchLighting／PrivateField。勾选「匹配主光入射亮度」并以 DiffuseGain=1 为匹配起点。匹配指受光处和直射交界的目标亮度，外围继续衰减，材质显示不保证每像素相等。增益只调返光，旧 Bounce 仅调 LegacyPoint；连接半径0可对比关闭拐角连接。所有返光字段进入单灯临时草稿、逐项覆盖和 Undo；确认保存到 Definition 或共享预设后按相应引用范围生效。

工坊的单灯覆盖面板和调试台共用模式可见性规则：LegacyPoint 仅显示单点返光强度，Off 隐藏所有返光调节项，Continuous 显示连续漫反射字段并隐藏单点强度。SoftBlob 隐藏仅 WallBand 读取的沿墙扩展；连接半径仍显示，因为它参与两种光形的相邻受光墙边分组，WallBand 另用它柔化相连端部。DiffuseMaxReach 按光形标为「漫反射最大法向深度」或「漫反射光团最大半径」；近距离／关闭距离注明「手电距墙」，控制入射距离门控而非光团内部衰减。显示依据预设、物体覆盖及临时草稿合成后的当前值；隐藏不清除数值或覆盖位，切回、恢复来源及 Undo／Redo 后按当前模式重新显示。

私有光场按输入失效准备受光墙段：源实例／地形版本、已安装边界、已知区域、灯数量、位置／朝向、锥角／灯口／柔影／光束边缘、强度、近远距离／范围／入射匹配／连接半径变化均重算；仅改变颜色、正增益、光形、沿墙扩展、探针数、返光遮挡规则或切边外扩宽度时更新合成参数，不重算同一组入射节点。零强度、非定向和关闭／零增益／零范围灯不查询候选；激活状态切换必须撤除旧准备结果。灯参数向量仅在精确数值变化时重新上传，候选上传限于当前灯数，未激活灯的旧槽位不进入合成。

软阴影的五个固定采样口共享灯口起段可见性，分别保留原直射步进和入射精确 DDA 算法；灯输入、源／纹理、地形版本及已知区域不变时复用，阴影尾段仍使用原路径。额外 GPU 缓冲为16灯×10浮点值共640字节。SoftBlob 只积分圆形支持域可能非零的区间；WallBand 在接缝权重为零时省去圆滑核；同一返光探针位置复用可见性但保留原权重；节点最大值加浮点余量仅用于拒绝已被直射覆盖的目标，不改亮度、探针数量、坡形或墙后拒绝规则。冻结原 Shader 与可计量参考渲染器分别保留在 Tests，性能标记注入仅用于 Editor／Development，不进入正式 Player。

每个私有后端拥有独立 Shader 实例；固定缓冲与输出纹理在创建时绑定，地形纹理身份变化时重新绑定，返光核的绑定及查询开关按变化更新。绑定复用不能跨后端实例，换源／模式及资源退休仍遵循原失效合同。编辑态预览在等待后台任务退出后用 DestroyImmediate 释放纹理，Play 内使用 Destroy；不能留下预览资源或把迟到释放作用到新世界。

冻结像素比较区分 Shader 计算误差与 RGBAHalf 输出量化：既有低亮度夹具沿用绝对 3e-5；多灯运行后端允许绝对 3e-5 或该通道一档半精度 ULP，取较大者，并保留每次最大差异。作者完整画面仍独立逐像素对比；浮点容差不代替 PNG 或真实前台画面检查。

| --- | --- |
| 柔影开关／Softness | 从单条阴影尾段变为五条；正柔度之间不改变射线数量，但改变采样口及遮挡结果 |
| DiffuseVisibilityProbes | 每有效墙边每点2–4条精确可见性查询，重合点只查询一次；坡角和墙表层结果不同，不能直接删减 |
| DiffuseOcclusionMode／DiffuseFeatherWidth | 墙体遮罩跳过返光路径DDA；外扩复用原2—4探针预算，每探针至多一次DDA，另有切边距离与smoothstep运算。射线路径和提前拒绝可能改变耗时，未测量GPU绝对收益 |
| DiffuseMaxReach／DiffuseFarDistance | 扩大参与合成的像素和／或候选搜索范围、墙段采样跨度；决定视觉扩散范围及距离门控 |
| DiffuseShape | SoftBlob 使用连续径向积分；WallBand 使用沿墙积分并可加接缝圆滑核，实际开销取决于姿态与覆盖 |
| DiffuseCornerRadius | 两种模式都参与分组，WallBand 另有接缝核；复杂墙边需要保留 |
| DiffuseLateralSpread | 只在 WallBand 生效，SoftBlob 输出与其数值无关，面板已隐藏该项 |
| DiffuseMatchIncident／正 DiffuseGain | 改入射／目标亮度及有效补光余量；不会增加配置的探针数，但可能扩大实际需要查询的区域 |
| Bounce | 只在 LegacyPoint 生效；Continuous／Off 的面板隐藏并跳过其路径 |

上述条件失效不等于参数没有全局价值。保留作者数值与模式切换能力，不以缩小范围、减少探针或更改光形作为无损优化；遮挡规则切换本身会改变画面语义。计量必须保存当前配置、源码身份与原始配对回执；单Editor离屏结果只说明照明调用本身，不能推广为前台帧率或 Player 预算。

### 返光遮挡规则⑨

在 `Dark Nights → Debug → 手电光照调试 → 返光 → 遮挡与切边` 选择「返光遮挡与羽化规则」。场景后端须为PrivateField，单灯返光模式须为Continuous。参数随单灯冻结，多个灯可选择不同规则。原始入射节点、正余量、圆形核及同灯墙段融合继续产生完整返光；第三项在其后统一滤波空气返光，直射与墙表层保持原接收合同。标题⑨保留既有引用，完整返光羽化新增两次滤波调度，不再仅是⑨内部近似。

| 选项 | ⑨内部处理 | 墙体与空气表现 |
| --- | --- | --- |
| 原始切边 | ProjectedShadow=0，沿用原探针路径可见性V | 默认不变，保留原墙表层返光；遮挡投影可能切掉圆形光团 |
| 墙体遮罩 | WallMask=1，已知空气M=1、实际岩体／未知M=0，不查询返光源到目标路径 | 与v1.2.0离线意图相同，只裁返光，原直射单独计算；墙体材质内的间接光也移除，隔墙空气可能收到径向返光 |
| 完整返光羽化 | 保留序列化身份OutwardFeather=2；原路径产生返光B，再对空气域B横纵滤波 | 圆周及空气中的所有切边统一平滑；亮侧可略暗、暗侧补亮，墙表层保持；宽度0严格走原始路径 |

羽化宽度保留作者默认1.5格及0—4格范围，现定义为高斯阶跃10%—90%的主要过渡跨度，sigma=width/2.563103；不是前版单侧到切线的距离，也不把1.5直接当sigma。按光场矩形和384×216尺寸换算采样距离，镜头缩放不改变格宽。每轴九个有界高斯位置覆盖约±3sigma，至少按一光场像素间隔采样，亚像素位置用几何约束双线性重建；因此属于有限采样近似，不声称任意尺度严格等价连续高斯。圆形核半径参数不改，最终光团外围可向原支持域之外渐变；亮侧也可略减，不以max(原值,滤波值)保留原跳变。

采样只收集已知空气像素。每个双线性源像素分别检查至目标的空气路径，不能仅用“两端都是空气”放行薄墙；同格已知空气为凸域，可直接接受。中途遇实墙或未知区域拒绝并重归一化；用几何作为许可，不以照度差保留旧明暗切线。横纵两跳可以沿空气转角扩散，属于局部画面近似，不承诺真实多次反射或物理能量守恒。墙体、深岩与未知域不接收空气滤波结果，原墙表层返光不与空气混滤；滤波后不再乘原源到目标硬可见性。

按单灯模式和精确宽度分组，同宽灯先累加线性RGB，异宽灯各占一层，不平均宽度；其他模式及宽度0留在原合成。`IlluminateDiffuseFeather`仅把指定空气返光写入分层原始图，其余光保留为合成基底；`FeatherHorizontal`一次Dispatch处理全部层，`FeatherCompose`一次Dispatch纵向滤波并合成，更新总照度direction.w，原直射照度direction.z及方向矩不变。原始切边／墙体遮罩／无有效羽化灯使用原Kernel，不触发这两次调度。

两张线性RGBAHalf纹理数组按需分配、容量按1／2／4／8／16层扩容并复用；当前容量内宽度及规则变化不重建纹理。一层约1.27MiB、最大十六层约20.25MiB，扩容退休期间另有旧纹理暂存；替换及退出通过GPU fence或单像素回读屏障后释放。关闭羽化跳过计算，已分配资源留作复用，随相机后端退休释放。无新增URP渲染Feature或整屏材质后处理，新增的是现有私有光场内两次Compute滤波；计算量随层数、灯数及空气路径长度增长，不以固定Dispatch次数证明GPU成本。总GPU采样器包含滤波，新增横纵独立采样标记；原三槽DDA计数未覆盖滤波查询。实际GPU／四人表现仍待获批测量。

工坊和调试台共用字段，第三项现显示“完整返光羽化”。仅该模式显示宽度，墙体遮罩隐藏不使用的探针数，隐藏不清除覆盖或作者值。字段名、枚举值2、覆盖位及记录身份不变，已有作者1.5格保留但效果语义按上文更新；内置默认仍为原始切边。临时调整、蓝点恢复、撤销／重做、命名记录和显式保存继续沿用同一合同，不自动保存或迁移作者资产。

2026-10-13 的拐角／柔光团修复增加了入射准备与选中墙边预算。2026-10-12 的两墙段性能记录只代表旧候选，不能用于本候选的前台或GPU预算结论。

显式迁移入口 `Dark Nights → Tools → 迁移灰松谷返光到单灯配置` 只读取 PinewatchLighting 文件中遗留的旧返光字段，转到现有手电 Definition 的未覆盖返光项及 DeviceLighting 预设，再保存场景移除旧字段。保留原手电覆盖位／作者值、共享墙体规则和 GUID，备份原三个资产；目标有未保存修改时拒绝迁移。原非定向设备在 Continuous 下仍无候选墙段，避免误启单点返光。完成后重入为空操作，导入和启动不自动迁移。回退或调参在对应单灯配置中显式选择 LegacyPoint 或 Off。

有限验收入口为 `WallDiffuseAcceptance.Start(新的批次标识)`，需空闲单一 Editor、内存门控和独立产物目录。A0 使用保留的仓库旧 Shader；A1 为开发专用四区间常量 profile，B 为32区间连续 profile，Off 不运行新准备。GPU CustomSampler 分别记录 Profile、Select、积分合成与照明总成本；查询计数单独采样，避免原子计数污染性能值。CPU 记录冻结、worker、候选准备、上传和提交；分配使用带已知分配正向自检的 Unity GC.Alloc 记录器，事件为零才记0字节，有事件时保留事件数而不伪造字节。Mono 的 GetAllocatedBytesForCurrentThread 在本环境返回无效零值，不作通过证据。冷资源帧、地形／区域失效的重建分配与无失效稳态分开。实际结果、失败及尚未覆盖的前台／动态矩阵见 DEVELOPMENT 和本批证据，不从本合同推导验收通过。

| 后端 | 能力与限制 |

| PrivateField | 每游戏相机共享384×216GPU光场及入射方向缓存，最多16个环境光源；局部遮挡、墙内羽化和有限反射；接收材质须显式接入表面函数 |

打开 `Dark Nights → Debug → 手电光照调试`。UITK 调参台采用左侧窄纵向导航、中央分类控件、右侧固定预览和底部统一保存。页签为光束、返光、补光、场景、灯口、来源、历史；切页保留草稿。默认选择已有手电 Definition 与 `PinewatchLighting`，来源页可选择运行手电或独立预览。预设只是参数来源，Definition／共享预设的写入目标另行选择；切换预设保留覆盖、场景与预览草稿。切换 Definition／实例只询问当前单灯与灯口，切换场景只询问当前场景，其他范围及其撤销记录保留。

右侧独立预览复用五张 `.minemap` 作者图、正式 `TerrainPreview`、材质、光效和 `EnvironmentLighting`；输出为1024×640，正式地形工作台的默认输出不改。人物与手电只复制原生 Prefab 的视觉树、Sprite、idle 动画及明确挂点，不装配对象业务或碰撞器。可选择矿室起点、输入地图格 X/Y（Y向下）或左键定位人物，勾选手电360°循环转向并设置角速度，取消后精确设置方向。画面内中键拖拽平移镜头，滚轮以指针位置为锚点缩放，半高限制3–24格；镜头偏移独立于人物位置，输入偏移0/0可回到人物。留白不启动画布手势，拖拽捕获丢失／面板退出必定结束；整次拖动和连续滚轮各归一条临时撤销记录。关闭预览停绘，退出释放临时资源；绘制与退休恢复 Shader 全局绑定，URP 临时灯在绘制后停用。右侧不启动会话、网络、业务 RNG、Play 或玩家存档；不替代真实运动／返程、联机或性能验收。

相机位置、半高和局部范围在 `ShowBlueprint` 前设定，前景与矿层只装载视野外带32格光束／规则邻域的区块，背景轮廓也只栅格化窗口及声明邻域。镜头超出当前邻域且停止移动150ms后替换局部宿主，旧宿主取消退休；不先准备整图再裁取相机画面。保留原作者逻辑蓝图及正式材质的固定贴图地址空间，窗口外不构建显示页。背景基础轮廓保留全局噪声坐标；本调参台的背景圆簇使用作者参数的 LocalV2 副本与世界坐标局部求解，原背景资产和正式世界的 LegacyV1 不改，不声明两者像素等价。当前只支持既有轮廓背景与空栈／单圆簇，不支持的配置明确报错，不回退整图。跨区窗口接缝、快速拖动／退休以及加载耗时仍待人工验收。

局部宿主的前景使用冻结 `IMapChunkSource` 与只读 Layer，只显示当前内部视野，不发布草稿编辑用的整批 `MapInputBatch.Baseline`。冻结局部页面的任务期限为10秒，避免复杂页面在 Editor 默认100ms期限内反复 `Expired` 重建；世界／可见性／版本校验与退休取消保留。整图地形工作台和正式世界维持原输入与调度，局部换区按宿主退休重建，不补一套地图编辑状态。

调参台的深色界面显式覆盖原生标签、输入、下拉、复选框与禁用文字，避免继承浅色 Editor 的黑字；中右两栏主标签14px粗体、标题16–18px，输入文字14px，输入行至少28px，窄窗口允许换行。此样式只属于本调参台，不更改 Editor 全局主题或其他工坊。

场景页只编辑后端、底光及共享墙体规则；返光模式、光形、匹配与连接半径在返光页。场景临时副本仍作用于本机引用该配置的活动会话。单灯柔影、柔度、光束边缘和灯口宽度使用同一冻结解析，两后端读取相同参数。Player参数 `--dn-lighting-urp`／`--dn-lighting-private` 同时存在时最后一个生效，覆盖该次启动的后端选择；未指定时跟随场景配置。切换先停旧后端，再退休纹理、灯和遮挡资源，不自动改变用户选择。

非游戏相机渲染时停用本任务灯实例，避免污染其他相机。URP阴影使用每16×16格区块一个模板，整格按连续行合并，坡形沿权威边界，未知格保守遮挡，几何变化只重建哈希变化区块。阴影用Collider为provider来源，Ignore Raycast、Trigger、排除碰撞层及关闭回调，不参与运动或伤害。

## 调试窗口持久化、撤销与重做

调试台所有参数首先写入独立运行时／预览副本，不标脏原 Definition、LightProfile、SceneLightingProfile 或 Prefab，也不因选择预设提前注册 Addressables。单灯参数按「预设 → Definition 覆盖 → 实例临时覆盖」合成，光效只消费冻结结果；取消临时覆盖恢复当前持久化基线。工坊继续直接编辑 Definition 资产，两入口复用 `LightOverrides`、字段范围与 `LightProfileResolver`，不共享可写配置对象。持有、开关、方向仍来自权威投影，调参不改变协议、存档或其他客户端。

调参台只有「保存全部（Ctrl+S）」一个保存入口，先集中展示单灯写入目标、预设引用、场景、灯口和调试记录的路径、修改项及影响范围。单灯只选 Definition／共享预设之一；预设引用始终归 Definition。Definition／Profile 只合并本轮覆盖字段，场景只合并相对初始副本改变的白名单 Settings 字段，保留其他当前作者值。保存前拒绝目标已有未保存编辑、同字段外部改动、确认期间文件变化及对应脏 Prefab Stage；资产写回前保全本批原文件与清单至 `artifacts/lighting-tuner-uitk-20261013/saves/<记录ID>/`。失败恢复已写作者目标并保留草稿，恢复不完整则明确报错及保留证据；全部作者目标和本地记录成功后才清空本轮临时历史、建立新起点。取消不写资产，也不清历史。

右侧「本次记录名称」与预览参数一起进入临时历史。保存全部同时新增 `Game/UserSettings/DarkNights/LightingDebug/records/<ID>.json`，包含当时完整生效单灯值、来源 GUID、场景值、灯口姿态、地图／矿室／位置、自动转向／角速度／方向、镜头半高与偏移；旧记录缺少偏移时按0/0载入，旧记录不覆盖或自动裁剪，最近预览设置独立保存在同目录 `last-preview.json`。没有作者改动时也可保存当前调试快照。历史页载入经过版本、参数和来源校验的记录，仅恢复临时草稿；完整单灯值作为临时覆盖锁定当时效果，继续写回仍需保存全部确认。损坏／缺失来源的记录保留并报错，不自动创建作者资产。本机历史不提交 Git，不属于游戏存档格式。

资产保存与玩法存档独立。普通关闭、脚本重载、Play切换、实例回收或换世界不自动保存；关闭有未保存草稿时沿用 EditorWindow 保存／丢弃／返回流程，选择保存仍先显示完整清单。Play切换撤除单灯、场景与灯口临时效果，右侧草稿在窗口存活期间保留；脚本重载和窗口实际销毁释放未保存副本，已保存历史可重放。

调试台没有主动另选预设时，工坊更新 Definition 的预设引用后，未临时覆盖项继续跟随新的持久化基线，已临时覆盖项保留。保存 Definition 只在调试台明确另选预设时写回引用，避免保存一个参数时恢复过期引用。

工坊继续使用原资产的 Unity 原生 Undo，在属性树结束当帧处理后合并拖动期间追加的记录；仍有鼠标捕获的 Ignore 不提前结束。调试台使用独立且有界的临时历史，保留最近128次修改；窗口按钮及 Ctrl+Z／Ctrl+Y／Ctrl+Shift+Z 只恢复副本，撤销到起点后停止，不进入工程资产历史。Unity 主菜单的原生历史继续归工坊及其他资产编辑。两者复用同一指针手势边界：一次按下到松手登记一条，重做恢复松手终值；连续两次拖动分开，取消或真实失去捕获时结束。数值输入框在 Enter 或失焦时提交，刷新无通知且不覆盖未提交文字；相同值不制造历史或丢弃重做分支。

灯口面板先编辑临时 Position／Rotation／Scale，作用于选中实例的明确 Emitter；没有运行实例时，在对应 Prefab Stage 旁用独立临时锚点预览，不修改 Stage 原对象。实例释放时自行恢复未保存姿态，避免池化后串到下一只手电。确认保存通过原生 Prefab API 仅写明确灯口，遇到该 Stage 未保存修改拒绝覆盖。临时光效和范围辅助线不启动业务、网络、RNG 或存档，使用 HideAndDontSave，退出面板即销毁；范围辅助线不替代正式墙体遮挡及双后端画面验收。

## 材质和异步资源

LightingSurface.hlsl是共用表面适配入口：私有模式读取光场，URP模式将真实颜色、Alpha和Mask交给锁定URP的CombinedShapeLightShared，避免把原生加法照明再乘入底色。CampSprite、CaveStrata、CaveBackgroundLayer及CavePixelRock接入Universal2D／NormalsRendering；CampSprite可选Normal Map／Light Mask，默认保留平面受光。

标准第三方Sprite Lit可接收URP原生灯，但不自动接收私有目标补光。屏幕HUD保持正常显示；世界交互提示可读性单独检查。模板的Sorting Layers需随新增受光排序层显式核对。

资源预加载沿ObjectSessionResources.Prepare／StartupResourceBatch，在事务外await，主线程同步装配／上传／GPU提交；不逐帧回读GPU。后台几何读取独占冻结局部格副本，每缓存只有一个运行任务；完成核验源、区域和修订，过期结果丢弃。退休先取消、等待任务退出再释放纹理，await前冻结旧矿层／源／控制器，避免迟到清理新世界。
