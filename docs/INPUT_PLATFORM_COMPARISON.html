      实施时保持的边界

      • GameInputActions 是每位本地玩家在游戏代码中唯一的 Unity InputAction 接入点；不启用旧 GameVS InputBus 的第二套资产。
      • 业务只读取当前帧的语义值：主角、营地和 Entry 不持有 InputAction；输入层不再对它们公开原始动作、Asset、CampAction 或 CanRead。
      • 改键只使用 Gameplay.inputactions 自带的动作／绑定身份与少量可改键白名单；不维护平行的动作目录或第二份运行输入状态。
      • 沿用 YYGC 的动作许可、Interaction Sessions、改键与保存。短按缓冲、30 Hz 变化发送、10 Hz 保活以及服务端 ActorState 权威归属保持原样。
