# 正式游戏随机灰松谷

2026-09-17，分支 `codex/feature-dualgrid-game-start`。基于 main `a1cd509` 的 DualGrid 生成器接入正式开局。原 `Res/Scenes/Pinewatch/Pinewatch.unity` 保留；新增 `Res/Scenes/RandomPinewatch/Pinewatch.unity` 作为灰松谷的随机场景模板，保留可编辑的原生营地对象和场景引用。

## 测试入口

专门观察随机地形、无需营地平地和守夜波次时，使用[独立 Debug Bootstrap](TERRAIN_DEBUG_BOOTSTRAP.md)：直接出生入口洞室，WASD 穿墙飞行、近距离镜头与实时参数重建。下列正式入口仍保留营地规则与 72 列保护区。

- Mono：运行 `artifacts/random-map/player-mono/DarkNights.exe`，主菜单点击“选择地图：灰松谷 · 生成新地图”，等待种子状态更新，再点击“开始守夜”。再次选择地图产生新种子；已选地图在开局时复用。
- Editor：从 Bootstrap 进入默认正式菜单，或使用既有关卡试玩入口运行 `RandomPinewatch/Pinewatch.unity`。原 Pinewatch 仍可单独试玩；Player 的 `--dn-camp-mode` 保留原固定场景回归入口。
- 随机地图就绪后，小地图从网络只读格子绘制完整 320 列地表轮廓，竖线标出前 72 列营地保护区；镜头框、角色和建筑使用同一地图比例。
- Editor 可在 `Dark Nights/Debug/主角移动 8×` 勾选本机试玩加速，停止 Play 后切换；Development Player 可传 `--dn-debug-hero-speed 8`（范围 1–16）。倍率只由房主用于权威主角横向移动，不改变敌人、时间倍率或存档，正式默认仍为 1×。
- 联机：第二个同版本 Player 从菜单加入房主；也可执行 `powershell -File tools/test-game-random-map.ps1 -PlayerPath <DarkNights.exe绝对路径>`，自动启动独立 Host、客户端及晚加入进程。

## 生命周期和边界

每个关卡对应自己的随机场景模板，当前只实现已有灰松谷一个关卡。模板承载原生对象、镜头、环境和明确的 `RandomLevelTemplate.Definition` 引用，不用生成脚本覆盖原 Pinewatch 或人工素材。场景初始营地放置仍来自该模板的 `ScenePlacement`。

选择地图时，`Task.Run` 仅执行 Core 纯生成算法，主线程负责缓存结果和更新菜单。当前生成 320×192 格（61,440 格），复用 rolling 地表与有机洞穴算法；前 72 列预留原营地平地和四格保护地基。随机区域延伸至 5,120 玩法像素；原营地对象、经济数值、波次和出生位置不改。随机模板移除固定单向平台，旧固定场景保留。

正式会话启动时，冻结候选交给 `ObjectSession` 内的 `SessionTerrain`，激活后唯一地图写入者为现有 `TerrainMapAuthority`。主角继续使用 YYGC `ActorState`，位移、跳跃和落地查询权威格子并按两像素子步检测；表现副本和 Unity Collider 不结算运动。随机地形允许负高度，镜头跟随主角纵向位置。旧营地 AI 和生产仍沿用原营地区域规则，本次不增加采矿、工具耐久、背包奖励或跨区域 NPC 寻路。

地图通过 AnyRules 的可靠 AMP1 区块流发送真实最终格子和保护位，客户端不按种子自行重放。初始阶段订阅整个有界地图（负坐标对齐后 70 块），后续静态版本门闩避免扫描和重复发送。显示使用网络只读副本构造 DualGrid 可见页；地图 epoch、完整数据和初始可见页都就绪，实体 Ready 才能通过。Ready 携带地图世界身份与代次，服务端核对当前权威地图，拒绝旧地图上的就绪请求。

正式业务协议升级为 **9**，存档升级为 **v4**，保存目录为 `v4`。存档保存最终材料及保护位；恢复先验证并构造候选，再与实体一起提交，随后更换地图代次并重新同步。暂停时网络继续，晚加入与重连取得完整地图；“重新开始”恢复本次已选地图，返回主菜单重新选图才生成另一张。旧 v3 文件不迁移、不删除。

## 框架适配

仅对游戏隔离 `.deps/AnyRules` 应用可重现补丁，未修改 `D:/Developer/YYGC` 工作区。原 `MaximumChunks=64` 和每轴六块订阅限制不能容纳正式地图，新增 `PlayableMapChunkBudget.patch` 将块预算提高到 128、每轴上限十块，并在分配前检查与实际地图相交后的 halo 块数。保留单包 256 KiB、缓存 2 MiB 等其他边界。准备脚本和 442 文件哈希锁同步，完整解包加三份补丁可复现。逐文件说明见 [YYGC 账本](YYGC_CHANGES.md)。
