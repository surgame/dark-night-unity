# 地面基础玩法范围

本页决定正式会话当前开放／暂停的玩法。运行协议、存档版本和完成情况统一见[执行状态](DEVELOPMENT.md)；原2026-10-07收敛和装备恢复的验证见[项目历史](archive/PROJECT_HISTORY.md)及[原机器证据](evidence/equipment-restore-20261007.json)。后续照明切片沿用此范围。

## 当前运行范围

| 内容 | 正式会话行为 |
| --- | --- |
| 地面开局 | Bootstrap后台生成当前星球地图，飞船安全落地；首次Ready在左坡道旁地面创建专属主角，不从太空或天空开始 |
| 主角与镜头 | 权威碰撞、坡形、移动、跳跃、冲刺、镜头和改键；使用既有输入租约 |
| 购买 | 船内商店E交互、共享信用点、支付验证、四格库存和已购标记；价格保持，出售原矿入口暂停 |
| 手持使用 | 矿镐目标／耐久／距离提示与左键持续挥镐、手枪射击、已有炸药蓄力投掷及有界投射物推进；船内禁止手持攻击 |
| 喷气背包 | 购买后装备并充满；长按跳跃在普通跳跃后衔接喷气，落地回复；独立能力，不占四格手持库存 |
| 手电与照明 | 新角色通过库存事务配发手电，占一格；F开关，切工具持续照明，移除关闭并释放，恢复不重新配发已移除手电；光效和后端仅本地表现 |
| 采集收益 | 前景／矿层按工具能力和权威事务采集，铁／金进入个人货袋并保存；不增加警戒，不开启NPC、出售、卸货或返航结算 |
| 飞船 | 地面坡道登船／下船、E驾驶席和唯一驾驶位；F1飞船页提供驾驶／离座、起飞、降落、取消收舱；起飞检查船内人员，降落检查实际支撑与空间 |
| 联机与恢复 | 可信连接、SharedCamp／HostOnly、Ready、双层局部副本、晚加入／重连、epoch、冻结保存及原子恢复；当前房间策略不由存档覆盖 |

炸药保留已有操作链，不新增商店商品、价格或数量。手电商品键为空，通过新角色配发或现有房主调试添加；没有新增电池、掉落拾取或帽子产品。

## 暂停的玩法

正式会话不推进太空目的地／航程过场、探索计时、警戒刷怪、NPC自动战斗、设备部署／派工、自动物流、卸货、舱段升级、损失补充、撤收和返航结算。旧营地建造、训练、招募、修缮、夜袭及对应快捷键也停止执行。

原F1远征16项操作只保留4项飞船操作；目的地、销售、旧营地修改和已退休离散UseHeroItem请求由服务端拒绝，装备使用走既有主角输入流。隐藏按钮、把舱段归零、关闭旧流程配置或使用 `--dn-camp-mode` 均不构成恢复授权。

暂退实现、作者资产、原GUID、离线工作台和必要规则来源保留。调试页可以展示暂停玩法的真实定义，但不自动开放其创建或业务执行。正式预加载聚焦主角与飞船，商品定义和地图资源沿原路径加载；Addressables中的人工内容不因收窄入口被删除。

## 状态和存档边界

ObjectSession只组合已有YYGC对象／会话能力；主角、装备和船体归所属Behaviour／State，前景／矿层归会话托管原生地图。不存在第二套基础会话状态系统。

合法主角姿态、装备动作／燃料／炸药、手持投射物、个人货袋、信用点、飞船及最终两层地图允许保存。NPC、工位、旧箭矢、自动任务、风险／探索计时、船仓货物、舱段、损失和结算遵循基础会话的零值／空集合约束。星球本地飞行仍属于Landed环境，可保存飞行阶段及高度；文件和身份校验见[存档合同](SAVE_FORMAT.md)。

## 重新加入玩法的条件

每个恢复切片须明确用户选择的范围、唯一状态所有者、权限／自动调度、输入与可见入口、保存关系、资源装配以及验收。旧代码、历史完成记录、模板和共享营地目标不自动扩大当前范围。对应验收先按当前源／配置安排，不借用旧Player通过数。
