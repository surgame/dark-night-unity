# 飞船远征与星图导航策划草案

版本：v0.1。日期：2026-10-19。用途：审阅船舱准备、采矿交货、撤离出售和下一次出发的完整体验。

开发切片、现有系统复用、YYGC状态归属及联机／存档接入要求见[开发执行方案](SHIP_EXPEDITION_IMPLEMENTATION.md)。

星球内的探索、采集和合作是主要玩法。固定飞船承担队伍集合、货物保全、补给与目的地选择；航行提供短暂的准备和交流时间。玩家通过模拟星图理解自己所在的位置，所有人都能看到当前目标、预计抵达时间及目的地危险信息。

本方案按当前讨论方向组织：**下矿采集 → 回船存矿 → 继续探索或共同撤离 → 脱离矿区后自动出售 → 航途中补给与选下一站 → 自动降落。** 除下节列明的用户要求外，具体操作、数值及异常规则均作为本轮建议审阅；当前正式玩法范围仍以[地面基础玩法](GROUND_GAMEPLAY_BASELINE.md)为准。

## 用户要求与本轮建议

| 类别 | 内容 |
| --- | --- |
| 用户已明确 | 星球内玩法优先；飞船样式重做，不做DIY飞船 |
| 本轮要求纳入 | 飞行时镜头拉近船舱；导航显示当前位置；模拟宇宙小地图与下方星球列表联动；航行耗时随当前位置和目的地距离变化 |
| 本轮新增要求 | 所有玩家都能看到抵达目标所需时间；小地图与列表都显示对应目的地的危险程度，当前可用mock数据 |
| 已获认可的流程方向 | 矿物带回飞船，起飞撤离后换钱，再准备下一次落地；具体出售时点和货物边界在本案细化 |
| 本轮建议 | 单层固定船舱、自动起降、安全区域一次性出售、全员查看但受权限限制地改道、短航行、危险信息分级展示 |

界面可用多颗示意星球表达距离和路线。当前CL阶段仍以一个正式星球主题为内容范围；mock节点不代表新增星球、危险玩法或地图已经开放制作。

## 玩家的一次远征

| 阶段 | 玩家主要行为 | 看见的结果 |
| --- | --- | --- |
| 船内准备 | 查看星图、讨论矿区、购买装备、确认目的地 | 当前船位、各目的地距离与预计耗时、危险参考和携带建议 |
| 航行 | 在船内走动、补给、查看路线，需要时改道 | 船位沿航线推进；所有人都看见当前目标和抵达倒计时 |
| 自动降落 | 等待飞船落稳 | 目标地表进入视野，坡道展开，可以下船 |
| 矿区探索 | 采矿、找路、处理危险、带货返船 | 随身货量增加；未知矿脉规模和遭遇留在实际探索中揭露 |
| 回船交货 | 将矿物放入货舱，整理装备 | 随身负重释放，船货与预计售价增加；钱尚未到账 |
| 再次下矿或撤离 | 继续探索，或提出撤离并集合 | 回船补给不结束远征；确认撤离才关闭坡道并起飞 |
| 安全交货 | 飞船脱离当前矿区 | 本次可出售货物自动交接，收入到账，可在航途中为下一趟补给 |

首次进入游戏建议从船内准备开始，直接配发或提供基础装备，避免没有收入就无法出发。首次出生位置及起始资金仍需与现有菜单和装备规则一起确定。

## 固定船舱与镜头

### 船内三个工作点

船体采用紧凑的横版剖面，常用设备放在同一层。正常准备不依赖爬梯、跳跃、坐席或逐人准备按钮，四名玩家应能看清彼此与交互位置。

| 位置 | 工作点 | 主要用途 |
| --- | --- | --- |
| 左侧坡道旁 | 交货口与货舱显示 | 回船就近卸货，查看已存矿物和预计售价，决定继续探索还是撤离 |
| 中部 | 补给柜 | 查看装备与余额、购买用品；准备操作可与他人选图同时进行 |
| 船头 | 导航台 | 查看星图、选择目的地、确认航线、提出撤离 |

角色、工具图标及可复用设备沿用现有像素素材；新船体保持相同像素密度、硬边和调色方向。内饰以铁灰结构、克制的暖色舱灯、清楚的设备轮廓组织。外形重做不要求保留旧DIY舱段接口，具体轮廓仍待美术审阅。

### 航行时的近景

进入航行后，各客户端镜头平滑收近，以船内人物和设备为主体，窗外或背景表现航行。玩家仍能在船内活动。起降时短暂调整构图，落地后恢复现有地面探索镜头。

打开导航只改变操作者自己的界面，不强制切换其他玩家的镜头。其他人通过公共航行信息条了解进度；想查看详情时，可以自己打开星图。镜头调整不控制航行、出售或降落的业务完成。

## 星图与星球列表

### 上方模拟星图

星图为有固定坐标的示意空间，展示星球节点、飞船当前位置和当前航线。首版采用固定星球位置与统一航速，航线直接连接当前位置和目标；不加入轨道公转、引力、航行战斗或手动操纵飞船的操作负担。

每个星球节点直接标出名称和危险等级。当前目的地再显示抵达时间，其他节点点击后显示从当前船位前往所需时间与简介；详细信息留在下方列表，避免星图堆满文字。飞船位置与目的地使用不同形状，危险等级同时使用文字和颜色，不能只靠颜色辨认。

### 下方快速列表

星球列表提供稳定、容易点击的选择入口。每行或卡片包含：名称、可前往状态、距离或相对远近、预计抵达时间、危险等级、风险标签及一项简短资源／装备提示。当前目标固定置顶，其余按稳定顺序排列，时间变化时不反复跳行。

点击列表会定位并高亮星图节点；点击星图会选中对应列表项。个人正在查看的星球与全队实际前往的星球分开显示。只浏览、悬停或切卡片都不更改航线。

### 信息示意

以下均为界面mock，名称、风险、资源和秒数不代表正式内容配置。

| 目的地 | 从当前船位预计抵达 | 危险参考 | 风险标签 | 资源提示 |
| --- | --- | --- | --- | --- |
| A 灰松星 | 12秒 | 低 | 洞道开阔 | 基础矿较易接近 |
| B 裂谷星 | 12秒 | 中 | 落差较多、局部塌方 | 建议准备梯具 |
| C 暗脉星 | 15秒 | 高 | 巢穴迹象、厚壁清障 | 壁内矿脉潜力较高 |

星图可见mock节点不自动赋予正式降落资格。不可前往项显示原因，例如“示意节点”或“尚未开放”；原型若支持模拟抵达，明确标记为体验占位。

## 当前位置与航行耗时

飞船在星图上的位置连续变化。前往任何星球的耗时都从当前位置计算，而不是使用每个星球写死的固定秒数。接近A时，到A更近；若此时转向B，到B的时间按改道瞬间的位置重新计算，不瞬移回出发点。

首版建议采用：

> 剩余航行时间 = 当前船位到目标的直线距离 ÷ 航速。
>
> 预计抵达时间 = 剩余航行时间 + 预计降落时间。

地图距离使用内部示意单位，不必展示真实天文尺度。星球位置、航速和起降时间共同配置，不对每个目标单独裁剪剩余时间，以免破坏距离关系。

例如A在坐标0、B在坐标90，飞船位于二者连线的45处，航速为每秒5单位。此时到A或B均需航行9秒；移动到15处时，到A需3秒，到B需15秒。若自动降落预计3秒，界面抵达时间分别为6秒和18秒。以上仅用于说明算法。

航行应足够短，让玩家完成少量补给或交流。首轮以多数航程约5–15秒、远端航程约20秒作为原型调节起点，不作为正式平衡值。目的地已确认时到达后自动进入降落；没有目的地时，飞船在安全区域待命，界面明确显示“等待选择目的地”，不显示虚构倒计时。

### 改道与抵达

建议在巡航阶段允许有权限的玩家改道。确认前预览新的预计抵达时间和危险信息，确认后向全队提示新目的地。改道不重新出售货物，也不创建另一笔撤离收入。

进入最终降落阶段后锁定目标，避免临近开舱时突然换图。加载与同步尚未就绪时显示“正在准备降落环境”，不让倒计时长期停在0，也不声称已抵达可下船。抵达后须先完成环境就绪与安全落地，再展开坡道。

## 所有玩家共享的航行信息

### 常驻信息条

航行期间，无论玩家正在购物、移动还是关闭导航面板，画面都显示同一份公共信息：

> 前往 B 裂谷星　｜　预计抵达 12秒　｜　危险 中

降落阶段改为“正在降落”；目标变更、航行取消和环境等待都更新同一位置。信息条保持简短，不挡住角色、商店主要按钮或装备槽位。

### 每个人都能查看

所有玩家可以从信息条入口打开个人星图，查看当前位置、各目的地耗时及危险信息，无需排队占用驾驶席。各自浏览不会覆盖他人的选中项，也不会把全队界面一起打开或关闭。

航线变更属于正式操作，默认建议遵循当前SharedCamp／HostOnly房间策略，并在导航台附近执行。具体操作资格仍待确定；全员读取不依赖谁有改道权限。多人同时提交时只接受基于当前航线版本的有效请求，其他人收到明确反馈。

### 信息一致

当前船位、目的地、航行阶段与预计抵达依据由同一个权威状态维护。各客户端可以平滑显示船位和倒计时，但不能各自决定抵达或重抽危险信息。晚加入或重连后读取当前航程，不从完整航行时长重新倒数。

游戏暂停时，航行进度与倒计时按统一业务暂停规则处理，网络和界面继续工作。加载等待、改道和降落造成时间变化时，向所有人展示相同原因。

## 危险信息与mock边界

首版使用“低／中／高”三档目的地危险参考，配少量可理解的标签，例如落差、塌方、巢穴迹象。mock等级和标签由节点配置提供，星图、列表及公共信息条读取同一份数据，打开界面时不临时随机生成。

| 显示位置 | 必须看见的信息 |
| --- | --- |
| 星图节点 | 名称、危险等级；选中后可见标签与预计抵达时间 |
| 下方列表 | 危险等级、风险标签、预计抵达时间与简短提示 |
| 全员常驻信息条 | 当前目的地、预计抵达时间、目的地危险等级 |

这些信息表示目的地的一般风险，不等于当前矿区随时间升级的危险，也不显示精确巢位、隐藏矿脉形状或必然收益。“低危险”不意味着无敌或不会遇到事件，“高危险”也不保证一定赚得更多。

开发原型在详情中标记“危险资料为mock”。正式替换为作者审核数据前，不按mock触发伤害、刷怪、奖励倍率或矿量变化。未来是否展示实时风险，需单独确定信息来源、可见范围与更新规则。

## 交货保全与撤离出售

### 回船时存矿

采矿所得先进入个人货袋。回船后，在坡道旁交货口一次提交，将实际接收量转入货舱；若设容量上限，未接收部分仍留在身上。界面显示随身货量、船货数量和预计出售收入。

交货释放携带空间，但不立即换钱。玩家可以多次往返同一矿区，已采空矿物和已触发事件保持当前状态。返船本身不重置地图，也不结束远征。

### 撤离时集合

导航台提出撤离后，全员看见集合提示和仍在船外的人员。普通撤离建议等待所有在线、可行动队员登船后启动短倒计时；倒计时结束前可以取消，有人离船则停止关舱。封舱后进入自动起飞。

倒地、断线、紧急撤离以及全员失败下的货物保全，继续由[阶段待决问题](EXPEDITION_CORE_LOOP_GOALS.md#5-待决问题与处理时点)中的Q-08处理。普通撤离不默认吞并这些异常规则。

### 脱离矿区后自动换钱

出售节点建议放在脱离矿区、进入安全航行区域时。背景上由轨道矿业回收商自动接收，玩家无需另去商店星球或寻找NPC。航行到下一颗星球的时间不影响上一趟是否已经结算。

按本次可出售矿种和数量计算收入，完成货物扣除与到账后，向全员短暂显示“本次货物已回收，收入＋金额”。预计售价与最终收入若有差异，显示原因；首版建议固定回收价，不引入市场波动。

已登船玩家身上尚未卸下的矿物，建议在撤离交接时自动并入出售，避免漏点按钮造成损失；正式采用前需要确认。货物、收入与结算记录作为同一次操作提交，同一趟远征不能因改道、重连、重复请求或读档再次出售。

收入进共享余额还是个人账户仍由Q-03决定。现有共享信用点可以作为原型展示方式，不据此确定正式收益归属。

## 补给节奏与再次落地

撤离后已到账的收入可以在航途中使用。补给柜与导航可由不同玩家同时操作；未购物的队员也能看见抵达时间，避免临落地时不知道队伍进度。降落完成后无需再次全员点击Ready即可下船。

矿区内多次返船期间，购物只能使用已有余额，不能把未出售的船货当作现金。首次交货的反馈先落在释放负重、货物保全与预计收益上；装备成长主要放在两趟远征之间。

这与原阶段目标“首次交付后获得可感知补给收益”存在节奏差异，需在审阅时确定是否接受。若希望本趟途中就能升级，再单独选择局部出售或消耗矿物换补给，不能同时把这部分矿物计入撤离收入。

建议将再次落地视为新一次远征。对同一星球，可以选取已审核图池中的完整地图版本；“星球身份”“所选地图版本”和“本次远征实例”分别记录。是否允许返回已撤离的旧矿区、同星球新远征如何刷新，以及装备／余额跨趟保留边界，仍归Q-05／09确定。返回旧实例不能悄悄补矿；重新加载存档也不能冒充新远征。

## 从当前流程接入的顺序

本节记录起草时的接入基线与设计顺序，当前实现和验证仅以[执行状态](DEVELOPMENT.md#stage-cl)为准。普通共享结算、按策略导航、正常全员集合与新远征已获续接选择；紧急／倒地、永久个人成长及最终船体美术另行处理。

现有采矿、个人货袋、购买、船内活动和乘员检查可以作为基础；正式卸货、撤离出售及选图循环尚未接通。既有船舱原型展示了动线，未实现本案的动态星图、共享抵达信息、危险资料或自动出售。

| 切片 | 交付内容 | 重点审阅与后续验证 |
| --- | --- | --- |
| 星图体验 | 连续船位、星图／列表联动、动态耗时、mock危险信息 | 接近A后去B是否更远；查看不会改道；两种入口显示一致 |
| 全员航行反馈 | 常驻目标／时间／危险条，个人可查看星图，确认改道通知 | 非操作者和正在购物者也能看到；个人浏览不互相干扰 |
| 货舱与出售 | 回船存矿、预计收益、撤离后一次性交接 | 转移不丢货；钱和货只结算一次；途中改道不重复到账 |
| 正式起降循环 | 集合／取消、自动起降、同版地图加载与下一次远征 | 环境未就绪不开门；矿区重置边界清楚；异常保留可恢复状态 |

CL-05负责携货、船货与补给事务，CL-06负责航程与结算时点，CL-07参与权限、同步和恢复，CL-08消费只读信息做反馈。正式状态沿用现有YYGC所属Behaviour／State和会话地图，不另建平行世界。协议、存档和公共状态的具体调整在实施前明确单一修改方。

审阅重点是：准备时间是否够短、危险信息是否足以选目的地又保留探索未知、途中改道是否值得保留，以及撤离后成长能否支撑下一趟动力。完整实现进度见[执行状态](DEVELOPMENT.md#stage-cl)，本草案不替代现行玩法合同。
