# 原生矿层实现与测试

本候选在 `ft-20261004-embedded-minerals` 当前分支开发。矿床已经切换为会话拥有的独立 AnyRuleD 地图，正式运行不再创建矿床 ObjectInstance。游戏协议25、存档v19、AMP1 schema2。本轮功能回归通过；专项前台性能及下述场景边界未验，完整方案尚未最终交付。

## 实现事实

`SessionTerrain` 托管前景地图和矿层，沿用 YYGC 会话生命周期。矿种、耐久、储量和最终空格唯一归 ARDMap 与 GridBusinessStateStore。矿床名称、稀有度、初始容量和格归属保留为静态生成元数据，不占实体预算。

2026-10-05 用户确认的暂定玩法：矿床可以藏在墙后。拆墙只改变前景格，不伤矿物、不产出矿物；墙格移除后，对应矿格露出并可采。多格矿床可只露出一部分。直接采矿要求目标前景为空，射线没有其他墙遮挡，并校验工具、范围及两层内容版本。

矿层位于背景点缀之后、前景之前，sorting order 为 -58。五种矿层作者图集和 GUID 保留；同矿连接、异矿边缘、斜角及跨页规则由 AnyRuleD 求解。矿层不参与人物身体碰撞，碰撞仍来自前景格及坡形。

耐久40、每轮产量1及工具伤害沿用已有配置。达到采出阈值后减实际储量，尚有储量则恢复耐久，最后一份才清矿格。货袋容量、奖励与地图变化进入原有对象短事务。资源收益映射继续冻结原矿床 Definition 的配置。

手采和矿工设备改用矿格目标。设备 TaskTarget 的负数表示有界矿格地址，正数仍用于实体，0表示无目标。正式创建入口拒绝矿床实体，世界投影和v19解析也拒绝旧矿床实例数据。旧作者 Prefab／Definition 保留引用，不自动删除人工资产。

## 局部加载与网络

独立 FishNet 广播承载原生 AMP1 字节，复用 MapInterestService、MapProtocol 和 ChunkReplicaStateMachine。游戏侧补连接、可信区域限制、发送预算和确认，不修改 YYGC／AnyRules 或升级依赖。矿层Hello早于可信世界信号时不会安装，客户端按500 ms有界请求重发已冻结的Hello；空游戏信封只用于这个请求，不改变AMP1编码，也不创建新流或授予区域。

前景与矿层客户端分别加载可信角色或船体附近最多160×160格，按32格区块移动；外圈保留完整渲染页缓冲，原生订阅的一格halo恰好补满所需区块。Ready前没有可信玩家槽时使用船体，不把 ControllerSlot 为 -1 的闲置角色当作本地玩家。房主常驻有限世界纯数据，客户端仅保留当前订阅及原生邻格缓冲。

两层的新区域完整区块到达后才装载页面，旧区域的提交不能放行新区域。Unknown 不安装为空格；未加载的缓冲区块变化不送进表现宿主。显示范围限制在加载区域内，地图底部边界保持区块对齐并裁掉世界外填充。

两层共用星球／世界代次，各自保存流会话、代次和提交。可信世界信号限定可接受的矿层 WorldIdentity。初次 Ready 合取对象、地图、矿层及实际相机绘制；普通矿层换区不重建玩家。断线、换世界和加载退休旧副本与页面。

两层均通过游戏侧 `NativeMapTransport<TWire>` 局部订阅：前景使用现有 `MapWireMessage`，矿层使用独立 `MineralMapWireMessage`。区域换代的旧请求若被拒绝，完整基线安装后以当前代次对齐最新需求。前景换区卸载旧逻辑块和页面，不销毁静态背景宿主；往返换区回归验证最多25个加载区块、远处Unknown及背景构建次数保持。诊断摘要现在只覆盖本地订阅区块，不能把不同区域的摘要作为全图一致性比较。

普通采集一次修改一层地图和相关角色状态。候选先校验、安装后通知。本轮不证明意外运行时故障下的通用双地图原子提交，也不新增背景矿物爆破玩法。

## 保存恢复与容量

v19 保存规则指纹、固定61440格最终矿种／耐久／储量，以及压缩的初始静态元数据。最终空格覆盖初始蓝图，加载不能补回已采空矿物。规则指纹与冻结目录确定材质身份，不保存临时流代次。

解码检查格数、压缩及解压上限、尾随数据、矿种、耐久、初始容量与最终储量。两张候选地图和对象准备成功后才交换；无效保存保留原世界。WorldSession资产保存时同时落盘既有入口步道默认值（Enabled、Headroom、MaxCandidates），运行默认值未改。没有自动升级v18，没有删除用户旧档。

全范围61440格夹具具有960个静态矿床、全格非默认储量，v19完整文件717985字节，小于4 MB上限；矿床实体0。该结果证明数据／保存容量，不代表合法生成密度、峰值内存或前台FPS通过。

## 玩家测试步骤

1. 打开正式 Bootstrap，Play 后选择主菜单快速测试中的内嵌矿局。独立Player可加 `--dn-quick-test landed-embedded-minerals`。
2. 检查露出矿物在后壁之前、墙和人物之后。挥镐先减耐久，达到阈值才增货袋；仍有储量时矿格继续显示。
3. 拆掉露出矿格旁的墙，确认发现更多矿床，拆墙没有减少矿物或产生矿物奖励。
4. 采空一格，确认矿层移除，其他格和背景保持，继续挥镐不能重复获得该格收益。
5. 部分采出后暂停、保存；采空后加载，确认耐久、储量和货袋恢复。退出进程后重开并加载应一致。
6. 第二个Player连接房主，比较矿格变化，测试晚加入、断线重连和换世界。未知／墙后矿格不能直接采集。
