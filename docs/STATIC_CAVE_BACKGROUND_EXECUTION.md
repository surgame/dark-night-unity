# 独立洞穴材质与静态背景实施记录

2026-09-22，分支 `codex/static-cave-background`，基线 `8dbee1d`。输入为用户提供的 [执行方案](STATIC_CAVE_BACKGROUND_PLAN.md) 和 H5 v16.1。本页记录真实实现与本批验收，不继承历史测试计数。

用户随后指出墙壁纹理、柔光、人物比例差距过大，并明确允许脱离旧素材和地图场景、保留 AnyRuleD 能力。因此交付范围扩大为**独立岩层风格**，不再只给旧前景叠背景。矿的视觉需要另做，当前候选隐藏矿粒及矿光；矿床实例、采集和货物状态未删除。

## 独立视觉实现

- 新 `CaveStrata` Shader、`StrataCave` 场景和 AnyRuleD 配置不引用旧 `CavePixelRock`、`cave-rock.png`、旧洞穴／Pinewatch／DebugBootstrap 场景。依赖检查为 0 个旧地形／场景路径。角色暂复用原始 worker 像素源，不覆盖源文件。
- 前景采用 H5 `buildFacetField / nearestFacet / shadePixel` 的同源纯 C# 算法，当前 4px 岩块、0.55 分组、1.9 距离宽度及暖岩调色板。**504×312 浏览器导出 RGBA 与 C# 烘焙逐字节一致**。没有 AI 生图、大图缩小或像素滤镜；目标原生密度为 8px／格，原始轮廓由 12 类真实坡形栅格确定，再应用独立的像素外轮廓。
- `CaveRockSurface` 是当前只读格子的显示缓存：后台生成 256×256 页，25px 距离采样边界叠加外轮廓采样边界，主线程每帧至多上传一页到 2560×1536 sRGB GPU 表面（15 MiB）。当前参数的失效半径为 5 格；更改参数后按算法覆盖范围重新计算；过时任务结果丢弃。AnyRuleD 仍负责规则求解、可见页网格与地图能力，白色 8×8 `RuleGeometry` 只提供规则几何覆盖，不是新的岩石美术。
- 新柔光以圆形距离衰减、三束有限宽度岩体遮挡采样生成，双线性插值光场，Linear 合成；纹理仍用 Point。背景中层 2px Alpha 柔边与动态柔光是两种独立作用。矿床不生成矿图、矿光或光场失效。
- 原生角色与地形统一 8px／格。工作台新建 Explorer Prefab，脚底锚点不变；正式候选只把 YYGC ActorView 的显示尺度设为 2，原权威 ActorState、运动数值与碰撞尺寸保持。旧风格显示尺度仍为 1。
- 固定样板由 HTML **未扰动原始轮廓**按整格占比转换后统一构建坡形，避免把不可表示的水平半格逐格拟合成重复锯齿。样板不是 HTML 轮廓逐像素碰撞复刻；格形变化与原始视觉占用共用实际形状；外轮廓只修改显示占用，尚未改写权威碰撞。固定初始格子是唯一可编辑布局源，EditorOnly 预览来自实际初始 Play 的 504×312 原生截图。
- 修正工作台边界 padding 的加载／更新指纹不一致，并在区域刷新前裁剪到世界边界；异常时 Ready 为 false。新增边界测试和实际爆破检查，避免只验证权威清格而遗漏表现更新。

## 独立外轮廓与生成方式选择

此前只有分面和距离着色，没有独立外轮廓。本轮已补上 `CaveOutlineSettings / CaveOutlineBaker`：关闭、宽波、B、C、宽波+B、宽波+C 六种方案，轮廓种子独立于地图种子。当前 Style 采用用户截图的 **HybridB、OUTLINE-0921、幅度 3px、波长 20px、阶梯 2px、岩块 4px**。运行前可在 `Style.asset` 独立切换、调参；活跃预览冻结参数，修改后 R 重建。参数签名进入地图视觉身份，客户端参数不同不会悄悄组成同一展示基线。

顺序为原始权威格形栅格 → 有符号曼哈顿距离 → 全局宽波/阶梯位移 → 孤立像素清理 → 当前轮廓距离 → 岩块分面/裂缝/明暗 → 动态光。初始背景也从扰动后的初始参考产生；挖掘只改当前岩壁，不追随重生成初始背景。显示轮廓通过完整页面合成，避免被旧规则网格裁掉向外长出的像素。没有把噪声简单变成 UV 扭曲。

六种方案均与 Chromium H5 金样逐像素一致；18 个任意切片、当前 4/3/20/2 完整 RGBA、七次分页及实际编辑后分页与整图一致。金样原生 504×312，新增夹具与旧 5px 默认夹具分别保存，不改旧金样掩盖差异。

| 方式 | 结果与适用范围 |
| --- | --- |
| 每帧完整动态计算 | 不选。Unity Mono 下 256×256 单页 CPU 中位数 32.28ms、最大 39.45ms（7 次），完整地图还有多页；不应占每帧主线程。 |
| 最终颜色与轮廓压成 16 张固定 RuleTile | 不选作完整效果。H5 样板中 14 种局部掩码对应 1,462 种不同 RGBA 图块；全局噪声相位、25px 邻域距离和背景层所有权无法仅由这 16 种局部索引表达。增加有限变体也不等价于任意种子和破坏结果。 |
| 同源算法按页生成并缓存 | **当前采用**。初次/失效时后台烘焙，静止不重算；可变前景局部失效，静态背景一次生成。动态光单独合成。AnyRuleD 保留地图、规则、流式副本与编辑能力；固定掩码/调色板可预制。 |
| 针对完整固定地图预烘焙页面 | 可作为加载优化，能保留完整效果，但这是整图页面缓存，不是通用 RuleTile。随机种子或挖掘后仍须同源动态烘焙作后备。本轮未另做离线页面打包器。 |

.NET Release 单页约 10.64ms，不能替代 Unity Mono 的 32.28ms；上述只测 CPU 烘焙，未包括上传和前台 GPU。正式 320×192 初始背景（含外轮廓）CPU 一次构建约 974.65ms；三层背景 256×256 单页中位数 3.80ms、最大 4.09ms；样板 20 盏柔光的光场更新 5.59ms（含反射调用开销）。前景固定 GPU 表面 15MiB，背景最多 45MiB。实测源样板外轮廓改变 1,410 像素，最大外扩 2px、内缩深度 1px。**此轮是表现外轮廓能力，不是逐像素碰撞改造**；权威十二坡形不变，可能存在细小脚底/墙边偏差，参数上限不能当作可行走几何验收。扩大成可改变通道的几何算法需另外把相同规则接入权威运动并验收。

## 已实现

- **背景源与方式**：直接提取 H5 的四组 16-mask 位图；纯 C# 移植同源噪声、距离、形态清理和着色，后台生成可见页。每 tile 原生 8×8，固定图集 128×32，背景页 32×32 格／256×256 像素。中层柔边 2 样本，即 0.25 格；不是屏幕像素或 Bilinear 滤波。
- **初始参考**：正式远征生成器完成泊位、通路和坡形后捕获材料与形状。`BackgroundBakeDescriptor` 深拷贝，持久 WorldId、种子、坐标／算法／样式身份纳入 SHA-256。Epoch 不参与图案随机数。活动格子仍唯一归 YYGC 会话内 `TerrainMapAuthority`；背景没有写入、碰撞或矿物结算能力。
- **保存与恢复**：协议 **13**／存档 **v9**，参考通过有界成对 RLE 封套保存。版本、样式、长度、材料、形状、哈希及尾随数据全部校验后才生成候选。远征缺参考拒绝，恢复失败保留活动世界。v8 等旧档保持原文件，当前读取器拒绝，不从破坏后的地图猜原始背景。
- **网络**：沿现有 FishNet 会话基线增加 8192 字节可靠块，总量最多 250000 字节（31 块）。接收器按世界／会话 Epoch／地图 Epoch 组装，完整校验后发布。当前 AMP1 地图与初始参考分别送达，共同门控 Ready；没有新网络栈、每格 RPC 或纹理同步。背景内容摘要进入握手和地图视觉身份。
- **表现**：新 `CaveStrata` 合成底墙→深→中→浅→当前前景，再使用各位置动态光。纹理不烘焙动态光或矿。作者 RGB 用 sRGB 纹理进入 Linear，Alpha 为 straight alpha。初批 `CavePixelRock` 背景分支只保留为阶段对照，不是新版样板的渲染依赖。
- **缓存**：后台一次生成逻辑层，再逐页着色；主线程每帧最多提交一页（三张纹理／768 KiB），CPU 纹理副本上传后释放。通常保留 24 页，超出的不可见页按最近使用顺序释放；全图调试上限 60 页、45 MiB 纹理数据。切世界取消任务并释放页。地形、矿和光场分别失效，均不触发背景重建。
