# 远征营地 Demo 实施与快速验收

2026-09-21，分支 `codex/expedition-camp-plan`。实现基于 [执行方案](EXPEDITION_CAMP_EXECUTION.md)，协议 **12**／存档 **v8**，YYGC 继续锁定 `12b253c`。这是首轮可玩实现和快速验收记录，不把原计划中的完整性能、全路线或双机器门槛写成通过。

## 已落地玩法

- 正式 Bootstrap 默认加载 `Res/Scenes/Expedition/Expedition.unity`。原生飞船、HUD、对象定义和 Addressables 已接线；`--dn-camp-mode` 保留旧 Pinewatch。
- 12 个紧凑洞室；普通室 22–30×10–15 格、裂隙 16×22 格、较大矿房 32×16 格。飞船局部泊位宽 24 格，第一矿床有确定性的往返阶坡。保持角色尺寸、16 px 格密度与权威坡形碰撞。
- 新洞穴不生成实心矿材料；独立矿床拥有余量，后壁绘制矿簇，覆盖岩体显示对应矿光。露矿没有角色阻挡；手采同时检查距离、视线、装备冷却和货袋容量。爆破只处理岩层，远征移除旧矿格全局收益。
- 整备→出发→探索→撤收→倒计时→结算。个人氧气、货袋、前线仓储、机器人携带和船仓分别归所属 YYGC State。矿物入船后仍不直接进入可支配经济，返航统一结算。
- 机器人舱、货舱、船员舱各 10 铁。机器人自动搬运氧气站、仓储、炮塔、灯；矿工使用实际地面运动交货，机器人走有尺寸的空域路径。船员舱再提供一个氧气中继，连接最多船→前哨→矿房。预算按稳定对象顺序启停。
- 矿工满包／低氧返程，机器人转运前线库存。召回优先停止新任务，保障氧气设备后收；起飞前检查人员、设备回收状态。紧急起飞两次点击确认，8 秒倒计时内仍可登船。
- 时间、设备和采矿增加警戒；一类旧敌人外观复用到洞穴导航，炮塔检查二维射程、遮挡与供能。新增警戒阈值在首次交货快验后调到 180，旧三夜规则不改。
- 未登船玩家丢失货袋，下一次出发恢复。丢失的机器人、矿工和设备不会免费重生；结算记录补充费用，整备阶段付款后再部署。模块配置保留。
- 返航将收益、损失和结算标记写入同一原子保存包，自动使用 **槽位 10**；写盘失败回滚当次结算并暂停。取消暂停可重试。手动保存沿用原槽位入口，文件位于独立 `v8` 目录，不删除旧档。
- 重连重新取得原玩家槽位的角色和货袋；Host 与来宾均走原可信请求链。地图完整数据、表现和对象基线共同门控 Ready。

目前“再次出发”复访同一保存世界，保留已挖岩层和矿床消耗；菜单重新选种子用于新营地。未实现携带现有营地成长自动切换到另一颗随机星球。

## 操作与制作入口

从 Bootstrap Play／Player 进入正式地图。裸装出发后向右沿阶坡到第一矿床，使用现有矿镐采集，返回船边卸货、登船。房主召回后正常起飞，或确认紧急起飞。首次收益可购买舱段，第二次出发自动展开已获得的能力。

中继按钮将可用氧气站搬到角色脚下，服务端检查父连接与机器人路径；派工按钮选择最近的有余量矿床。当前 HUD 是快速操作面板，没有独立的拖拽放置预览页。设备无电变暗，灯与飞船向洞穴光场提供实际光源。

占位素材采用 Pillow 按原生像素绘制，没有调用生图服务。13 张 PNG：飞船 8 个模块组合（192×48），机器人 16×16，氧气／仓储／炮塔 32×32，灯 16×32。源、哈希和方法见 `Res/Art/Custom/ExpeditionPrototype/source.json`；生成器 `tools/create-expedition-art.py` 拒绝覆盖已有 PNG。矿工复用工人外观。飞船当前采用最大泊位尺寸与固定槽位外形，未按已安装中段改变逻辑占地。

正式对象位于 `Res/Objects/Expedition`，HUD 位于 `Res/UI/Expedition`。新 Prefab 和场景已保存、重开并验证布局。新增资产保留 Unity 生成的 `.meta`，后续替换美术保留定义身份及 GUID。没有改动 YYGC 框架或依赖锁。
