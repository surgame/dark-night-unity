# 飞船到达连续取景

2026-10-03，分支 `fix-20261003-continuous-ship-arrival`，基线 `01d881d`。用户要求实现到达时的一镜到底衔接，先保证代码编译通过，再列出待验证项。本轮不构建 Player、不执行完整 Play／联机矩阵。

## 实现

- 权威 `Preparing → Transit → ArrivalSync → Descent`、地图事务、epoch、角色租约及驾驶权限保持原合同。没有修改 YYGC、依赖版本、协议 23、存档 v16 或 AMP1 schema 2。
- 同一连接、同一航程／地图／船实体正常到达时，镜头当前位置与目标同帧平移到新坐标系，保留缩放和跟随速度。读档、换房、不同航程及跨多个 epoch 不沿用该适配。船体取景不再受地面横向镜头边界裁剪；下船时平滑接近合法地面目标，不直接裁剪镜头当前位置。
- 同步期间本地船员可以继续跟随显示船体；输入及业务命令仍受 Ready 限制。镜头在角色 LateUpdate 更新目标后统一采样。
- 飞船、乘员和随船设备的显示位置共用冻结投影插值时刻；跨 epoch 仍直接使用新坐标，避免插值穿过两个世界。
- 星点位移不在阶段切换时归零。地图准备和实际绘制尚未完成时继续显示太空；完成后用 1.2 个本地表现秒平滑显露天空、远景、岩壁和三层背景。暂停期间不推进显露。
- 地形透明度通过本宿主的 MaterialPropertyBlock 设置，Shader 默认值为 1。原始 PNG、作者材质和配置资产未改。Ready 仍等待地图／背景／当前游标绘制，并额外等待完整显露后的相机回执。
