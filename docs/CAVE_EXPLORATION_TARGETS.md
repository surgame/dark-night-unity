## 结论

当前完成的是洞穴拓扑技术原型，尚未完成参考图要求的空间组织与美术。关键差距为洞室形态、可行走地貌、像素岩壁、空间分层和局部光照；仅替换贴图、增加噪声或增加房间数量无法补齐。

目标是“由厚岩层分隔、带岩棚与落差的天然洞穴剖面”：能看清脚下路面与前方岔路，远处有深度，矿物或灯光形成局部关注点。参考图本身包含大量精细明暗，不能未经角色与镜头尺度校准就把它理解为 16×16 tile 的逐像素模板，也不要求随机地图复刻其全部构图。

## 技术目标与边界

### 1. 保留 DualGrid，补齐独立形状

DualGrid 负责相邻格的视觉拼接，不能自动解决岩棚布局、坡面运动或天然洞穴构图。基础 16 个四角掩码继续服从 AnyRuleD 的 NW / NE / SW / SE 合同；斜面需要独立形状语义，不能仅靠同一个实心格的换图。

实施时先核对已锁定 AnyRules 的 tile／形状扩展能力，选择能被现有权威地图保存、同步和局部刷新的表达；不要先假定框架必须升级或另存一份碰撞地图。若确有缺口，再按隔离依赖修正规范处理并记录落点。

`TerrainHeroMotion.Solid` 当前按非空格判实心，落地吸附格顶；需要改为形状占据查询与斜面支撑高度，并处理横移抬升、下坡贴地、头顶碰撞、坡墙交界与高速落地。只添加 Unity Collider 不会改变当前权威运动。形状影响碰撞的数据必须进入唯一权威状态；背景、碎石和灯光只读其结果。

采矿射线、炸药命中与破坏后邻接重算也必须遵循形状，避免看见的空隙被当成实体。若网络／存档数据合同变化，届时明确升级版本，不在此次评估中预占新版本号。

### 2. 先确定空间用途，再生成外轮廓

生成流程目标：着陆区与入口 → 有洞室用途、深度与能力需求的隐藏图 → 洞室骨架及落脚平台 → 可变宽通道／竖井 → 岩体厚度与斜面约束 → 通路掩埋 → 最终几何通行验证 → 矿物／装饰／照明。

洞室至少覆盖宽洞厅、狭长裂隙、竖井、阶地洞腔四类轮廓。首批仍以现有 10–13 洞室为数量基线，重点改变形态和用途，不靠增加地图尺寸提升观感。

验证分开记录“初始开放”“按指定工具开通”“仍然封闭”的区域；检查主路线往返、跳跃落点、喷气燃料和可恢复落脚点。抽象图连通、空格泛洪与真实角色可达性是不同检查。梯子尚未作为本轮必需机制，竖井设计先服从现有跳跃／喷气能力；不能靠无限飞行观察器签署通过。

### 3. 用有限层次构成剖面

先做后壁、岩体、碎岩边缘及局部灯光的小样，保留当前 Linear。亮暗要随岩面朝向和遮挡变化，避免每块 tile 烘焙强光后在拼接处露出方格。高频细节集中在可探索边缘，岩芯降低对比，让角色与路径成为主体。

不预先要求迁移渲染管线；先核实现有材质、排序和局部遮挡能力。掘开通道后同时更新可见岩缘、后壁暴露与遮光。灯具若只是样板表现，不额外创建可交互业务系统。

## 生图必要性评估与制作规格

本项目需要生图时，明确使用 [imagegen-codex-provider](C:/Users/Jobscn/.codex/skills/imagegen-codex-provider/SKILL.md)。用户本次已指定此路径，不再沿用上次“等待 API 授权”的状态。按当前技能显式选择 `gpt-image-2.5`；技能升级时以其当时规范为准。必要的能力变更遵循技能约束，密钥不得进入命令、日志或项目。

| 素材 | 必要性结论 | 制作方法及理由 |
|---|---|---|
| 16×16／32×32 基础 tile、16 掩码、透明共边 | 默认不生图 | 直接像素绘制与确定性切片；共边坐标和像素团块比大图细节更重要 |
| 独立坡面、缓坡组合与角部过渡 | 不依赖生图决定形状 | 先定义占据区域和拼接合同，再制作对应像素边缘，确保视觉与碰撞一致 |
| 岩石调色板、岩层风格探索 | 可选，不是前置条件 | provider 可输出少量研究图用于色彩和层理参考；先比较最终目标尺寸下的效果，再决定是否扩大使用 |
| 大块远景、背景岩层、非碰撞装饰 | 视样板需要使用 | 较大画幅更适合生图；仍需统一像素密度、精修和分层，不直接铺整张概念图 |
| 灯、碎石、小晶簇等低像素点缀 | 优先直接像素绘制 | 需要稳定轮廓、透明边和有限颜色；生图后反复缩图通常增加清理成本 |

沿用前次 32×32 tile 作为首轮候选，逻辑格仍为 16 玩法像素；需要在角色、装饰和后壁之间统一“每世界单位的源像素数”。制作规模扩大前先在实际镜头检查像素密度，不擅自改角色尺寸、数值或旧素材。

基础目标仍为普通岩、松散填充、深色硬岩／基岩的视觉区分；首个样板先完成一种主岩与一种填充的完整拼接。稳定后扩展全部基础材质及每种至少四个纹理变体。变体按稳定种子／坐标选取，破坏和页面重载不应导致未修改区域纹理跳变。

最终资源 Point、无 mipmap、无有损压缩；控制透明边缘色，检查原生尺寸和整数放大后的接缝。源文件和派生图集放既定 Custom 目录，保存可编辑来源、生成或绘制方式、派生关系及校验信息；不覆盖 Original 或人工源文件。

本次只评估并确定制作方式，没有发起图像 API 请求，也没有将任何生成图记为已交付素材。
