## 2. 阶段目标

让两名玩家在一个星球主题中完成：**进入矿区 → 发现有价值的洞室 → 冒险采集 → 搬回飞船保全 → 补给后继续或共同撤离 → 结算成长 → 再次开局。** 架构维持2–4人兼容，本阶段以两人完整体验为主要判断入口。

阶段成功的核心证据是：玩家有已获得、值得保全的货物，又看到值得冒险的新发现，能够理解风险，并主动讨论继续还是撤离。编译通过、地图扩大或功能数量增加，不能单独证明该目标成立。

| 体验目标 | 玩家可感知的呈现 | 应交给用户判断的内容 |
| --- | --- | --- |
| 发现驱动探索 | 天然岔路上的露矿引导挖墙，壁内矿脉规模未知；沿路越远收益潜力越高 | 是否愿意主动挖下去，短途路边采矿与远行富矿是否都有吸引力 |
| 收益有落点 | 身上货物与船内保全货物清楚区分，首次交付获得可感知补给收益 | 是否理解返船价值，是否愿意再次下矿 |
| 时间带来压力 | 全局危险持续升级；噪声影响附近反应并可加速危险 | 是否前段能探索、后段需权衡；不是无上限刷怪 |
| 意外可学习 | 落石／塌方、拟态或伏击生物、隐藏富矿具有线索、反应窗口和结果 | 是否能解释危险、再次识别并利用环境 |
| 路线可经营 | 初始基础路线可原路往返，玩家携带梯具探索高处；梯具破坏或塌方会改变返程风险 | 初始路线是否成立、破坏后果是否可理解；动态破坏后不保证返回，本阶段不考虑回环 |
| 合作有意义 | 照明、采集、搬运、警戒可互换，队友可救援并共同撤离 | 是否自然协作，队友位置／状态／撤离意图是否清楚 |
| 一局能够收尾 | 撤离、全员失败、结算和新矿区有清楚边界 | 已保全收益是否可信，下局是否有明确动力 |

15–25分钟、3–5处关键发现、2–4次特殊遭遇、1–3次交付及前5–8分钟获得首次装备收益，均为原策划的试玩假设，不是已获验证的数值或硬性截止。暂停语义、危险计时起点和失败结算须先解决下方对应问题。

### CL-01开发目标：预制矿洞、探索节奏与返程

2026-10-15用户确认“开发端随机生成、游戏内预制加载”的方向，并要求整理CL-01目标，后续与CL-04怪物巢穴生成合并开发。本节是联合实施的目标与评审入口，实际切片顺序见[模块计划](ROADMAP.md#cl01-joint-slices)，生成与导出边界见[地形设计](TERRAIN_GENERATION.md#cl01-approved-map-design)。本次只整理目标，不据此宣称实现、通行或遭遇已通过。

**交付目标：提供可被反复选择、路线可经营、风险可读的矿洞完整版本。** 开发端完成“作者输入／随机候选 → 地形、矿层与巢穴共同生成 → 自动筛查 → 人工修整 → 获批实走与事件核对 → 冻结审核版本 → 地图库入库”；游戏端选择并加载已审核版本，保留本局正常采掘、塌方和怪物行为。地图预制不等于地形不可破坏，也不把怪物行动编成固定时间脚本。

| 目标 | 玩家体验／可审查交付 |
| --- | --- |
| T-01 初始路线与梯具探索 | 基础主路暂定天然贯通且有岔路，无喷气依赖，初始基础路线可原路往返；高处需玩家携带梯具到达，地图不生成梯子。梯子可被破坏，动态破坏后不保证玩家一定返回，不自动修路或补梯 |
| T-02 路程与矿脉收益层次 | 浅深按沿路距离及到达难度划分，不按垂直高度判定；越远、越难到达越深，更贵矿种与更多储量形成更高收益。内层指玩家用镐挖开墙壁后揭露的壁内矿，部分露矿吸引继续挖掘，可能延伸成大矿脉；路边小矿数量较多且好采集，短途采矿也有有效收益 |
| T-03 原路返程与探险风险 | 按原路返回设计，不考虑回环或捷径必做；塌方可完全封堵或收窄原路，梯具损坏亦可造成断路，审核记录这些风险，不以全程保证返回为目标。完全封堵不自动等于不可挖除，清障与损坏细节继续确定；入舱保全／补给仍归CL-05 |
| T-04 巢穴共同设计 | CL-04的巢体、出虫、前兆、退避与矿层排除需求参与洞室规划；地图与巢穴在开发端形成同一完整候选，不在运行开局再扫描空地补巢 |
| T-05 有限且可审核的变化 | 作者图和随机生成结果均可修整、冻结和入库；地图、矿层、巢穴与地质事件位作为一套完整版本审核；首轮不独立随机拼接这些业务内容 |
| T-06 可编辑与可复现 | 工具台能编辑用途、通路、候选与允许改形范围，预览最终碰撞／矿层／巢穴和失败原因；每图有稳定身份、版本、来源及审核记录；加载不依赖重新执行生成算法 |

以下硬性门槛保证初始地图与数据正确，并核对声明事件组合的实际后果；按D-11，动态破坏造成无法返回是允许的风险，不再以所有事件后必定可返作为通过条件：

| 指标 | 入库门槛 |
| --- | --- |
| 初始路线可达 | 天然基础主路及必需目标按基础运动可往返，不能靠调试传送、喷气或未确认升级通过；高处标出玩家携带梯具的进入条件，地图不预置梯子。核对初始空间及梯具完好时的条件，不保证其损坏后仍可返回 |
| 最终碰撞一致 | 净空、坡形、跳跃落点按实际角色身体及最终格形核对；只证空腔连通或生成成功不算通过 |
| 初始安全范围 | 飞船进出、出生及首次基础试采路径不被初始活巢、巢体或封路塌方强制占据；这不授予运行时无敌区 |
| 破坏后果一致 | 允许梯具破坏断路、塌方完全封堵或收窄；碰撞、表现及所属状态须一致，记录影响位置、占位、可挖性与可能失去返程的后果，不自动恢复可达性。具体伤害、清障成本、梯子破坏来源及失败出口仍需所属切片确定 |
| 巢穴与事件空间 | 必需巢位、出虫点、线索可观察区和退路全部有效；不得与原矿床、关键落点或保护结构冲突。活巢与塌方共享退避范围时必须作为显式组合核对 |
| 审核身份与加载 | 入库版本包含同批最终地形、矿层及静态站点；运行加载和各端所见初始布局与审核版本一致。改动影响上述结果或基础能力时使原审核失效，重新核对受影响范围 |

下表为首张样板的**设计起始建议，待实际试玩调整**，不是已确认平衡值、自动授权改图或运行计时规则。时间从持有基础矿镐／手电、出舱可操作时计；首次收获用正常速度探索测量，纯返程用已知路线、无采矿／战斗／停留测量；样本记录人数、装备及地图版本。

| 指标 | 首轮建议／记录口径 |
| --- | --- |
| 首次可采收益 | 出舱后约30–90秒取得首批矿物；不把发现矿物但无法开采算成功 |
| 首次短途往返 | 约2–4分钟能完成一次浅层试采并走回飞船；不是要求已完成交付或升级 |
| 关键发现 | 每图约3–5处值得停留或讨论的发现，至少覆盖浅层试采、中段选择和深层诱因；不是总房间数配额 |
| 有意义支线 | 首张样板约2–3条不同用途天然支线，含至少一处露头延伸成壁内富矿的发现；矿脉不必须附带独立矿室，路边小矿提供短途选择 |
| 连续空跑 | 无新地标、线索、资源或选择的连续行走段以不超过约20–30秒作为检查起点；需要长段时说明节奏用途 |
| 回程成本 | 未被事件破坏的已知原路纯返程先以约60–120秒评估，另记清障及梯具进出成本；发生断路则记录原因，不用调试传送凑时长。回环／捷径节时不作为条件，专项积怪刷怪后置 |
| 通道与跳跃余量 | 普通通道净高先以4–6格评估，特殊狭口单独核对；常用必经上跳先按不超过2格设计，不把理论约2.5格跳高当常态极限门槛 |
| 巢穴联合样板 | 以真实露矿、壁内富矿与关联巢位展示共同生成；富矿大概率伴巢，越深概率越高。具体概率／数量、出虫尺度、触发与反应窗口仍待联合设计，候选数不等于本局激活数 |

整体远征15–25分钟、前5–8分钟首次装备收益和1–3次交付仍只是阶段试玩假设；地图不能单独保证这些跨模块指标。首张样板优先评估当前默认折返洞网，最终选图在联合实施开工时登记；先完成一张，再推广不同路线结构的有限图池，首轮数量及每图变体数仍待审阅。若后续需要运行时内容变化，先审核完整组合及其边界，不以各系统独立抽签替代组合审核。
