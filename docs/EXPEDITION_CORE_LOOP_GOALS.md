## 2. 阶段目标

让两名玩家在一个星球主题中完成：**进入矿区 → 发现有价值的洞室 → 冒险采集 → 搬回飞船保全 → 补给后继续或共同撤离 → 结算成长 → 再次开局。** 架构维持2–4人兼容，本阶段以两人完整体验为主要判断入口。

阶段成功的核心证据是：玩家有已获得、值得保全的货物，又看到值得冒险的新发现，能够理解风险，并主动讨论继续还是撤离。编译通过、地图扩大或功能数量增加，不能单独证明该目标成立。

| 体验目标 | 玩家可感知的呈现 | 应交给用户判断的内容 |
| --- | --- | --- |
| 发现驱动探索 | 浅层可快速试采，中段有岔路、隐藏矿室和深层诱因 | 是否愿意主动探索，是否主要在挖普通墙和无意义跑图 |
| 收益有落点 | 身上货物与船内保全货物清楚区分，首次交付获得可感知补给收益 | 是否理解返船价值，是否愿意再次下矿 |
| 时间带来压力 | 全局危险持续升级；噪声影响附近反应并可加速危险 | 是否前段能探索、后段需权衡；不是无上限刷怪 |
| 意外可学习 | 落石／塌方、拟态或伏击生物、隐藏富矿具有线索、反应窗口和结果 | 是否能解释危险、再次识别并利用环境 |
| 路线可经营 | 基础能力能往返，局部破坏影响捷径与回程 | 暂无喷气背包时能否返回，塌方后是否存在基础解法 |
| 合作有意义 | 照明、采集、搬运、警戒可互换，队友可救援并共同撤离 | 是否自然协作，队友位置／状态／撤离意图是否清楚 |
| 一局能够收尾 | 撤离、全员失败、结算和新矿区有清楚边界 | 已保全收益是否可信，下局是否有明确动力 |

15–25分钟、3–5处关键发现、2–4次特殊遭遇、1–3次交付及前5–8分钟获得首次装备收益，均为原策划的试玩假设，不是已获验证的数值或硬性截止。暂停语义、危险计时起点和失败结算须先解决下方对应问题。

## 3. 本阶段范围与现有起点

当前正式游戏已有主角移动／跳跃、手电、挖墙露矿、个人铁金货袋、船内购买、飞船及联机基础。五张作者扩展图已接入，但不等于随机房间组合或全图通行已完成；H5中的搭梯、痕迹观察、巢穴及交矿不计作正式Unity成果。当前事实以[基础范围](GROUND_GAMEPLAY_BASELINE.md)、[地形合同](TERRAIN_GENERATION.md)及 DEVELOPMENT 为准。

本阶段覆盖一个主题的可复玩矿区、受控破坏与返程、三类核心事件、新时间威胁／噪声、货舱保全与现场补给、撤离结算与最小成长、两人合作／救援及必要反馈。先用作者样板验证路线和事件，再接入受约束的房间组合或内容变化；只有固定图不能宣称随机矿区目标完成。永久升级以至少两种为设计目标，具体内容和所有权仍待决定。

第二颗星球、运输无人机、自动采矿、复杂气体／水电连锁、机械遗迹及外观个性化列入后续候选。新计划不恢复旧营地、守塔、训练、自动物流，也不自动批准框架修改、并行Editor、额外测试或构建；用户已有明确授权按原范围连续执行。
