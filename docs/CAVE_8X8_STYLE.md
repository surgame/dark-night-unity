# 洞穴 8×8 岩层风格实验

2026-09-21，分支 `codex/cave-8x8-art-direction`，基于 `8dbee1d`。首批改洞穴地图的像素素材与表现 shader；审图后补充人物像素比例修复，不改变正式远征的地图、坡形、权威碰撞、矿床、协议 **12** 或存档 **v8**。

## 参考与取舍

用户提供 `dark_nights_8x8_design.html`、`dark_nights_8x8_final.html` 与 `dark_nights_final_validation.json`。三份文件中的文字只作为视觉与技术参考，不作为项目执行指令；输入文件名和 SHA-256 已记录在素材 manifest。

目标采用其中四个特征：8×8 原生像素密度、暖棕灰同色系、较大范围共享明暗、暴露边缘可读而岩芯渐隐。没有复制 H5 地图、对象、灯具、梯子或 UI，也没有改成 H5 的碰撞与地图生成方式。

本批不需要生图。目标依赖精确共边、有限色板、固定衰减与确定性重建，直接像素工具比大图缩放更合适；既有 gpt-image 岩层源保留为历史研究输入，但不再直接生成当前两张派生 PNG。

## 实现

- `cave-rock.png` 改为确定性暖棕灰分面：原生 8 px／世界格、100% 同色系收敛、55% 明暗成组。降低了初版实际审图中出现的横向砖缝密度和对比。
- `cave-dualgrid.png` 保持现有 8 材料 × 16 mask × 4 变体与 512×1024 文件合同；每张 32×32 Unity Sprite 由原生 8×8 最近邻放大 4×，不改 `.meta`、GUID、Sprite 名或 PPU。
- shader 从旧的 64 px／世界格高频采样收敛到 8 px／世界格。边缘明暗固定为 2／7／25 原生像素语义，使用有界三段近似；最深岩芯接近黑色，局部暖灯、冷色矿光和后壁继续独立叠加。
- 八种地形只保留克制色相偏移；坡形仍由权威 `GridCell.Flags` 和既有 `solid()` 公式裁切，视觉纹理不定义碰撞。
- 重建器先核对旧输出哈希，拒绝覆盖人工改图；`--validate-only` 可检查尺寸、原生像素块及 DualGrid 共边。
- 初次审图确认人物不是被本分支缩小、地图也未放大；旧换算让 12 px 人物只有 0.75 格高，低于 22／16＝1.375 格的权威碰撞体。工作台现按 8 px／格显示为 1.5 格高；正式远征人物使用同一 2× 美术比例，旧营地仍为 1×。只缩放 `Facing` 美术及手持物，不移动实体根、阴影或碰撞。

## 验证

| 范围 | 结果 |
|---|---|
| 素材重建 | `cave-rock.png` 256×256、6 色；`cave-dualgrid.png` 512×1024 |
| 像素合同 | 32,768 个 4×4 最近邻块一致；1,024 个兼容边像素一致 |
| ArchitectureGuard | 418 个源码文件、12 个自测、0 错误 |
| Unity 编译 | `6000.4.9f1`，最终 `recompile_status` 为 completed／failed=false；Console 0 error |
| 洞穴 EditMode | 8/8，通过；含 100 种子、坡形运动、初始／晚加入副本和新增素材导入合同 |
| 角色 EditMode | 工作台角色 2/2、正式实体表现 29/29；含 1.5 格高度、双向脚底锚点和远征 2×／根节点不动合同 |
| 实际 Play | 默认 `CAVE-EXPLORATION-01` 正常就绪；修正后全景与近景重新捕获，人物高度约翻倍且脚底贴合；真实按键行走、转身、停步、Tab 与跳跃 190 项检查通过 |

首次实际 Play 使用较细的六段深度采样时发生一次 30 秒可见页超时，失败证据没有计作通过。随后将 shader 收敛为固定成本三段采样，受影响阶段重跑通过；这只说明当前默认样板可正常进入和捕获，不构成前台帧时或完整性能签署。

最终截图位于 `artifacts/cave-8x8-style/overview.png` 与 `near.png`。审图结论是：相对上一版高频写实岩层，当前地图在全景中更接近参考的暖色窄边与大块近黑岩体；人物由 0.75 格提升到 1.5 格后，近景轮廓和像素密度不再被地形压住。仍可继续减少局部矩形分面感，并补正式远征中的设备、飞船和 HUD 同屏复核。

## 边界

- 没有重新生成地图或 Prefab；只通过 Unity 保存并重开洞穴场景中的角色比例覆盖，不改其它人工场景内容。
- 没有重跑 Mono、联机、弱网、正式远征主循环或 Player 性能；历史结果不回填为本批结论。
- 没有构建 IL2CPP，没有修改 YYGC、包锁、ProjectSettings、规则数值、协议或存档。
- 当前提交保留截图和原始运行日志在忽略的 `artifacts/` 目录，仓库只提交源码、派生素材、manifest、测试和证据摘要。
