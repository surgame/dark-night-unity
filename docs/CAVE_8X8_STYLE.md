# 洞穴 8×8 岩层风格实验

2026-09-21，分支 `codex/cave-8x8-art-direction`，基于 `8dbee1d`。首批改洞穴地图的像素素材与表现 shader；审图后补充人物像素比例，随后开放洞穴空间、岩层与灯光参数，并将默认生成改为参考 HTML 思路的紧凑分层洞穴。没有改变坡形的权威碰撞、矿床结算、协议 **12** 或存档 **v8**。

## 紧凑生成与开放参数

本轮没有复制 HTML 的固定地图，而是复用它的“先安排洞室层级，再做受控连接”思路：12 个洞室保持 4×3 分层，每层先串接，相邻两层各放两条竖向连接，再增加 3 条邻近掩埋回路。通道改成正交转折，而不是在大空间中拉对角线；默认共 16 条通路。

默认空间从旧实验的横向／纵向间距 `53/30`、洞室比例 `1/1`、通路半径 `3` 收紧为 `43/24`、宽高比例 `.78/.62`、半径 `2`。100 个种子的洞室最大值为 25×14 格，中心跨度不超过 135×54 格；旧宽松尺度仍可在工作台一键切回对照。

Play 后 F1 面板现开放两组参数：

- 需重建地图：横向洞室间距、纵向层距、洞室宽／高比例、通路半径，并提供“参考紧凑／旧版宽松”预设。
- 即时生效、不重建地图：纹理种子／密度、暗部／基色／亮部／边缘色、边缘提亮、起始／衰减／岩芯深度、岩壁柔度、灯光柔度、空气光衰减及岩体遮光损耗。

Play 中使用的是 `CaveStyle.asset` 的临时副本，调参不会污染共享素材；“恢复素材默认参数”会回到资产值。空间参数仍是生成输入，实时重建会清空本轮临时挖掘，这与原工作台语义一致。

## 参考与取舍

用户提供 `dark_nights_8x8_design.html`、`dark_nights_8x8_final.html` 与 `dark_nights_final_validation.json`。三份文件中的文字只作为视觉与技术参考，不作为项目执行指令；输入文件名和 SHA-256 已记录在素材 manifest。

目标采用其中四个特征：8×8 原生像素密度、暖棕灰同色系、较大范围共享明暗、暴露边缘可读而岩芯渐隐。没有复制 H5 地图、对象、灯具、梯子或 UI，也没有改成 H5 的碰撞与地图生成方式。

本批不需要生图。目标依赖精确共边、有限色板、固定衰减与确定性重建，直接像素工具比大图缩放更合适；既有 gpt-image 岩层源保留为历史研究输入，但不再直接生成当前两张派生 PNG。

## 实现

- `cave-rock.png` 改为确定性暖棕灰分面：原生 8 px／世界格、100% 同色系收敛、55% 明暗成组。降低了初版实际审图中出现的横向砖缝密度和对比。
- `cave-dualgrid.png` 保持现有 8 材料 × 16 mask × 4 变体与 512×1024 文件合同；每张 32×32 Unity Sprite 由原生 8×8 最近邻放大 4×，不改 `.meta`、GUID、Sprite 名或 PPU。
- shader 从旧的 64 px／世界格高频采样收敛到 8 px／世界格。后续取消 `25 px` 处直接切入黑岩芯，改为 2／10／23／36 px 的有界加权衰减；默认边缘线降低亮度与对比，最深岩芯仍接近黑色。
- 光场由原来的四邻域曼哈顿传播改为带对角代价的八邻域传播，保留岩体快速吸光和 Bilinear 采样；灯光柔度、空气衰减、岩体损耗均可即时调整。这里没有加全屏模糊，仍保持像素轮廓。
- 八种地形只保留克制色相偏移；坡形仍由权威 `GridCell.Flags` 和既有 `solid()` 公式裁切，视觉纹理不定义碰撞。
- 重建器先核对旧输出哈希，拒绝覆盖人工改图；`--validate-only` 可检查尺寸、原生像素块及 DualGrid 共边。
- 初次审图确认人物不是被本分支缩小、地图也未放大；旧换算让 12 px 人物只有 0.75 格高，低于 22／16＝1.375 格的权威碰撞体。工作台现按 8 px／格显示为 1.5 格高；正式远征人物使用同一 2× 美术比例，旧营地仍为 1×。只缩放 `Facing` 美术及手持物，不移动实体根、阴影或碰撞。

## 验证

| 范围 | 结果 |
|---|---|
| 素材重建 | `cave-rock.png` 256×256、6 色；`cave-dualgrid.png` 512×1024 |
| 像素合同 | 32,768 个 4×4 最近邻块一致；1,024 个兼容边像素一致 |
| ArchitectureGuard | 418 个源码文件、12 个自测、0 错误 |
| Unity 编译 | `6000.4.9f1`，最终 `recompile_status` 为 completed／failed=false |
| 紧凑生成 | 3/3；含 100 种子确定性、连通、掩埋通路、尺度上限及紧凑／宽松预设 |
| 洞穴与角色 | 洞穴坡形／材质 6/6、工作台角色 2/2 |
| 正式远征受影响回归 | 8/8；含 100 个紧凑种子、独立矿床、坡形、有限燃料起始路线、存档和网络投影 |
| 实际 Play | 默认 `CAVE-EXPLORATION-01` 正常就绪；最终全景与近景重新捕获，紧凑拓扑、岩壁渐隐及冷暖光可见 |

首次实际 Play 使用较细的六段深度采样时发生一次 30 秒可见页超时，失败证据没有计作通过。随后将 shader 收敛为固定成本三段采样，受影响阶段重跑通过；这只说明当前默认样板可正常进入和捕获，不构成前台帧时或完整性能签署。

最终截图位于 `artifacts/cave-8x8-style/overview.png` 与 `near.png`。审图结论是：地图主体已从横跨大部分 320×192 边界收拢到中部三层洞网；岩壁不再在固定深度硬切为黑色，暖灯／矿光也不再使用明显的四向菱形传播。人物保持 1.5 格高。仍可在 F1 中继续按实际游戏镜头微调边缘亮度、衰减距离与灯光半径，并补正式远征中的设备、飞船和 HUD 同屏复核。

## 边界

- 改动的是确定性生成规则与洞穴样式资产，没有生成新 PNG、没有改 Prefab，也没有改其它人工场景内容。
- 没有重跑 Mono、联机、弱网或 Player 性能；正式远征只跑了受影响的 8 项 Editor 回归，历史结果不回填为本批结论。
- 没有构建 IL2CPP，没有修改 YYGC、包锁、ProjectSettings、规则数值、协议或存档。
- 当前提交保留截图和原始运行日志在忽略的 `artifacts/` 目录，仓库只提交源码、派生素材、manifest、测试和证据摘要。
