## 实现范围与设计差异

- 初始太空使用显式空载体地图复用 AMP1 生命周期：只有底边基岩，没有矿床；它不是一颗可探索星球。
- 星球沿用 `320×192` 格、每格 16 权威单位，在天然洞穴上生成开放天空、地表、受保护平台及下洞步道；表现继续使用 StrataCave。
- 每个预设只有一个降落点，暂不支持任意地形落地、多点择地、战略地图或返回太空。
- 船壳、驾驶台和坡道仍使用已有 `ShipGeometry`；速度、加速度、门时钟及着陆规则读取 balance。有人驾驶松手缓降、无人驾驶悬停、安全接地自动着陆并释放驾驶席，随后按配置开门。
- UI Toolkit 单面板已完成源码导入、草稿/配置/预览、真实域重载和主要操作/绑定检查；仍需补全未执行的原生交互与视觉组合。预览通过不代表任意生成地图的完整玩法通过。
- 新脚本及生成注册已由 Local Unity 导入并完成 Mono 编译。原生资源/GUID 的最终整体核对见下列未完成项，没有手工编造 GUID。
