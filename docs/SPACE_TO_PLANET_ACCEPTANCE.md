# 太空到星球流程：待执行验收清单

2026-09-26。本清单对应基于主分支 `31aaecf` 的 `ft-20260926-space-planet-flow` 开发批次，设计来源为 [流程设计](SPACE_TO_PLANET_FLOW_DESIGN.md)。

**用户明确允许本批不执行验证和验收，只列出验收项。以下所有项目均未执行，全部保持未勾选。源码实现、源码阅读、已有历史通过数以及检查表本身都不是本批通过证据。** 本批没有启动 Unity、运行测试、构建或启动 Player，也没有进行画面或联机验收。

## 实现范围与设计差异

- 初始太空使用显式的空载体地图复用现有 AMP1 地图生命周期：只有协议要求的底边基岩，没有矿床。它不是一颗可探索星球；舱外和地面玩法仍须由航程阶段关闭。
- 星球地图沿用当前 `320×192` 格、每格 16 权威单位的固定尺寸；在现有天然洞穴上生成开放天空、地表、受保护降落平台及下洞步道。岩壁和洞穴背景继续使用 StrataCave，并非新增一套星球美术。
- 每个星球预设只有一个降落点；可配泊位位置、平台宽度、到达高度及飞行范围。暂不支持任意地形落地、多资源点择地、战略小地图或返航到太空。
- 船壳、驾驶台、船舱地板与坡道仍使用已有 `ShipGeometry`；水平／垂直速度、加速度、舱门时间和着陆容差继续读取既有 balance 规则。单面板配置没有复制这些已有作者数据，也尚未把完整飞船几何迁为独立资产。
- 单面板为 UI Toolkit 原型：正式会话的 `ExpeditionFlowConfig : IConfigData`、星球表格、草稿详情、行操作及纯蓝图预览。预览只展示实际生成的格子布局，不代表正式材质、角色通行或可玩性通过。
- 新源码尚未由 Unity 导入。新增文件／目录的 `.meta`、YYGC／MemoryPack 生成注册以及编辑器实际装配均待后续 Unity 导入与验证；本批没有手工编造 GUID。已有资源引用和 GUID 必须保持。

## 1. 导入、配置与 UI Toolkit 制作面板

- [ ] 使用锁定 Unity `6000.4.9f1`，在唯一授权的 Local 验收通道导入本批源码；记录编辑器、依赖和提交身份。
- [ ] 导入后无新增编译错误；确认新增文件／目录 `.meta` 由 Unity 生成，纳入后续成果记录。
- [ ] 菜单 `Dark Nights/配置/星球与航程` 正常打开；展示实际 `WorldSession.asset`，没有指向同名临时资产。
- [ ] `MultiColumnListView` 正确显示稳定 ID、名称、启用、种子和降落区，选择行后详情对应同一行。
- [ ] 新增、复制、停用／启用、删除、上移／下移只改草稿；复制产生新 ID，排序在重新打开后保持。
- [ ] 字段编辑与各行操作支持 Undo／Redo；选择切换、窗口缩放、关窗／重开不产生串行编辑或残留绑定。
- [ ] 脚本重新编译／域重载保留未应用草稿、原配置基线和正式来源；只有实际关闭窗口才释放草稿对象。
- [ ] 应用只更新当前会话定义中的航程配置，保留手持装备配置、其他能力和人工内容。
- [ ] 缺少配置时仅在显式应用时安装；重复应用不会新增第二份 `ExpeditionFlowConfig`。
- [ ] 取消草稿恢复正式作者配置；关闭含未应用修改的窗口时，保存／放弃行为清晰且不静默覆盖。
- [ ] 其他 Inspector 在草稿期间改动正式配置时，应用拒绝覆盖并保留可处理的错误提示。
- [ ] 运行态禁用制作面板写入；暂停／结束 Play 后编辑状态和订阅恢复正确。
- [ ] 校验空目录、全部停用、重复 ID、空行、非法 ID、过长名称／说明、非法种子及 32 行上限。
- [ ] 校验浮点 NaN／Infinity、负数、到达高度超过最大升高、平台宽度／边界、超时范围及非法颜色／策略。
- [ ] 固定种子预览可复现；空种子预览使用明确的固定预览种子，不消耗游戏随机数。
- [ ] 预览实际调用当前生成器，正确标注平台、到达点、矿床；修改配置使旧预览失效。
- [ ] 预览在后台生成纯数据，主线程发布纹理；15 秒超时、修改、换行、域重载或关窗后取消并丢弃旧结果。
- [ ] 预览不启动网络、不建立运行会话、不改场景、不读写玩家存档；反复生成／关窗释放临时纹理。
- [ ] 启用与停用流程均有明确入口行为；停用后旧地图模式没有因缺少航程配置而失效。

## 2. YYGC 注入、注册和状态生命周期

- [ ] `ExpeditionFlowBehaviour` 通过 `RequireConfig`／注入取得正式共享配置，缺失配置明确失败，不悄悄使用另一份默认运行参数。
- [ ] `ExpeditionJourneyBehaviour` 和 `ExpeditionJourneyState` 注册、生成序列化及对象定义 `BehaviourTypes` 完整。
- [ ] 航程阶段只有 Journey State 一个所有者；船体、驾驶者、舱门和乘员位置仍归现有 Building／Actor State。
- [ ] `ObjectSession` 只组合能力，不保存另一套地图、驾驶席或船员状态；没有逐船员 NetworkTransform 或重复模拟入口。
- [ ] 进入会话后冻结目录；更改编辑器作者配置不能改变已开始会话的参数或指纹。
- [ ] 池化 `OnSpawn`／重用／`OnDespawn` 清空前一会话目录、候选、任务、错误和订阅，不泄漏驾驶权。
- [ ] 后台生成只访问纯冻结输入，不读取 Unity 对象、不跨线程持有池化 State／SessionScope。
- [ ] 取消、超时、离房或销毁后丢弃过时任务结果；取消回调及时结束后续生成阶段，异常得到观察。
- [ ] 相同航程、地图和修订只提交一次；回收后完成的旧任务不能推进新会话。

## 3. 初始太空和船内自由活动

- [ ] 新建正式远征首先处于 `Orbit`，太空环境正确显示，飞船安全悬停，地面远征尚未开始。
- [ ] 独立 Host 与每位客户端都在船内生成自己的合法角色，重复 Ready 不增员。
- [ ] 两至四名船员可同时走遍有效船舱地板和坡面，乘员相互操作不争抢驾驶权。
- [ ] 太空、准备、过场、到达同步和下降阶段均不能步行穿过关闭舱门或跌出船体。
- [ ] 初始空载体地图没有矿床、可用地面经济或可误入的落脚点；底边基岩不出现在正常太空镜头。
- [ ] 船员、船体及设备的相对位置在网络插值和环境平移期间保持，角色不滑出舱内。

## 4. 目的地选择、并发与授权

- [ ] 仅靠近驾驶台的本人角色能够打开有效选择入口；浏览列表不占驾驶席、不生成地图。
- [ ] 星球列表使用会话冻结目录，显示名称／说明与启用状态；停用星球无法通过直接请求绕过。
- [ ] 确认目的地与取得驾驶席在一个权威事务完成；失败时不残留席位、航程或控制租约。
- [ ] 两至四位玩家同帧确认不同目的地，恰好一个成功；其余收到可理解的失败提示。
- [ ] 身份仅来自可信连接；伪造人物 ID、其他玩家的 EntityId、过远交互、死亡角色和未登船角色全部拒绝。
- [ ] Host 使用相同验证入口，一次确认、一次输入只执行一次。
- [ ] 重发 RequestId、乱序序号、旧策略修订、旧航程修订、旧 epoch 和旧控制租约全部按合同拒绝或返回原结果。
- [ ] 只有当前驾驶员可取消尚未提交的准备阶段；取消后释放席位、清零输入并允许再次选择。
- [ ] 选定后其他船员仍可自由走动；未登船合法成员不会被静默丢弃或绕过起航条件。
- [ ] 冻结种子来自服务端；固定种子稳定，随机种子在相同权威恢复路径中不由客户端自行决定。
- [ ] 随机模式的衍生种子有界重试最多 3 个候选（含初次），固定种子仅尝试一次；成功后的实际种子同时进入航程、地图、背景参考和存档，不能仍保存失败的原种子。

## 5. 地图生成、开放天空和真实碰撞

- [ ] 多组固定种子得到完整尺寸、合法材料／坡形／软岩／保护位，底边基岩完整。
- [ ] 降落区以上天空连续开放，最高允许飞行高度加船顶余量不触碰地图顶边。
- [ ] 水平包络包含船体半宽后的最左／最右边界仍在地图有效范围内。
- [ ] 平台覆盖完整船体投影、起落架和坡道出口，不能只保护旧 24 格泊位。
- [ ] 配置边界内不同泊位列、地表行、平台宽度仍能产生可通行下洞路线；无法生成时明确失败并回太空。
- [ ] 下洞步道有足够净高、受控坡度和实际洞室接点；真实角色可往返，不能只凭拓扑连通宣称通过。
- [ ] 地表不是悬空薄片；平台和步道连接到既有岩层，洞穴矿床不存在于开放天空或保护平台内部。
- [ ] 新铺设地表带不继承被覆盖的旧矿床标记；矿床位于最终有效洞穴区域，保护材料不被当作可开采资源。
- [ ] 船体扫掠使用权威坡形；下降、横移、最高速贴近地面与地图边界均不穿透。
- [ ] 背景初始参考在平台、天空和通道全部修改后捕获，前景与背景身份／哈希一致。
- [ ] 天空没有洞穴后壁遮挡；现有 StrataCave 前景、三层背景和光照在地下范围正确展示。
- [ ] 生成取消／异常／超时不会改写当前地图，旧空载体地图和船舱可继续正常使用。

## 6. 过场、到达同步与环境原子切换

- [ ] `star-shift`、`fade`、`none` 三种本地表现策略可配置，星点密度／速度／背景颜色可见生效。
- [ ] 星点动画仅本地推进，不逐帧发送网络状态，也不能自己宣布到达或解锁驾驶。
- [ ] 准备完成后最短过场时间由服务端控制；低帧率、不同本地时钟和不同动画时长不改变航程结果。
- [ ] 慢端保持等待画面，快端不会让其在缺少地图／资源时直接操作；错误和超时提示可见。
- [ ] 安装目标环境原子增加地图／会话身份，船体、乘员和随船设备同事务平移至半空。
- [ ] 切换保留原船员对象和合法人物身份，不使用读档的全量清人语义，不重复发放初始资源。
- [ ] 当前地图、背景参考、实体快照和初始可见页完整后才接受该端 Ready。
- [ ] 提交后单端超时不回滚所有人的世界；飞船保持悬停，慢端可重新同步并加入。
- [ ] 地图已经提交后，单个通知／订阅回调抛异常不会释放当前活动地图、重复提交候选或把全部玩家回滚到旧环境。
- [ ] ArrivalSync 完成后重新签发驾驶租约、清理旧输入；切图前保持的下降键不会自动带入新环境。
- [ ] 到达后关闭浏览／确认旧星球目录入口，阶段和目的地提示与冻结投影一致。

## 7. 手动降落、下船与地面衔接

- [ ] 只有当前驾驶者能施加推力；其他玩家不能通过旧营地命令或直接网络请求移动飞船。
- [ ] A／D 平移、上升、下降、松手制动及悬停遵循既有 balance 规则和当前星球范围。
- [ ] 到达点位于星球半空，留有船壳净空和制动距离，不在地面／岩层内生成。
- [ ] 高速触地不能穿透或误判安全着陆；没有未经设计授权新增的坠毁伤害。
- [ ] 只有指定平台、足够支撑、速度和净空满足条件时接受着陆确认。
- [ ] 着陆事务同时归零速度、对齐泊位、更新航程，并且只启动一次地面探索阶段。
- [ ] 舱门按原规则完成开门后才能下船；坡道出口与平台真实碰撞相接，没有跳变或卡脚。
- [ ] 非默认高平台（较小 DockRow）着陆、出舱、跳跃、下洞及返回船舱时，主角运动高度上限使用当前环境，不能被旧营地的固定上限截断。
- [ ] 船员可下船、返回船内、接近矿床及使用已有地面玩法；机器／设备出舱归队关系完整。
- [ ] 当前不支持的返太空、多点着陆和战略地图入口没有误导性可用按钮。

## 8. 独立进程联机矩阵

以下两组应复用同一个已明确记录身份的 Mono Player，各包含完整五步流程、选择竞争、地形身份、驾驶租约和乘员关系核对。

- [ ] 正常网络：独立 Host＋Client 完整流程；不能用 Host 单窗口替代。
- [ ] 正常网络：独立 Host＋三名客户端，驾驶员分别由房主／来宾担任，各阶段状态一致。
- [ ] 弱网：同一 Player 在 `200 ms RTT + 5% loss + 25 ms jitter` 下完成 Host＋Client 流程。
- [ ] 弱网：同一 Player 在四进程下竞争选星球、过场、切图、手动下降和下船，无重复提交和旧输入回放。
- [ ] 正常／弱网分别记录最终航程阶段、地图 ID／epoch／哈希、驾驶者、船员和设备数量。
- [ ] 模拟可靠消息延迟与重发，背景分块、AMP1 地图、实体快照和 Ready 跨顺序抵达后仍一致。
- [ ] 不同配置指纹、协议或地图样式客户端明确拒绝混连，不以黑屏／无限等待代替错误。

## 9. 晚加入、断线、策略和暂停

- [ ] 在 Orbit、Preparing、Transit、ArrivalSync、Descent 和 Landed 分别晚加入，取得当前真实环境和合法出生位置。
- [ ] 非驾驶员断线后不阻塞全部航程；重连保持项目既有“重新接入角色”的规则，不复活旧驾驶租约。
- [ ] 准备／过场提交前驾驶员断线，航程取消或按实现的明确策略处理，候选不再提交。
- [ ] 到达／下降阶段驾驶员断线，立即清零推力、安全悬停并撤销租约，其他合法船员能够接管。
- [ ] 房主退出时客户端退出当前会话并得到明确提示，不宣称支持房主迁移。
- [ ] SharedCamp／HostOnly 切换按可信权限拒绝旧请求；关闭共享时不会保留来宾驾驶输入。
- [ ] 暂停不停止网络、心跳、重连和 UI；阶段计时、到达超时与暂停策略没有永久等待或偷偷驾驶。
- [ ] 非驾驶员打开菜单或选择面板不影响他人操作；输入焦点、交互会话和主角控制互斥正确。

## 10. 稳定阶段存档、恢复与错误边界

- [ ] Orbit、Descent、Landed 分别保存，实际退出进程后重启读取，恢复环境、船位、成员、货物和阶段。
- [ ] Preparing、Transit、ArrivalSync 按本批稳定阶段策略明确拒绝保存，拒绝不覆盖已有成功存档。
- [ ] 空载体地图存档有合法底边且无矿床；恢复后仍是太空船舱，不能被误认为已降落星球。
- [ ] 下降中存档恢复后悬停、安全清理网络控制身份；客户端不能沿用上次进程的驾驶租约。
- [ ] 星球 ID、地图 ID、种子、航程阶段、指纹、泊位和飞行包络交叉校验，非法组合原子拒绝。
- [ ] 正式配置与存档冻结目录／指纹不一致时明确拒绝或按当前约定处理，不静默替换星球参数。
- [ ] 非有限数、非法枚举、重复 ID、丢失字段、超长字段、错误背景哈希和损坏数据均有可诊断错误。
- [ ] 旧版本协议／存档按本批版本边界拒绝；不自动覆盖或删除用户旧存档。
- [ ] 保存采用原子文件替换；失败时旧成功存档可用，载入失败不部分改变当前世界。
- [ ] 正常／弱网分别执行已着陆后的开采保存与重启恢复，确认新航程合同没有破坏现有最终格子恢复。

- [ ] 原飞船、角色、设备、场景、材质与 UI 人工资源保存／重开后引用不丢失，已有 GUID 无意外变化。
- [ ] 新界面原型在真实 16:9、较小窗口和高 DPI 下可读，文字、按钮、选择列表及等待提示不遮挡关键操控。
- [ ] 编辑态场景仍能看到原生布局，运行时没有用空场景加全局生成替代人工资产。
