## 正式组合画面阻塞

单矿层 P0 小样通过不能替代正式背景组合。追加同一机位的真实 Player 采集前后比较，2748 个变化像素都来自人物挥镐姿态，人物区域之外矿格耗尽没有画面变化。追加无人物、同一正式地图的组合检查：全部矿占用改变395个像素，但最大颜色差仅5，目标格中心无变化。原“像素有差异”的断言过弱，因此该结果**不计正式呈现通过**。

背景近／中／深层具有不透明或高 Alpha 区域，当前矿排序 −88 至 −85 被盖住；前景修饰轮廓也需要一起复核。新增 `MineralCompositeTests` 加入 >20 的颜色差门槛及 −78／−68／−58 的排序诊断，用真实相机比较各候选。下一步优先检查“中景后壁与近景点缀之间”，同时保持原生矿层、冻结占用和素材；不能用抬到前景之上、隐藏背景或改碰撞来伪造通过。
