# Dark Nights当前操作指南

本页只描述正式地面玩法。完整开放／暂停边界见[基础范围](GROUND_GAMEPLAY_BASELINE.md)，当前版本和验证限制见[执行状态](DEVELOPMENT.md)。当前候选包含固定船舱普通交货循环，首张仍从地面开局；旧营地工具栏及旧Player目录不作为当前试玩步骤。

## 开始与合作

正式Editor入口为 `Game/Assets/Scenes/Bootstrap.unity`。UITK主菜单保留DARK NIGHTS名称与既有按钮位置；“开始远征”进入标题为“开始游戏”的设置页，横向选择仅自己／局域网／好友邀请。联机显示预填房间名和可选加入密码，仅自己隐藏房间字段；页面不显示存档、地图选择及常规模式说明。确认“开始远征”后直接启动游戏，菜单会话新建角色在现有飞船舱内会合，不再进入独立队伍大厅或要求队员点击准备。新局在后台选第一个空槽，不覆盖已有文件；十槽全部占用时明确阻止新局并提示整理存档。“继续远征”读取当前版本目录中最后修改的存档，仍经过原加载流程。玩法与操作位于设置内，返回使用无框箭头文字入口，主页面不保留底部工具栏。

其他玩家在“加入游戏→局域网”查看可加入房间，滚动紧凑列表，锁图标表示需要密码，人数和Ping在右侧；无可用测量时Ping为“—”。列表仅公开游戏会话已就绪且有空位的房间，不增加进行中状态分类；满员或关闭后缓存行最多保留7秒，实际加入仍由房主复核。也可输入房主IPv4地址直连。输入密码后显示真实加入／连接／同步等待，可取消；密码错误保留重输入口，连接失败显示原因。LAN发现与准入使用UDP27778，正式游戏使用UDP27777，最多四人；各端使用同一源码／内容构建，协议或摘要不符拒绝。首次完整Ready后创建专属主角，菜单房间新角色在现有船舱出生；保存的角色恢复原位置，非菜单快速测试和既有开发入口保持原出生策略。

好友房间／邀请入口不需要选择Steam或其他平台，平台来源由启动方式确定；当前服务尚未接入时界面明确提示，可改用局域网。界面提供入口不代表Steam邀请已经可用。

单人也走Host权威入口。默认SharedCamp；房主切HostOnly时来宾保留观察、镜头和帮助，业务修改／角色控制按策略撤销。菜单只锁本地输入；暂停由房主控制，心跳／连接／UI继续。

Player运行须保留完整同目录Data、UnityPlayer和Addressables内容。当前新照明后端没有完整独立Player验收结论，使用的实际产物身份先核对执行状态，不拿旧构建测试新增功能。

## 主角、装备与采集

下表为默认键位，可在已有帮助／改键界面查看和恢复实际绑定。

| 操作 | 行为 |
| --- | --- |
| A／D | 地面即时启停；空中保留起跳惯性，按方向有限修正落点；朝向立即跟随按键，镜头跟随 |
| 空格／Shift | 基础起跳／冲刺；喷气背包暂退，长按跳跃不再衔接喷气 |
| S | 下穿当前单向平台，不穿普通地面 |
| 1–4 | 切换实际四格手持库存，滚轮不切背包 |
| B | 打开／关闭背包，查看四格装备、个人铁／金及共享信用点；可改键，Esc也可关闭 |
| 左键／按住 | 当前工具使用；矿镐持续挥舞、枪射击、已有炸药蓄力投掷，船内手持攻击禁止 |
| F | 开关实际持有手电；换矿镐／枪后照明继续 |
| E | 按当前位置提示与船内交货口、商店、导航台交互 |
| F1／F10 | 开发会话Debug Hub／有界Smart Console日志 |
| P | 房主暂停／恢复；菜单仍可进行受支持的会话控制及存取档 |

四格库存包含手电，其新角色配发占一格。喷气背包暂退，商店和房主调试不能添加；已有存档保留其数据，但正式运行不启用喷气或回复燃料。移除手电关闭并清引用，加载不重新配发已移除手电。炸药和手电未新增正式商店商品；已有获取／房主调试入口不表示有新价格、拾取或掉落系统。

原地起跳后按方向，默认只能逐渐达到35%正常步速；跑动起跳保留实际水平速度，松键仍滑行，反打先刹停再小幅反向。落地后立即恢复地面启停规则，松键保持最后朝向。作者调参在`Res/Objects/Worker/Worker.asset`的ObjectDefinition→SharedConfigs→“移动”（MovementConfig），Archer／Spearman定义同样配置。每个单位只有一份移动配置：“允许主动跳跃”（CanJump）关闭后仍会下落及落地，“允许空中操控”（EnableAirControl）关闭后仍保留惯性和阻力；四项空控值及目标点到达距离也在此处。编辑后重新创建会话／角色生效，基础balance数值归属见[主角运动合同](ARCHITECTURE.md#主角与输入)。本轮实现及运行待验状态见DEVELOPMENT。

装备矿镐，鼠标指向最近真实可达表面，中心及装备提示显示目标、耐久、距离／遮挡／容量原因。指向墙深处仍先选外层；基岩和Unknown挡住后方。按住左键可连续挥舞，空挥不代表已命中，落镐时失效目标不会改打下一层。具体距离、材料及工具能力由作者Definition决定，配置入口见[工具合同](TOOL_DEFINITION_HARVESTING.md)。

先拆墙再采露出的矿格，拆墙不伤对应矿物或发矿物奖励。达到阈值才进入个人铁／金货袋，最后一份采空后不重复收益；容量不足、超距、遮挡或版本变化可被权威拒绝。回船在交货口按E存矿；满舱未接收部分仍留在个人货袋。入舱不立即换钱，安全撤离后船货和登船者余矿统一换共享信用点；不启动警戒、NPC或物流。

当前源码新增矿巢联合首片：重新开始新局才加载已冻结的新地图，已有存档不自动重生成。壁内背景矿与前景岩壁分离，先挖墙再采矿；矿团不一定伴巢。挖开侧壳后有短暂前兆，幼虫出巢并水平追近，可用矿镐、手枪或已有炸药清理，首版不扣角色HP、无额外掉落，清理状态随本局保存。当前只做侧壁单虫，不代表多方向、伤害或完整地图通行已验；具体候选及未验项见开发台账。

当前默认联合图新增一个人工塌方点：进入U141／V-60附近3×3格区域触发，前兆后避让，落地后用矿镐逐格清障；首片无伤害。配置入口为工作台地图设计工作台的「塌方设计点」，修改后先更新完整联合候选、保存，再冻结用于新局。当前只完成实现、编译及静态空间／资源核对，实际触发、清障、暂停、多人和存档恢复均待人工验收；CL02独立场景仍可单独使用。

## 购买与飞船

探索画面仅常驻底部四格装备图标；个人矿物数量收在背包内，空槽不显示大块“空”字。切换装备后短暂显示名称，手电开启时在对应槽位显示小标记。Esc菜单内保留帮助、房主暂停／倍速和原存取档；打开菜单不自动暂停全房间。

沿坡道进入飞船，靠近商店看到实际交互键提示后打开。按实际商品价格购买，余额和持有区由权威回执更新；满槽／重复／余额不足会拒绝。商店打开时阻断人物输入，关闭或Esc后恢复，不在等待中重复支付。

星图仅能在飞船操控室靠近导航台按实际交互键打开，离开操控室自动关闭；不再提供屏幕常驻星图入口。窗口采用Win98式灰色边框和深蓝标题栏，“目的地属性”单独排在边框上方。默认仅登记首个星球，其余星域由迷雾覆盖；按住鼠标拖图、滚轮缩放或“本船位置／原始比例”仅改变个人视图，不会清雾。星体下拉目录只列出已经发现的对象，不显示总数。

在迷雾中单击，或使用“指定坐标...”输入正负4096范围内的X／Y，先选择个人航点，再在导航台按“开始航行”向全队提交。Host沿实际船位清除周围迷雾，经过的区域持续保留；坐标抵达后在太空待命，不自动降落或出售货物。已发现星体可查看预计航程和危险示意资料；仅灰松谷可正式降落，其余现有示意节点仍未开放，星球最终数量未定。SharedCamp／HostOnly、登船和当前阶段的操作限制保持原约定。

在导航台选择“召集全员并撤离”，全员入舱后短倒计时自动升空；有人离船则停止，可在导航台取消。船外离线或倒地人员不自动抛弃。脱离矿区后自动回收并显示收入，再选择目的地；航途中可购买装备、在导航台改道或取消目标。地图和乘员Ready后自动降落，坡道展开即可下船；再次落地是新远征，装备与余额保留。手动驾驶按钮已退场。

F1物体页允许已授权房主在开发会话开启上帝模式后添加／移除开放装备及明确投射物；普通Client或非开发构建不能借SharedCamp取得该权限。暂停／受保护对象只读展示，不能据此恢复旧玩法。

## 日志与照明检查

F10查看消息、拒绝原因及真实运行错误。有界显示及中文回退已接入，原OOM事故保留；不要重新开启插件无界应用日志订阅或人为重现日志风暴。检查本机余量及运行保护见[CLI内存门控](UNITY_CLI_WORKFLOW.md#内存门控)。

手电调参／后端切换在Editor的 `Dark Nights → 工作台 → 运行诊断 → 手电光照调试`；地图更换保留本地调参，视觉参数不写玩法存档。PrivateField和Urp2D能力不同，墙内补光／反射等私有控制不用于URP效果判定。当前待验及人工检查见[照明合同](LIGHTING.md#人工检查)。

## 保存与恢复

房主在暂停菜单选择0–9槽位，保存／读取及F5／F9使用该槽位。主菜单新局后台选择空槽，继续选择最后修改的当前版本存档；主菜单不提供切槽，后台选槽不等于自动保存。一次文件任务串行，失败保留当前世界和原文件。读取／重开保持当前房间策略，增加epoch，各端重新Ready并重建控制租约。

正式存储位于Unity Application.persistentDataPath的 `Saves/v28`。当前Windows宿主为 `%USERPROFILE%/AppData/LocalLow/DefaultCompany/DNights/Saves/v28`；只接受当前格式与匹配内容，统一移动配置会改变内容摘要，整合前的文件可能被拒绝。旧文件保留、不自动迁移或删除。精确字段与关系见[存档合同](SAVE_FORMAT.md)。

合法主角姿态、装备／手电、燃料／炸药、个人货袋、飞船及最终两层地图保存；相机、按键、旧连接和租约不恢复。手电临时光场重建；采空矿格不能因重启补回。船货与已结算记录也随世界保存；只有Orbit／Landed稳定阶段可保存，其他阶段先等待。只有合法保存主角可接回，普通闲置人物不冒充恢复对象。

同进程同地址／端口重连使用内存恢复凭据，保留窗口120秒，成功后轮换；关闭程序后再次加入使用新身份。房主退出结束房间，没有房主迁移。晚加入、重连、弱网及当前版本独立进程恢复结果均以执行状态为准。

## 本机人工复测

Win98星图候选待验：新局打开导航应只登记首个星球，标题不压线；拖图／缩放／改选航点不清雾。先正常召集撤离，太空待命后指定例如X70／Y15并确认，沿实际航迹显露、抵达后待命；发现的示意星体进入目录但仍不能降落。取消／改道保留已探索区域，暂停不推进船位与清雾；稳定阶段保存v27并加载／重启后，勘测结果应一致。Host＋Client同时浏览互不抢选中项，实际探索同步一致，晚加入读取当前位图；HostOnly普通Client可查看但不能改道，旧Revision／epoch请求拒绝。本轮编译和资源引用检查不能替代上述操作验收。

先通过当前编译及内存门控，再按影响分短批检查新局Ready、移动／跳跃、商店关闭与购买、矿镐目标／命中、切枪、喷气退场／历史数据休眠、F／F10、飞船、保存读取及断线释放。记录实际源／Player、种子、位置、配置和失败，不以旧日期测试累计当前通过数。

最终坡沿手感、改键、洞室通行和光照可读性单独确认；前台性能仍按用户暂缓边界。开发脚本、构建及独立进程矩阵从[Unity CLI](UNITY_CLI_WORKFLOW.md)进入，独立[LAN Sample](samples/LAN_SAMPLE.md)不代表正式玩法验收。

当前候选的本机快速验收使用同一份Mono Player运行Host＋两个客户端，分别覆盖普通新局和显式交货初值。可重跑入口为 `tools/ship-expedition/test_navigation_network.py` 与 `test_ship_loop.py`，均要求 `--player` 及 `--output-root`；后者明确初始化测试矿物，不代替玩家采矿路线。两者使用D3D11启动参数以控制同机资源占用，正式项目图形设置保持原样；当前结果及Player路径见开发台账和机器回执。
