# Dark Nights当前操作指南

本页只描述正式地面玩法。完整开放／暂停边界见[基础范围](GROUND_GAMEPLAY_BASELINE.md)，当前版本和验证限制见[执行状态](DEVELOPMENT.md)。历史太空开局、出售、旧营地工具栏及旧Player目录不作为当前试玩步骤。

## 开始与合作

正式Editor入口为 `Game/Assets/Scenes/Bootstrap.unity`。主菜单新游戏建立本机Host，Ready后在星球地面、飞船左坡道旁出现专属主角。其他玩家输入房主局域网IPv4地址加入，正式UDP端口27777，最多四人；各端使用同一源码／内容构建，协议或摘要不符拒绝。

单人也走Host权威入口。默认SharedCamp；房主切HostOnly时来宾保留观察、镜头和帮助，业务修改／角色控制按策略撤销。菜单只锁本地输入；暂停由房主控制，心跳／连接／UI继续。

Player运行须保留完整同目录Data、UnityPlayer和Addressables内容。当前新照明后端没有完整独立Player验收结论，使用的实际产物身份先核对执行状态，不拿旧构建测试新增功能。

## 主角、装备与采集

下表为默认键位，可在已有帮助／改键界面查看和恢复实际绑定。

| 操作 | 行为 |
| --- | --- |
| A／D | 左右移动，镜头跟随 |
| 空格／Shift | 起跳／冲刺；购有喷气背包后长按跳跃衔接喷气，落地回复燃料 |
| S | 下穿当前单向平台，不穿普通地面；驾驶飞船时为对应下降输入 |
| 1–4／点击装备格 | 切换实际四格手持库存，滚轮不切背包 |
| 左键／按住 | 当前工具使用；矿镐持续挥舞、枪射击、已有炸药蓄力投掷，船内手持攻击禁止 |
| F | 开关实际持有手电；换矿镐／枪后照明继续 |
| E | 按当前位置提示与船内商店、驾驶台交互 |
| F1／F10 | 开发会话Debug Hub／有界Smart Console日志 |
| P | 房主暂停／恢复；菜单仍可进行受支持的会话控制及存取档 |

四格库存包含手电，其新角色配发占一格。喷气背包是独立能力，购买后装备／充满，不占四格。移除手电关闭并清引用，加载不重新配发已移除手电。炸药和手电未新增正式商店商品；已有获取／房主调试入口不表示有新价格、拾取或掉落系统。

装备矿镐，鼠标指向最近真实可达表面，中心及装备提示显示目标、耐久、距离／遮挡／容量原因。指向墙深处仍先选外层；基岩和Unknown挡住后方。按住左键可连续挥舞，空挥不代表已命中，落镐时失效目标不会改打下一层。具体距离、材料及工具能力由作者Definition决定，配置入口见[工具合同](TOOL_DEFINITION_HARVESTING.md)。

先拆墙再采露出的矿格，拆墙不伤对应矿物或发矿物奖励。达到阈值才进入个人铁／金货袋，最后一份采空后不重复收益；容量不足、超距、遮挡或版本变化可被权威拒绝。当前不出售、不入仓、不增加警戒，也不启动NPC／物流／结算。

## 购买与飞船

沿坡道进入飞船，靠近商店看到E提示后打开。按实际商品价格购买，余额和持有区由权威回执更新；满槽／重复／余额不足会拒绝。商店打开时阻断人物输入，关闭或Esc后恢复，不在等待中重复支付。

靠近驾驶台按E申请／离开唯一驾驶席。开发F1“飞船”页提供驾驶／离座、起飞、降落及取消收舱；起飞要求乘员已在船内，降落验证真实支撑、船壳及坡道空间。安全地面阶段可从坡道登船／下船。当前不走太空目的地选择或完整航程过场。

F1物体页允许已授权房主在开发会话开启上帝模式后添加／移除开放装备及明确投射物；普通Client或非开发构建不能借SharedCamp取得该权限。暂停／受保护对象只读展示，不能据此恢复旧玩法。

## 日志与照明检查

F10查看消息、拒绝原因及真实运行错误。有界显示及中文回退已接入，原OOM事故保留；不要重新开启插件无界应用日志订阅或人为重现日志风暴。检查本机余量及运行保护见[CLI内存门控](UNITY_CLI_WORKFLOW.md#内存门控)。

手电调参／后端切换在Editor的 `Dark Nights → Debug → 手电光照调试`；地图更换保留本地调参，视觉参数不写玩法存档。PrivateField和Urp2D能力不同，墙内补光／反射等私有控制不用于URP效果判定。当前待验及人工检查见[照明合同](LIGHTING.md#人工检查)。

## 保存与恢复

房主在暂停菜单选择0–9槽位，保存／读取及F5／F9使用该槽位；主菜单继续读取所选已有槽位。一次文件任务串行，失败保留当前世界和原文件。读取／重开保持当前房间策略，增加epoch，各端重新Ready并重建控制租约。

正式存储位于Unity Application.persistentDataPath的 `Saves/v23`。当前Windows宿主为 `%USERPROFILE%/AppData/LocalLow/DefaultCompany/DNights/Saves/v23`；只接受当前格式，旧Godot／Unity文件保留但拒绝、不迁移。精确字段与关系见[存档合同](SAVE_FORMAT.md)。

合法主角姿态、装备／手电、燃料／炸药、个人货袋、飞船及最终两层地图保存；相机、按键、旧连接和租约不恢复。手电临时光场重建；采空矿格不能因重启补回。只有合法保存主角可接回，普通闲置人物不冒充恢复对象。

同进程同地址／端口重连使用内存恢复凭据，保留窗口120秒，成功后轮换；关闭程序后再次加入使用新身份。房主退出结束房间，没有房主迁移。晚加入、重连、弱网及当前v23独立进程恢复结果均以执行状态为准。

## 本机人工复测

先通过当前编译及内存门控，再按影响分短批检查新局Ready、移动／跳跃、商店关闭与购买、矿镐目标／命中、切枪、喷气、F／F10、飞船、保存读取及断线释放。记录实际源／Player、种子、位置、配置和失败，不以旧日期测试累计当前通过数。

最终坡沿手感、改键、洞室通行和光照可读性单独确认；前台性能仍按用户暂缓边界。开发脚本、构建及独立进程矩阵从[Unity CLI](UNITY_CLI_WORKFLOW.md)进入，独立[LAN Sample](samples/LAN_SAMPLE.md)不代表正式玩法验收。
