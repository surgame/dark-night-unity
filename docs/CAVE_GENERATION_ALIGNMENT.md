# 洞穴生成统一与通路阻断退出

2026-09-29，分支 `fix-20260929-single-cave-generation`。2026-09-30 按正式地图进一步统一：Tuner、ReferenceChamber、RandomCave 与 Bootstrap 的新航程均以 `WorldSession.asset` 中的洞穴生成配置、星球和种子为输入，调用完整星球生成入口。本次按用户要求不运行测试、Unity 编译或构建。

## 当前行为与入口

- 正式航程、无航程远征、ReferenceChamber、RandomCave、星球配置蓝图预览和 Tuner，均调用 `PlanetTerrainGenerator.GenerateCandidate`。天空、保护泊位、下洞步道、坡形与初始背景参考在同一流水线内完成；重试规则也在此收敛。
- `CaveExplorationGenerator` 是流水线的天然空间阶段。旧 `Cover` 塌方回填以及 `CaveRoomCarving.Shelves` 通道岩棚均已移除，所有生成连接为 `Open`，不再产生 LooseFill、ThinRock、DeepRock。旧远征入口只转发，不再单独改写矿床、泊位和步道。
- **这项实验原来没有 Inspector 开关，而是代码写死。本次彻底移除，不保留可重新启用的参数。** 打开 `Dark Nights / Terrain / Cave Wall Tuner`，顶部可见“通路阻断实验已移除”；RandomCave 运行时“地图”页也显示此状态。
- Tuner 只显示正式星球生成预览；两个当前工作台场景也从同一正式配置读取参数。原固定格子选择和“应用固定地图”入口已移除。岩壁、背景、点缀和修饰器草稿、Apply/Cancel、临时拆填、撤销/重做、网格、平移缩放仍可使用。
- Tuner 在默认正式预览中可选择正式星球、输入复现种子和调整地表起伏。“保存正式生成配置”写回 `WorldSession.asset → ExpeditionFlowConfig.CaveMap`，并检测外部修改冲突。需要 Bootstrap 生成同一张图时，先点“将预览种子设为此星球固定种子”，再保存配置；随机种子模式仍会产生不同布局。
- 拆填只修改当前预览草稿，可以撤销或取消，不会把某局格子当成生成参数保存。工作台的“保存生成参数到正式配置”写入共用 CaveMap；样式资产仍由原 Apply/Cancel 和显式保存流程管理。
- 原 `ReferenceChamber.asset` 与 `.cells.bytes` 保留为历史人工资料，但当前 Tuner、工作台和正式航程均不读取它们。已有航程和存档不会自动重生，必须新生成地图。协议仍为 17，存档仍为 v13；生成行为版本进入航程配置指纹。
