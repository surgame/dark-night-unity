## 当前行为与入口

- 正式航程、无航程远征、RandomCave、星球配置蓝图预览、Tuner 的正式生成预览，均调用 `PlanetTerrainGenerator.GenerateCandidate`。天空、保护泊位、下洞步道、坡形与初始背景参考在同一流水线内完成；重试规则也在此收敛。
- `CaveExplorationGenerator` 是流水线的天然空间阶段。旧 `Cover` 塌方回填以及 `CaveRoomCarving.Shelves` 通道岩棚均已移除，所有生成连接为 `Open`，不再产生 LooseFill、ThinRock、DeepRock。旧远征入口只转发，不再单独改写矿床、泊位和步道。
- **这项实验原来没有 Inspector 开关，而是代码写死。本次彻底移除，不保留可重新启用的参数。** 打开 `Dark Nights / Terrain / Cave Wall Tuner`，顶部可见“通路阻断实验已移除”；RandomCave 运行时“地图”页也显示此状态。
- Tuner 默认仍为原 `ReferenceChamber` 固定样板。岩壁、背景、点缀和修饰器草稿、Apply/Cancel、拆填、撤销/重做、网格、平移缩放及固定地图保存保留。人工源图、Style 资产和固定地图格子文件未被生成器覆盖。
- Tuner 点击“切换到正式星球生成预览”后，可选择正式星球、输入复现种子和调整地表起伏。“保存正式生成配置”写回 `WorldSession.asset → ExpeditionFlowConfig.CaveMap`，并检测外部修改冲突。需要 Bootstrap 生成同一张图时，先点“将预览种子设为此星球固定种子”，再保存配置；随机种子模式仍会产生不同布局。
- 正式生成预览中的拆填仅是临时草稿，可以撤销或取消，不会覆写固定样板或把某局格子当成生成参数保存。RandomCave 的“保存生成参数到正式配置”同样写入共用 CaveMap。
- 固定样板是读取人工格子，不是另一套生成算法。已经生成的航程、已有存档和固定样板中的旧岩石不会自动消失；必须新生成地图。协议仍为 17，存档仍为 v13；生成行为版本进入航程配置指纹，旧客户端不能把旧规则视为相同内容。

## 人工测试清单

1. **确认旧 Tuner 功能保留。** 退出 Play，打开上述菜单，确认默认为 ReferenceChamber。测试缩放、拖动画布、网格、拆格、填格、撤销/重做和取消；调整一项岩壁或背景参数后 Cancel，确认恢复。需要确认 Apply 时使用可恢复的小改动，随后恢复原值并再次 Apply。
2. **检查关闭状态。** Tuner 顶部应显示“通路阻断实验已移除”。切换正式星球预览，选灰松星，输入 `STRATA-0922` 等明确种子并重建；观察洞室间连接不再被旧的矩形塌方块或竖井岩棚回填。原固定样板不用于判断新生成算法是否生效。
3. **同种子对照。** 在正式预览点击“将预览种子设为此星球固定种子”，再“保存正式生成配置”。Play Bootstrap，新开房间，走到驾驶台按 E，选择同一星球，等待到达。对照泊位边缘、下洞入口、洞室及分叉的格子布局；正式镜头的缩放和动态光照可不同。测试后在 `Dark Nights / 配置 / 星球与航程` 清空该星球固定种子并应用，可恢复每局随机。
4. **检查工作台复用。** 打开 `Dark Nights / Terrain / 打开新版随机地图 RandomCave` 并 Play；在“地图”页选择相同星球、输入相同种子、点击重新加载地图，应看到同一完整星球地形。改地表起伏后保存正式生成配置，再新开正式航程，检查改动是否出现；记得恢复测试参数。
5. **真实通行。** 从船舱下船，走过平台两端与下洞入口，进入首个洞室；对水平、斜坡、竖井和相邻洞室连接分别走、跳或使用已购买的喷气装备，再返回飞船。重点检查“有可见开口但碰撞挡住”和“入口步道切断下面通道”；记录星球、实际种子、位置及画面。
6. **换种子与恢复。** 再换 2–3 个种子，重复入口与主要分叉观察。保存后退出并加载，当前格子应原样恢复；加载旧地图不会重新应用本次生成规则。

关闭旧回填不等于所有天然洞穴都适合步行。第 5 项尤其重要，目前不能宣称全洞穴通行通过。
