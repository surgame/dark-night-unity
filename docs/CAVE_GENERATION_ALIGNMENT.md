## 当前行为与入口

- 正式航程、无航程远征、RandomCave、星球配置蓝图预览、Tuner 的正式生成预览，均调用 `PlanetTerrainGenerator.GenerateCandidate`。天空、保护泊位、下洞步道、坡形与初始背景参考在同一流水线内完成；重试规则也在此收敛。
- `CaveExplorationGenerator` 是流水线的天然空间阶段。旧 `Cover` 塌方回填以及 `CaveRoomCarving.Shelves` 通道岩棚均已移除，所有生成连接为 `Open`，不再产生 LooseFill、ThinRock、DeepRock。旧远征入口只转发，不再单独改写矿床、泊位和步道。
- **这项实验原来没有 Inspector 开关，而是代码写死。本次彻底移除，不保留可重新启用的参数。** 打开 `Dark Nights / Terrain / Cave Wall Tuner`，顶部可见“通路阻断实验已移除”；RandomCave 运行时“地图”页也显示此状态。
- Tuner 默认显示正式星球生成预览，与 Bootstrap 的新航程使用同一生成器；不同种子仍会产生不同地图。点击“打开人工固定样板 ReferenceChamber”可编辑原固定格子，点击“返回正式星球生成预览”切回。岩壁、背景、点缀和修饰器草稿、Apply/Cancel、拆填、撤销/重做、网格、平移缩放及固定地图保存保留。人工源图、Style 资产和固定地图格子文件未被生成器覆盖。
- Tuner 在默认正式预览中可选择正式星球、输入复现种子和调整地表起伏。“保存正式生成配置”写回 `WorldSession.asset → ExpeditionFlowConfig.CaveMap`，并检测外部修改冲突。需要 Bootstrap 生成同一张图时，先点“将预览种子设为此星球固定种子”，再保存配置；随机种子模式仍会产生不同布局。
- 正式生成预览中的拆填仅是临时草稿，可以撤销或取消，不会覆写固定样板或把某局格子当成生成参数保存。RandomCave 的“保存生成参数到正式配置”同样写入共用 CaveMap。
- 固定样板是读取人工格子，不是另一套生成算法。已经生成的航程、已有存档和固定样板中的旧岩石不会自动消失；必须新生成地图。协议仍为 17，存档仍为 v13；生成行为版本进入航程配置指纹，旧客户端不能把旧规则视为相同内容。
