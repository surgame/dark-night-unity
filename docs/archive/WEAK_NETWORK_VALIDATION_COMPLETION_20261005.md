## 修复与测试口径

- 原生矿层接入后的工作台握手测试必须带当前 `GridBusinessCatalog`；爆破按实际耐久执行多次命中。
- 配置逐字段检查比较 JSON 中的枚举键与当前枚举值，并从原始 JSON 统计字段数；数值仍逐字段核验。
- 按钮动态可交互性在真实 Play 帧检查；后台工作台测试驱动 Unity 自身的延迟队列，仍验证实际配置与 dirty 状态。
- 旧营地生命周期测试打开保留营地关卡，由现有 `ScenePlaySelection` 通过 Bootstrap 装配，继续测试建造、训练、保存和恢复。
- 离屏地形冷装载采用90秒有限等待，热编辑仍20秒；错误和真实 GPU 结果不跳过。局部求解按实际提交的 recipe 计数，保留单格4依赖、64格81依赖及 CPU／GPU 补丁一致性断言。
- 相机回执测试挂接当前独立 `TerrainDrawReceipt`；移除回调时仍必须未 Ready，恢复后必须有真实绘制。
- 显式 GUI 用例由 CLI 向实际 GameView 发送鼠标事件点击启动按钮，验证 Ready、Landed、矿镐及独立存储。点击期限与启动后的 Ready 期限分别有界，没有直接调用启动业务替代按钮。
- 架构守卫区分主类型与嵌套辅助类型，并解析 Editor／Development 条件代码；嵌套类型仍检查中文 XML summary。输入绑定名称枚举拆到 `GameInputBindingCatalog`，动作、绑定 ID、默认键位和输入行为不变。
