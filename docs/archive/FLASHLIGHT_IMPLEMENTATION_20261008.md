## 已实现

- `item.flashlight` 为正式本地 YYGC 工具 Definition，使用 PrefabRef／Addressables、生成注入、`FlashlightToolBehaviour` 与唯一 `FlashlightView`。初始可控角色配发独立挂载手电；矿镐、手枪、炸药及喷气背包入口和原参数保留。
- 手电身份与开关归 `ActorState`；`HeroLightBehaviour` 只编辑所属角色。默认 F 开关，通过原 GameInputActions／改键／Interaction Sessions 接入。请求使用目标开关值、角色 ID、控制租约和原会话序号，沿用可信连接、epoch、策略和去重门禁。
- 照明方向与攻击方向独立，仍通过原主角输入流发送；矿镐冻结挥击意图不冻结手电。客户端自行计算光照，不同步纹理或阴影。死亡、登船隐藏照明及退场不留下幽灵工具。
- 环境底光、定向直射、近身散光、有限墙面反射分开处理。近身散光从身体附近发出；手电灯口贴墙时沿挂点至灯口的真实坡形几何限制有效发光位置。
- 当前游戏相机生成 384×216 的局部线性照明及入射方向缓存，最多 16 个可见光源，接入手电和既有供电设备。转向只更新 GPU 批次；地形修改和换区才重算有界几何缓存。
- 前景、背景、原生矿层和 Camp Sprite 共用受光函数。作者色与环境光分开，避免角色、衣着与手持装备重复乘环境色。屏幕 HUD 保留正常显示；现有世界交互提示的可读性仍需人工评估。
- 空气中的柔影采用有限光源采样，墙内补光独立限深、限强；接收材质按几何分隔插值，再限制墙内补光。未知格及加载范围外保持遮挡。此为有约束的艺术照明，有限反射不等于真实全局光照。

## 异步与生命周期

资源预加载复用 `ObjectSessionResources.Prepare` 和 `StartupResourceBatch`，在事务外 await，资源就绪后同步装配与激活；不让 SessionScope、池状态或 Unity 对象跨线程。

距离任务读取独占局部格副本，后台只执行 Core 纯算法。View 通过 Entry 注入计算入口，不直接依赖业务 Logic。每个缓存只有一个执行中的任务；完成时核对源实例、区域和地形修订，过期结果丢弃。地图绑定退休立即取消，等待任务退出后释放纹理。Unity 上传与 GPU 提交都在主线程，不逐帧回读 GPU。

TerrainPreview 的退场改为可跟踪 Task，并在 await 前冻结旧矿层、旧源和旧控制器引用，避免迟到清理释放后来安装的源。保留原局部加载修复。

存档只保存手电身份和开关；照明方向由朝向恢复，光场、调试参数和后台缓存重建。v21 不作为 v22 兼容输入；旧文件不自动删除。

## 调试与资产

进入正式 Bootstrap Play 并创建本机房间后，打开 `Dark Nights → Debug → 手电光照调试`。

可独立调整：环境底光、硬／柔遮挡、阴影柔度、光束边缘、墙内最大深度、墙内补光上限、近身散光、有限反射、岩壁受光层次、距离／角度／强度。窗口仅调整本机当前表现，不写装备、存档或作者资产。墙内深度以格计：**1 格 = 8 原生岩壁像素**；0 表示关闭墙内动态补光。

手电配置在 `Game/Assets/DarkNights/Res/Objects/Flashlight/Flashlight.asset`。挂点保存于 Worker、Spearman、Archer 的原 Prefab，保留其 GUID 和动画。新增 F 动作保留原动作及绑定身份。

素材采用确定性像素绘制：原生 **6×3** 像素小型金属手电外观，透明边缘／灯口可控，100 PPU，Point、无 mipmap、无压缩；随主角既有整数比例显示。无需 AI 生图。生成来源为显式 `FlashlightContentSetup`，普通开局／构建不重建作者资产。
