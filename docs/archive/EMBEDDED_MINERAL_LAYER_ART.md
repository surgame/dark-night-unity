# 内嵌矿首版素材合同

2026-10-04 开发批次。目标为原生 8×8 像素／格的独立矿层，每矿种 16 个四角掩码、4 个变体；图集为 128×32。复用 `experiments/ore-dualgrid-v1/atlases/*-merged.png`，复制到新的 Unity 原生资源目录，保留源字节与来源，不覆盖现有素材。

本批不需要生图：已有候选满足尺寸和风格输入要求，四角共边、透明退让和斜对角断开需要确定性规则及真实 GPU 检查。透明填充为确定生成的 8×8 全透明图；矿图使用最近邻、无 mipmap、无压缩、Linear 项目中的 sRGB 纹理解码。原生 Sprite 与所有 GUID/meta 由 Unity 导入和 AssetDatabase 创建。

规则采用各矿种的 `This/AnyKnown` 四角条件、掩码位数优先级、`ore` 通道和 `TerrainSurface` 覆盖；填充必须透明。异矿只绘制各自裁剪区域与普通外缘，不增加矿种对的专属过渡素材。真实裁剪是否保留外缘由 P0 相机图验证，纯编译通过不能代替画面验收。

铁、金用于后续正式业务；铜、银、钻石只参与五矿边界样板。样板须检查两种世界缩放、同矿直连、斜对角、异矿直连、内部空洞及耗尽为空格。背景/点缀正式排序、共享光场、实际镜头和局域网验收另行记录。
