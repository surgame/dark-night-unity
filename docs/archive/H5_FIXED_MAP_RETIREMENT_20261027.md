# 旧H5固定底图分支退场

2026-10-27用户授权退出旧固定底图规则，改为同一地图配方的固定／随机／种子池策略。本页保留退场前合同，不再作为当前操作或生成能力说明。

退场范围为五份H5 06～10底图、专用Core数据／雕刻／生成器、Unity资源类型和导入器、专用MineMapTests及重建脚本。32个文件连同meta按原相对路径保全到`../../artifacts/待清理/20261027-旧H5底图规则退场/`，精确原／目标绝对路径、字节和SHA-256见该处清单与manifest；没有永久删除。原H5来源、预制地图、已复制到场景的局部内容、冻结证据及用户存档保持。

手电预览和照明基准转为读取当前规则预制地图；旧基准结果仍只适用于旧输入，不能将替换输入后的结果与旧身份混称。原固定策略的来源摘要保持，非默认种子策略进入新的制作身份；协议与世界存档格式不因制作策略增加而变化。

## 退场前合同原文

### 作者关卡矿洞

`Res/Terrain/MineMaps/*.minemap`是旧H5固定底图与声明扩展的制作输入，每图一份JSON，原生导入为`MineMapAsset`；“唯一输入”仅适用于这条固定底图分支，不覆盖当前规则生成与独立地图文档。现有工作台可通过导入资源读取，另存新地图配置，不覆盖来源。新增同合同文件即可导入，无需修改角色、手电或网络注册。

当前五图来源为 H5 06–10 的132×78格，逐行嵌入264×156格矿洞，通过新增洞庭、分岔及回程扩展。2026-10-26用户要求移除固定步道与挡路墙：三份cave模板的基础通路改用自然曲廊，不再按脚底逐列削台阶，取消步行附加支撑、SealX封岩和sealedTop井口盖板；当批两份natural模板的基础洞形保持，后续入口特例退场见下文。扩展连接同样复用CaveRuleGeometry曲廊，不再补支撑或执行SealX。只移除这一批人为固定结构，规则模式的天然封岩比例、洞室／连接骨架及保护边界保持。

该输入保存的是具体底图格子`BaseRuns`、显式`Rooms／Paths／Shafts`及基线接缝约束；其意义是复用旧地图的具体几何，不是以另一套机制实现固定种子。相同规则、种子及生成实现可复现规则结果，但种子本身不能表达任意外部底图或生成后人工修改。现有`MineMapDefinition`将132×78基线与264×156扩展作为硬约束，不能据此宣称已有任意尺寸底图或任意局部锁定的通用混合生成系统。固定种子、随机种子及候选种子池属于规则输入的选择策略，设计上不依赖该底图分支；种子池等策略的实际接入须另核对实现，不因本说明认定已完成。旧底图的保留不要求在日常规则制作界面赋予其同等地位，也不授权删除原文件、测试或导入路径。

重建入口为`node tools/mine-map/remove-fixed-routes.cjs`，默认只核对；`--write`才更新五份minemap，可加`--report <json路径>`记录变化。脚本读取原H5来源但不改写，先核对全部输入，再批量输出；拒绝覆盖配方外的基础栅格编辑。SourceHash继续表示历史来源，修改后的BaseRuns、矿物坐标及完整输入仍进入既有内容指纹。原输入与逐格变更、源码身份保存在本片证据目录；不修改旧地图结果或玩家存档。

Unity保持16像素格；矿洞局部偏移(40,32)，正式地图仍为320×192。基线材料0／1／2分别转换为空格／slate／带软岩标记的slate。矿簇Id、矿种、容量及数量保持；因曲廊改形失去覆盖的锚点，在原位置8格半径内就近投射到有效岩层，逐项记录，不能新增储量、把空气补成挡路墙或取消矿袋校验。正式挖掘权限与矿层分配沿用现行规则，不复制H5的手感或基岩开采规则。

`ExpeditionFlowConfig.MineMap` 是作者资源引用；冻结后的纯 `MineMapDefinition` 仅作为一次后台生成输入，不序列化到共用设置，不拥有运行世界。内容指纹及预览重建身份包含完整冻结数据，切图或改通路会重新生成。天空、泊位、最终坡形、矿层分配与背景捕获仍使用正式流水线；接缝保护检查先于这些正式阶段执行。新选择只影响新局，已有地图和旧存档不自动重生成。

竖井与高洞使用真实前景结构，没有预搭梯子；搭梯／回收、痕迹观察、隐藏巢穴及 H5 交矿不在此批恢复。相关上下层通行留给后续切片与人工验证，不能以生成或画面完成宣称全程可达。

正式星球与预览复用WorldSession航程／地图配置的完整生成入口；独立预览不装配正式会话、网络或玩家存档。2026-10-26用户要求地图按所选规则直出：附加地形Modifier暂不执行，完整入口也忽略显式传入的旧流水线；配置仍保留类型、顺序、启停和参数供旧来源摘要及无损复制使用，工作台撤下生成步骤编辑入口。明确选择的入口类型、洞室／连接、地表起伏和矿巢配方属于地图规则，飞船实际泊位、边界保护及最终坡形保持；美术前后壁修饰不属于权威格子塑形，不随此项停用。

同批五份作者模板取消固定营地入口特例：cave入口与其他洞室共用普通洞室公式，首条连接从实际洞室中心接出；natural入口恢复该地图自身的地板起伏及洞高规则，不再强制22格平地／浅拱。不再在旧封墙矩形范围额外挖空，只由洞室和曲廊规则决定边界；矿簇完整数据及其他洞室声明保持。制作脚本只在独立VM中撤下H5入口特例，原H5字节不写回，接受原始／上一版制作配方／当前配方输入并拒绝其他基线编辑。天然布局不再额外压平24～47列或填入受保护营地平台；飞船泊位由星球配置唯一决定。连通洞室的入口规则仅在基础生成中执行一次，星球后处理不重复覆盖。

前景完整地图和矿层分别由会话生命周期托管，房主保存有界权威数据。矿床静态元数据不能当作恢复最终状态的蓝图；旧按床实体、逐格对象投影或第二张权威地图不重新接入。保留矿床Prefab／Definition用于配置及来源，不因正式实例退出删除作者内容。
