# Dark Nights｜矿洞远征核心循环最终设计文档

> **文档版本：** v1.0 · 2026-10-13  
> **状态：** 玩法方向确定；时长、概率及伤害等数值均为原型验证建议，不代表最终平衡。  
> **设计对象：** 2D横版像素风、多人合作、异星探索采矿游戏。优先保证地下探索，不扩展独立飞行/复杂飞船DIY。

## 01｜核心定位与确定事项

**一句话定位：** 玩家选择异星矿区并自动降落，在不断升级的时间威胁下，探索随机洞室、应对机关与怪物、采集运输资源，决定何时带着战利品撤离，再用收益强化装备并开始下一次远征。

**设计支柱：**

1. **时间一定会变危险。** 即使什么也不做，局内威胁也持续升级；没有“慢慢挖就永远安全”的解法。
2. **发现驱动探索。** 高价值矿、隐藏洞室、机关和奇遇集中布置，避免长时间机械式挖普通方块。
3. **行动改变风险。** 炸药、钻机、开启遗迹、惊动巢穴会产生额外的即时风险，并可能加速全局危险。
4. **危险能够被学习和利用。** 怪物、机关、物理灾害具有线索、反应窗口及互动结果，追求意外和多人故事，而非随机秒杀。
5. **主动撤离，越久越难。** 没有固定20分钟强制结算；高危阶段通过持续增加撤离代价推动玩家离开，强度设置上限。

**明确不做：** 自由驾驶飞船、长时间舰内活动、像素级自由飞船DIY、常态化站岗守塔、完整永久保存每一局矿区地形。飞船是**交付/补给/撤离节点**，不是第二款游戏。

## 02｜一局游戏与跨局成长

### 2.1 主循环

**星图选择星球/矿区 → 自动降落 → 探索洞室、采矿、遭遇意外 → 运回飞船交付 → 现场补给/更换工具 → 决定继续下矿或撤离 → 轨道结算/购买永久装备 → 选择下一个目的地。**

单局可以反复进行“下矿—交付—再下矿”，但时间威胁持续累积，不因回到飞船清零。

### 2.2 两层结构

| 层级 | 保留什么 | 不保留什么 | 设计目标 |
| --- | --- | --- | --- |
| **长期：星球与角色** | 已解锁星球、行星特征、装备、金币、重要发现记录 | 不要求保存所有矿洞地形变动 | 有跨关卡追求、能重访熟悉星球 |
| **单局：矿区远征** | 当前随机地图、已发现房间、怪物与机关、飞船货舱、即时装备消耗 | 撤离后不默认永久保留该矿区 | 保证短局复玩与低维护成本 |

**默认规则：** 重访同一颗星球可以选择**新的随机矿区**；星球生态和矿产特征保持一致，每次房间布局和事件不同。首版不做“原矿区几天后原样回访”。特殊固定遗迹可留给后续版本。

### 2.3 目标节奏（原型值）

| 项目 | 建议范围 |
| --- | --- |
| 常规远征时长 | 15–25分钟，非硬性倒计时 |
| 人数 | 优先验证2人，架构兼容2–4人 |
| 单局关键发现 | 约3–5处值得探索的洞室或岔路 |
| 有记忆点的特殊遭遇 | 约2–4次；不包括普通小怪 |
| 交付次数 | 约1–3次，视背包与队伍策略决定 |
| 首次可感知装备收益 | 前5–8分钟内完成一次补给或升级 |

## 03｜星球、地图与洞室

### 3.1 星球承担“主题差异”，矿区承担“重复可玩”

每颗星球配置**地形主题、矿产池、怪物池、环境事件池和威胁节奏系数**，而非另做一套规则。初期可规划：

| 星球类型 | 主要吸引力 | 特有危险 | 单局节奏 |
| --- | --- | --- | --- |
| 荒漠矿星 | 常规资源、路线易读 | 落石、砂层塌陷、干燥气穴 | 标准/较宽松 |
| 虫巢矿星 | 高价值矿群、虫巢战利品 | 潜伏生物、声音猎手、巢穴追击 | 短局/高风险 |
| 机械遗迹星 | 稀有组件、特殊设备 | 漏电池、失控设备、警戒机关 | 探索/机关导向 |

首版只实现**一个星球主题**，使用少量房间与事件组合验证结构。

### 3.2 地图生成约束

- 采用**随机房间连接 + 可控局部地形生成**：主通道、岔路、隐藏洞室、矿脉和特殊事件位有结构地生成，而非纯随机散矿。
- **地表降落区相对安全**；浅层可快速取得第一批矿，深处提供更高收益与风险。
- 重要洞室带标签：`普通矿室`、`高收益矿室`、`生态巢穴`、`地质灾害`、`遗迹机关`、`隐藏奖励`；按预算抽取，不把所有高危事件堆在一起。
- 地形**允许受控破坏**：普通矿可采，特定结构岩层需炸药/对应工具。避免任意挖掘导致路线全是碎坑和断崖。
- **撤离路线始终可恢复**：塌方可以堵住捷径，但不能永久封死唯一可行的回船路径；基础工具或替代通道必须可解。
- 地图可以随机，但**不允许不可读**：关键危险给出局部可识别的视觉、声音或震动线索。

## 04｜时间压力与噪声：核心规则

### 4.1 三层危险（不再作为三个玩法模式）

| 危险层 | 变化依据 | 作用 |
| --- | --- | --- |
| **全局时间威胁** | 从降落开始持续增加，不可逆 | 决定刷怪档位、敌种、追击强度与高危事件权重 |
| **行为扰动** | 炸药、钻机、攻击巢穴、强行启动遗迹 | 立刻惊动附近生物，并额外推高全局进程 |
| **局部环境危机** | 进入特定房间、破坏岩层、触发机关 | 构成具体的“惊险瞬间”，可能创造新的机会 |

**原则：** 时间是主轴，噪声是加速器，房间事件是内容；不能通过静默挂机把时间威胁降回安全期。

### 4.2 建议的危险阶段

| 实际游戏时间（无额外扰动） | 阶段 | 体验变化 |
| --- | --- | --- |
| 0–4分钟 | **勘探期** | 基础敌人、弱机关、清晰探索路线；尽早下矿 |
| 4–9分钟 | **活跃期** | 巡逻、伏击概率上升，开始出现复杂环境事件 |
| 9–14分钟 | **警戒期** | 增加特殊敌种、追踪行为，深入开采的返程成本变高 |
| 14–18分钟 | **高危期** | 敌人可持续追击，运输与回程变得紧张 |
| 18分钟后 | **极限期** | 威胁保持高位，持续压迫撤离；不无限提高同屏怪物数量 |

这张表是**用于首版试玩的起始参数**，不是规定玩家必须在18或20分钟撤离。升级后可通过强工具、运输效率与防护能力提升高危阶段的有效收益。

### 4.3 噪声的双重代价

- **即时效果：** 在当前位置产生声音事件；附近猎手转向声源、巢穴活跃、部分脆弱岩层可能被波及。
- **长期效果：** 将一定的“等效时间”加到全局危险进度，例如一次大爆破 +30–45秒；首版可设置**单局累计加速上限**防止过早进入极限期。
- **工具差异：** 手动采矿慢且安静；炸药快但有响声、地形连锁风险；钻机居中，但持续发出声音。噪声与效率是策略，不是禁止玩家使用好工具。

实现上可以抽象为：`危险进度 = 实际经过时间 + 行为附加时间（有上限）`；独立保留“最近噪声位置/强度”用于局部怪物感知。数值可调，不必向玩家展示公式。

### 4.4 反刷怪与公平性

- 难度增加优先表现为**敌种、行为、位置和围追能力变化**，其次才是数量或生命值。
- 每个阶段限制**同屏敌人总量、刷新频率与危险事件预算**；不允许无上限刷怪导致性能和战斗失控。
- 重要事件避免连续重叠：刚塌方或中毒时，不立即在无路可退的位置再触发致命伏击。
- 高威胁可增加**高价值收益入口**，让继续冒险始终有吸引力；不能只增加惩罚。

## 05｜地下意外系统：类型、线索与连锁反应

**目标不是“多做陷阱”，而是少量基础系统能两两组合，形成不可预知但可学习的遭遇。** 建议由一个轻量遭遇调度器控制每局特殊事件预算与冷却，房间本身只负责具体机制。

### 5.1 核心事件清单

| 类别 | 事件 | 提前线索 / 触发 | 有趣的结果 / 玩家应对 | 优先级 |
| --- | --- | --- | --- | --- |
| 地质 | **落石、局部塌方** | 裂纹、掉灰；挖掘/爆炸/踩踏 | 砸怪、堵路、砸开隐藏洞；可避让或开路 | P0 |
| 生物 | **拟态矿虫** | 异常矿纹、轻微蠕动；开采 | 奖励可能变成战斗，也可能掉特殊材料 | P0 |
| 生物 | **伏击虫/虫卵** | 声响、巢穴痕迹；靠近/震动 | 打断采矿、多人救援，可绕开/提前清理 | P0 |
| 气体 | **毒气穴** | 岩缝气泡、颜色变化；破岩 | 毒雾扩散迫使改道，可用面罩/快速穿越 | P1（可提前做） |
| 环境 | **带电积水** | 电弧与嗡鸣；水+电源 | 避电、断电，也能将怪物引入电水 | P1 |
| 生物 | **震动猎手** | 岩壁震动；爆破/钻机 | 高速采矿招来追击，可转移声源 | P1 |
| 生物 | **偷矿兽** | 偷取地面矿石 | 追踪其洞穴，可能找到隐藏库存 | P1 |
| 环境 | **可燃气囊** | 气体光点、火花提示 | 火焰/爆破连锁，能炸开捷径或造成伤害 | P1 |
| 机关 | **失控炮台/矿车** | 电源、警示灯、轨道 | 切断、利用或绕开，反过来击退敌人 | P2 |
| 异星 | **吞光植物/声波晶体** | 闪烁、回声与周期变化 | 改变照明或声音传播，塑造星球独有规则 | P2 |

### 5.2 四个优先验证的事件组合

1. **爆破 → 高价值矿掉落 → 吸引猎手 → 顶岩塌方。** 玩家得到收益，也改变了返程计划。
2. **落石 → 堵住捷径 → 打开隐藏矿室。** 负面事件同时提供新机会。
3. **怪物追击 → 经过带电积水 → 利用电击反杀。** 地图是战斗资源，不只是障碍。
4. **偷矿兽 → 追踪巢穴 → 发现积存矿物 → 撤离时钟继续前进。** 意外自然形成贪心与撤离抉择。

### 5.3 事件调度和可读性规则

- 单局预计出现**2–4次有记忆点的特殊事件**，普通小机关和小怪不计入；由随机预算和冷却控制，不固定写死剧情。
- 致命或高损失的事件必须有**可观察线索与反应窗口**；第一次可能受伤，第二次应当能识别，第三次可以主动利用。
- 基础工具始终提供至少一种解法；高级装备提高效率和容错，而非制造早期必死锁。
- 优先用**击退、困住、失明、丢失矿石、路线改变**制造混乱，不用无预警秒杀堆砌难度。
- 事件由房间环境和玩家行为触发，调度器负责约束密度；避免看上去像系统故意针对玩家。

## 06｜挖矿、搬运、交付与装备

### 6.1 资源分布和开采体验

- **普通通道**：少量基础矿，保证随手采矿的反馈，不要求一直挖整片地面。
- **集中矿室**：承担大部分可观收益；必须通过探索、绕路或突破障碍发现。
- **高危深层/隐藏洞室**：高价值矿、特殊制作材料，以及更高的事件风险。
- **结构岩层**：指定工具或炸药才能破坏；危险释放和矿洞连通可成为策略选择。

玩家的核心决策不是“挖哪个普通方块”，而是**去哪里、用什么工具、多挖多久、怎么搬回船**。

### 6.2 两段式资源经济（避免重复计价）

| 地点 | 资源处理 | 玩家获得 |
| --- | --- | --- |
| **矿洞里** | 资源在玩家/运输设备背包里，尚未保障 | 可继续冒险；倒地或失联有丢货风险 |
| **飞船货舱** | 资源**入库并保全**；可消耗部分矿物制作补给/临时装备 | 明确的阶段性安全与当局成长 |
| **撤离后轨道/贸易界面** | 将剩余库存出售换金币 | 永久工具、防具、背包、无人机、星球解锁等长期成长 |

资源只有一次去向：**已用于现场制作的矿物不再参与出售结算。** 不引入第三种复杂货币。首版保证第一次资源交付后能够体验到一种可感知提升（例如多携带、照明、炸药、应急药包）。

### 6.3 工具成长重点

1. **前期：** 手动挖矿、个人背包、基础照明，玩家亲自搬运。
2. **中期：** 炸药、强化镐/钻具、危险探测、防护装备，允许更快进入深层矿室。
3. **后期：** 矿物搬运无人机、定位标记、短途运输设施、自动采矿设备；提高效率但引入能源或噪声成本。

即便后期机器能挖，玩家仍然负责**选择路径、发现洞室、处理机关、应对特殊敌人、管理危险和决定撤离**，不能让自动化替代全部核心操作。

## 07｜飞船与撤离：弱化操作、保留意义

### 7.1 飞船功能边界

- **星图选择后自动降落。** 只保留简短的降落/起飞演出，不再设置空中自由驾驶。
- **固定预制飞船。** 可更换少量外观或功能升级，但不做完整结构DIY或深度舰内装修。
- **地面节点。** 货舱、工作台/补给、队伍集结、危险提示、启动撤离。
- **防御从属。** 飞船自带基本防御；高危阶段可以出现偶发的警戒、耗材或修复事件，但**不要求玩家定时回地表守塔**。

### 7.2 撤离与失败规则

- 任意时刻可以提出撤离；多人合作时显示队伍撤离提示，成员集结后自动起飞。高危紧急撤离允许倒计时机制，具体操作时长在原型中验证。
- **货舱内资源保留**；身上和地面未入库资源在全员失败时损失。避免一次死亡抹平20分钟所有成果。
- 倒地队友优先提供救援交互，减轻联机挫败；撤离不是强制击杀所有怪物后才能触发。
- 高危险时期返程本身是一段挑战；通过导航标记、路线解锁和运载升级缩短枯燥跑图。

## 08｜多人合作的核心乐趣

**强调临场协作，不设置强制职业：** 一名玩家采矿，另一名搬运、照明、警戒；遇到险情可以即时互换任务。

- **共同风险：** 全队共享全局威胁时钟与重大事件；噪声具有位置，可让分队行动产生权衡。
- **共同物流：** 飞船货舱为团队共享；减少抢矿和背包内耗。首版建议共同结算且不因队友加入直接稀释个人奖励，具体多人经济倍率另行测试。
- **互救与意外：** 被怪物抓取、塌方隔开、货物掉落、放电误伤等优先导向互救，而非一击出局。
- **共同决定撤离：** 必须清晰显示剩余队友位置、回船距离和全局危险阶段，减少“有人想撤有人不知道”的沟通成本。

联机实现原则沿用现有 **YYGC + 服务端权威游戏状态**：全局威胁、事件触发、资源入库、撤离与关键地形修改由权威端决定；客户端负责本地表现。矿洞局部破坏同步只发送必要的局部状态变更，避免每次事件重新复制整张地图。此处是策划约束，具体数据链路由现有技术方案负责。

## 09｜一局20分钟的模拟（不是固定脚本）

| 参考时间 | 场景 | 真正发生的选择 |
| --- | --- | --- |
| 0–4分 | 自动降落；两人找到基础矿室；首次运回货舱 | 是继续浅层搜集，还是马上向深层探索？ |
| 4–8分 | 挖开空心岩壁，出现拟态矿虫；购入炸药/补给 | 风险带来了新的矿室与材料 |
| 8–12分 | 爆破快速取得矿石，但额外推进危险并吸引地下敌人 | 省下开采时间，却增加了返程风险 |
| 12–16分 | 发现高价值洞室；附近发生小型塌方，原捷径受阻 | 现在带货回去，还是赌最后一批稀有矿？ |
| 16–20分 | 敌种变复杂、追击加强；队友互救并撤回飞船 | 成功撤离，损失少量未交付资源或获得超额收益 |
| 结算后 | 剩余矿物售出，购买长期升级，选下一个矿区 | 熟悉核心规则，但下一局路线与事件不同 |

**成功的一局应该能够被玩家复述：** “我们爆破挖出大矿，结果把巢穴惊动了；后来利用落石砸死追来的怪物，差一点没带走最后那批矿。”

## 10｜首版开发边界与顺序

### P0：必须先跑通（一个星球、一个完整远征循环）

1. 星图选择 → 自动降落 → 固定飞船 → 返船撤离 → 结算/重复开局。
2. 洞室式随机矿区：少量主通道、岔路、隐藏矿室；集中布置矿脉；返程保证可达。
3. 时间威胁系统：基础敌人与较危险的敌种/行为分档，最大同屏数量有上限。
4. 噪声链路：至少让**一种爆破行为**同时影响局部生物和全局威胁进度。
5. 三个可复用特殊事件：**局部落石/塌方、拟态/伏击生物、隐藏高价值矿室**；可组合触发。
6. 资源搬运、货舱保全、现场补给、撤离后金币和至少两种永久升级。
7. 两人联机全过程：同一地图、危险、机关、地形变化和货物状态一致，支持倒地/救援。

### P1：首版好玩之后扩充

- 毒气与带电积水、震动猎手、偷矿兽；明确危险提示与怪物/环境互动。
- 第二颗主题星球、更多洞室模板、差异化危险参数。
- 更有表现力的回船追击、飞船防御/修复的偶发轻量事件。
- 矿石运输无人机与定位/短途运输工具。

### P2：中长期内容

- 机械遗迹、异星植物、声波晶体、反重力等星球专属规则。
- 更复杂的高风险房间、稀有事件链、特殊委托任务。
- 轻度飞船个性化与装饰；不重新引入复杂驾驶/自由DIY作为主循环。

## 11｜试玩验证标准与调参

建议先用 **2人、同一星球、10局左右** 的内部试玩验证以下问题，数值均属目标假设：

| 验证项 | 期望观察 | 需要调整时 |
| --- | --- | --- |
| **撤离抉择** | 玩家在有货可保时，仍会为了新发现讨论是否继续 | 若只想着尽早跑，增加深层独特收益或改善风险反馈 |
| **时间压力** | 前段能探索，中后段明显紧张；不出现开局就被围攻 | 调整阶段时间、刷怪行为和上限，不只改生命值 |
| **下矿占比** | 主要有效游玩时间花在地下探索、挖掘与运输 | 缩短起飞、商店、无意义返程和守船时间 |
| **意外质量** | 发生2–4次可讲述的特殊遭遇，死亡原因可解释 | 降低事件堆叠，增加线索与反应窗口 |
| **经济成长** | 首次交付后有收益，结算后有明确下局动力 | 调整矿室收益、入库容量、装备价格和资源需求 |
| **联机可靠性** | 2人看到一致的塌方、怪物、矿物和入库结果 | 优先修复事件/地形/资源权威状态链路 |

建议记录：**实际撤离时间、撤离前携货价值、已入库/未入库价值、第一次交付时间、特殊事件次数与类型、失败原因、返程耗时、怪物最高同屏数、局部地形同步异常**。这些指标可以直接支持后续平衡和技术验证。

## 12｜最终设计决策清单

| 问题 | 当前结论 |
| --- | --- |
| 选用哪种基础模式？ | **模式1：随机短局、时间压力持续升级。** |
| 危险由什么主导？ | **时间是必然因素，噪声是加速因素，地形/机关是局部意外。** |
| 是否强制固定时刻撤离？ | **不强制。** 超时只让留守越来越难，压力和同屏数量有上限。 |
| 如何保证探索重于打怪？ | **奖励集中于有价值的洞室**，敌人承担阻碍和戏剧性，不以击杀数为主成长。 |
| 飞船还有什么意义？ | **自动降落、交付、补给、货物保全、撤离。** 防御轻量化。 |
| 如何跨关卡循环？ | **轨道结算/商店 + 星图选择**；重访星球时生成新矿区。 |
| 地图怎样复玩？ | **固定星球主题 + 随机洞室连接 + 可控局部破坏 + 事件组合。** |
| 什么是第一阶段成功？ | **玩家愿意再下矿一次，并且在发现高收益时真的会犹豫要不要撤离。** |

---

**最终方向：** Dark Nights 是一款以**随机地下探索与采矿**为主体、以**时间升级压力和环境连锁意外**制造冒险感、以**飞船撤离和装备成长**连接多次远征的2D多人合作游戏。首版先把“发现矿室→冒险采集→送回飞船→继续贪还是撤离”做得足够好，再扩张星球内容和自动化设备。
