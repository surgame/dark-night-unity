# 地表天空与环境衔接候选

2026-10-03 正式地表改为[复用现有三层的分层衔接](CAVE_ENTRANCE_ART_LAYERS.md)：原点缀素材保持，退出 Shader 的深度透明／变色／变暗。下方 2026-10-01／02 的环境包络和入口渐变属于已替代的历史候选，不能作为当前绘制合同。

日期：2026-10-01。分支：`ft-20261001-surface-environment`。

用户报告正式远征的地表天空空旷，且天空与地面被整条水平线切开。本批按确认的方案 B 实施，做简单验证后保留人工验收项；不合入 main、不推送远端。

## 原因与范围

- `JourneyEnvironment` 原先把天空矩形底边限制在当前星球的 DockRow，低于泊位的露天凹地直接显示地下底色。
- 正式远征有意关闭灰松谷旧天空和远景，当前蓝色区域实际是航程渐变天空，缺少远景层次。
- `CaveStrata` 的地下底色和三层背景页完全不透明。只移动天空的排序不能解决问题，必须同时为露天地表做遮罩。

本批不修改 `PlanetTerrainGenerator`、权威地图、坡形、飞船落点、碰撞或矿镐规则。全图清空泊位以上岩体的生成约束仍保留；自然山坡、山脊和着陆局部整平属于尚未实施的方案 C。

游戏协议 **20**、AMP1 schema **2**、存档 **v14** 不变。没有 YYGC、UPM、ProjectSettings 或人工 Prefab／场景改动，没有 AI 生图。

## 实现与配置

1. 航程天空覆盖完整视口，绘制在洞穴背景后方。太空继续使用既有星点和过场；地表增加两层低对比远山剪影与稀疏云层。
2. 遮罩按每个原生像素列的首个真实坡形实心像素生成。当前前景表面用于判断露天与风化边缘，冻结初始表面用于地下环境深度；岩檐下仍保留地下背景，不把所有拓扑连通洞穴都画成天空。
3. `CaveSurfaceSkyline` 归当前 View 宿主，2560×1 RGBA 数据纹理约 **10 KiB**。RG 保存当前首个实心像素行，BA 保存初始参考行；已安装空格与尚未安装的输入区分，后者暂用冻结参考。初始基线与变化格只标记受影响列，整批一次上传纹理，远景与三层静态背景不重烘焙。
4. 岩壁最上缘叠加薄的风化颜色。地下基础亮度与背景色按所在列相对初始地表的深度变化，退出原先横贯地图固定行号的地表模式明暗带；移动／设备光源仍走原路径。
5. 远景由星球 ID 确定，颜色跟随已有 SkyColorHex；不消耗玩法 RNG。原生密度沿用 **8 px/格**，轮廓以 **2 逻辑像素**量化，不把大图缩小成 tile。无新外部素材，源代码就是重建来源。

当前配置入口：WorldSession TerrainProfile 引用的 `CaveTerrainStyle` 资产 Inspector → `Surface Environment`。默认启用，远景视差 **0.14**、远山高度 **7 格**、云层高度 **18 格**、风化厚度 **1.25 格**、洞口明暗过渡 **9 格**、地下基础亮度 **0.36**。关闭“启用地表装饰”仅关闭远景和风化，天空遮罩修复仍保留。配置在宿主装配时冻结，修改后重新开局；参数纳入 VisualIdentity。

完整地表环境目前接入正式航程。独立洞穴工作台保留原完整背景预览；它的原有烘焙合同不随本批自动替换。没有追加植被、天气、昼夜系统或新的 UI。

## 人工验证清单

以当前分支 Local Editor 的 Bootstrap 开始，建议新开局，在驾驶台选星球、航行、着陆、步行出舱。记录星球、种子、窗口比例、检查步骤和截图；原存档不删除。

- [ ] **飞船平台和两侧凹地**：平台附近天空仍存在；低于平台的露天凹地显示天空／远景，整条水平切线消失；平台本身保留真实平面，不把它当作裁切缺陷。
- [ ] **坡形和岩檐**：斜坡边缘没有矩形空洞、蓝边、漂浮风化条或岩壁被天空覆盖；岩檐下和洞室内部不会漏出天空。
- [ ] **远景风格**：远山与云层符合当前星球色调，低对比、不压角色与飞船；相同星球重新开局远景稳定，切星球不会残留旧远景。当前云层为静态稀疏轮廓，不承诺天气或云动画。
- [ ] **洞口到地下**：沿一处真实入口走入洞穴，亮度和底色逐渐转为地下环境；高低不同的入口没有同高度整齐变色的带，地下仍有层次，原光源正常。
- [ ] **采矿打开地表**：在露天地表逐格采挖，天空遮罩随实际新表面更新；挖深处墙壁保留地下背景。地形、遮罩和碰撞没有长期错位。矿镐功能本身不计作本批新增验收。
- [ ] **镜头与分页**：左右移动，跨页边界，滚轮近／远缩放；检查远景视差、像素抖动、露天空洞、背景页接缝和闪烁。另查 16:9 与窄窗口。
- [ ] **太空与切换**：检查太空待命、过场、到达、下降、着陆和返航；太空只显示原星点，地表出现远景，返航不残留地表装饰；暂停与菜单不破坏表现。
- [ ] **样式设置**：分别关闭远山、云层和地表装饰后重新开局；天空衔接修复仍有效。调整风化厚度和过渡深度，确认不会影响行走或采矿。
- [ ] **客户端与晚加入**：独立 Host＋客户端使用同一版本，核对相同位置；挖过地表后再加入／重连，当前遮罩一致且初始背景稳定。这一项未由简单同进程验证替代。
