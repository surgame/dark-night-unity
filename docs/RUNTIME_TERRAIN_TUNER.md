# 运行时洞穴工作台

2026-09-26。`ReferenceChamber` 与 `RandomCave` 的 Play 左栏接入 Cave Wall Tuner 调参和拆填能力，独立 Editor 窗口继续保留。通过 `Dark Nights / Terrain` 打开新版场景；场景位置及正式远征接入关系见[场景索引](SCENES.md)。本批无需新增美术素材。

## 页面和操作

| Tab | 内容 |
| --- | --- |
| 地图 | 角色／平移／拆格／填格、材料、网格、笔触撤销重做、地图来源、随机参数、房间定位 |
| 岩壁 | 外轮廓、前景造型、刷新三个子页；造型栈每次只展开一项 |
| 背景 | 总览与近／中／深三个层；每层独立调点缀和造型 |
| 显示 | UI 缩放、面板宽度、镜头距离、全图适配、返回角色 |
| 状态 | 就绪进度、错误、刷新批次和提交统计；默认页面不堆叠诊断信息 |

每个 Tab 独立保存滚动位置。F1 收起／打开面板；窄栏的主 Tab 自动变为两行。分辨率自适应叠加 0.75–1.75 倍手动缩放，面板逻辑宽度 280–520，小窗口限制有效缩放，正文滚动，页签与样式操作保持可见。UI 缩放独立于场景镜头。

角色模式保留 Tab 行走／观察、左键手采、右键爆破。其他模式用左键拖动、中键平移、滚轮缩放；面板内滚轮只滚动 UI，文本输入时屏蔽角色快捷键。从面板开始的拖动不会穿透到地图；笔触跨入面板、松键或失焦即结束。

## 预览、应用与保存

- 修改样式约 0.4 秒后重建表现，保留当前地图格子、笔触历史、角色和初始背景参考。
- **应用样式**建立本次运行的取消基线；**取消样式**和每字段恢复按钮回到上次应用值。两者都不写源资产。
- Editor Play 中的**保存样式资产**才写入共享样式及其修改过的 Modifier／点缀资产。复用独立 Tuner 的逐字段冲突检查和 Unity Undo；在另一个窗口改过同一字段时拒绝覆盖。
- 笔刷按连续拖动组成撤销事务，仅编辑内部可破坏格。地图仍由离线工作台的权威地图持有，历史只保存差异；角色手采等外部操作改过同格后，撤销／取消拒绝覆盖。
- **应用地图到固定资产**保存固定蓝图最终格子，校验打开时源文件、保护格、坡形和独占引用，并重载蓝图。随机地图不提供覆盖固定资产的按钮。
- 退出 Play 丢弃未保存的运行时修改。重新加载地图／R／新种子会重置运行时地图；按钮明确标注此行为。样式资产会影响所有引用它的场景。

Player 不引用 Editor API，也不显示写入工程资产的按钮。此次没有改变正式协议 14、存档 v10、场景 GUID、美术字节或联机命令入口。
