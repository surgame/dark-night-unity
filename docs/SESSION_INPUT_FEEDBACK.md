## 面板职责与消息路径

后续用户已明确要求将原常驻按钮移入 RuntimeDebugHub，最新入口见[远征调试页](RUNTIME_DEBUG_HUB.md)。以下“保留该面板”仅描述本页首批提交，当前正式画面不再显示此按钮块。

截图对应 `ExpeditionPanel`：它是正式远征主流程面板，卸货、舱段升级、派工、补充和驾驶按钮经 `ExpeditionHud` 提交可信命令，不能当作纯调试面板隐藏。此批保留该面板、数值及操作说明。

按用户要求，HUD 消息和横幅暂时全部转入 Smart Console；连接／Session 常驻提示、航程确认及超时、主角错误和改键结果同步改为日志。YYLogger 仍为统一入口，Smart Console 接收 Unity 日志，原生配色区分普通信息（灰白）、警告（黄）、错误／异常（红）与命令（蓝）。状态日志仅在值变化时输出；F10 开关沿用已有输入阻塞。未来需要横幅时，在冻结事件消费入口选择性恢复，无需改变服务端通知合同。

## 滚轮

`HeroFrame` 不再携带滚轮；`HeroInputSampler` 只消费 1–4 对应的装备选择。点击装备格仍走原命令入口。UI 列表滚动、旧营地镜头缩放和地形工作台滚轮行为不变。

## 已确定的返航后无法移动缺陷

用户离开窗口期间模拟继续运行。读取到的 Editor 日志包含自动返航结算；代码确认：缺氧／战斗死亡的专属主角被保留，结算搬回船内后生命值仍为 0，而 `ActorBehaviour.Tick` 对零生命值直接返回。故可出现画面与会话正常、主角永久不能移动的情况。该缺陷并不能证明用户所有“切回来卡住”都出自同一原因；按用户后续要求，不扩大调查焦点丢失、Editor 热重载或整体冻结，等待更准确现象。

结算事务现在恢复专属玩家的生命值和氧气，保留角色身份与装备；损失仍按恢复前状态计算。控制租约递增，船内归位清空输入，旧输入不能继续生效。恢复与结算存档属于同一事务，存档失败必须整体回滚；存档格式不变。此修改不自动更改或覆盖用户已有存档。
