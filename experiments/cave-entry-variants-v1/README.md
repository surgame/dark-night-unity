地形以无纹理矢量轮廓表达，使用主题感知的淡色围岩／空腔和独立生态色。选择该方式是为了比较自然曲线、台阶和出口高度；本片没有最终贴图、tile切片、透明共边精度或原生碰撞资源。

## 六组形态

| 名称 | 入口 | 第二片 |
| --- | --- | --- |
| 缓坡续深 | 长短缓坡分段下行，低位出口 | 平顺接续后继续缓降，没有必经垂直坠口 |
| 岩阶入洞 | 开头两级不等形岩阶，再走短坡 | 横向舒展的小厅，地面轻微起伏 |
| 浅坳低口 | 偏心浅坳，小幅回升，出口仍低于地表 | 低口进入另一段起伏洞道 |
| 岩肩上台 | 浅降后回到天然岩肩，出口略低于地表 | 岩肩之后再次下探 |
| 沿溪深入 | 入口缓降并保持低位 | 局部浅水窝与渗流，随后抬高一点接下段 |
| 岩棚分岔 | 逐段下行进入稍开阔空间 | 右侧围岩伸出的岩棚分成上下两个出口候选 |

每组独立成对设计；两片的接口位于x=6.4，由同一作者曲线分割观察，地面／洞顶位置和水平切线一致。不同组的出口高度不同，当前没有任意交叉组合、WFC求解或正式端口枚举。岩棚上层是空间候选，不以本片证明跳跃、梯具或返程可达。

## 生态及动作

- 受光入口和岩肩边缘放短草，洞檐／顶缝放稀疏垂根；阴暗凹处放菌簇，水窝周边使用较密的湿生点缀。
- 生态挂点取自作者轮廓，图形与地形分层，可关闭生态直接比较地形。没有采集物、经济、碰撞或怪物语义。
- “动作预演”运行5秒：草与垂根轻摆、菌盖受扰回弹、渗水向下流动及落水波纹。支持手动停止，隐藏页面或离开可见区域时停止，遵循系统减少动态设置。
- 当前是浏览器表现草案，未制作Spine骨架、Unity粒子、Shader或水体模拟；后续原生制作应保留这些独立挂点及动作分工。
