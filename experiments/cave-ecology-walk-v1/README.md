## 美术和动态

植物精修制作前合同：一张目标1536×1024透明原生图，3列×2行、每格512×512，分别放草簇、橙菇、蓝绿菇、乳白菇、垂藤和蕨叶，各格留透明边缘并保留脚底／根部锚点。采用内置生图制作非低像素手绘切出图，以改善程序初版过于几何的轮廓；不把它当作16×16 tile或精确形状合同。原生整图与提示保留，分格仅用于包装独立对象；预览中分别变形、摆动、回弹，不生成或采用新的生态整景。

- 六张原透明岩体和一张用户指定的原设计断桥分别保留。断桥原生1536×1024等比放到495×330、位于623×414模块的x64处；完整主体不作通用U槽切除或程序道路覆盖，左右64单位接口位于原设计外侧，仅核心侧缘8单位及深床岩底12单位软接。原主角透明PNG另层入景，后壁与矿物分离。静态生态整景仅作参考，不参与打包。
- 草叶轻摆并受角色靠近影响，菌菇摆动和压弯，垂藤与泉瀑根系有独立锚点。水流有连续流纹、按高低确定的流向，瀑身向下运动并在落点产生飞沫和涟漪。
- 架桥按片展开，0.65秒完成后才提供支撑；采矿有碎屑粉尘，货物在0.85秒运输完成后才成为可拾取对象。碎岩修桥候选的独立局部岩台先抖动预警、再破碎；原图固定岩体保留。所有粒子有数量与寿命上限。
- 地面沿作者土沿引导；新增接口与改形区分开保存支撑中心、道路远缘／近缘和暗前立面。用户原设计断桥的阶梯采用独立脚点引导，不把路前碎石最高点当脚下踏面。岩顶碰撞来自原生alpha轮廓，低顶修订及旁支壁台拥有各自形状。地面与原生逐像素边界不等同，碰撞开关可审阅，正式地形仍须另验。
- 当前生态是独立程序表现，没有创建或验证Spine工程。后续Spine Pro需按[模块合同](MODULE_CONTRACT.md)拆分草、菌盖、菌柄、根段、支点与隐藏补绘区域，保持动画与地形权威状态分离。

## 源与重建

`world-data.js`保存模块与插槽；`module-rules.js`编译完整接口签名和WFC；`terrain-shapes.js`派生道路、切口、低顶、水路和岩台；`engine.js`推进唯一浏览器试走状态；`renderer.js`只读绘制；`assembly-inspector.js`显示当前接边；`app.js`负责输入与预览恢复；`view.html`是界面。

`contours.js`由`build.py`根据原样板`art-silhouettes.json`生成。`authored-profile-input.json`声明用户原设计的脚点、原生尺寸与外侧接口；`trace-authored.py`只读源图alpha并生成`authored-profiles.js`。两份生成JS禁止手改，构建自动重建。原作者PNG字节及来源SHA保留；新增岩面材质只用于接口和明确修订区，不替代完整主体。

运行`python build.py <绝对输出路径>`打包为单文件片段，不修改原图。当前输出与来源SHA-256在`manifest.json`；常用输出：

`verify-engine.cjs`记录完整输入往返、触顶与种子静态核对；`verify-rules.cjs`记录规则拒绝与求解；`verify-assembly.cjs`记录形状／端口／水路／附着关系；`verify-phases.cjs`记录机关阶段与碰撞。当前批回执追加在`verification-records/`，每次构建身份追加在`build-records/`。旧`verification-*.json`只对应原输入。两次被用户指出缺乏透视／偏离原稿的画面保留在`artifacts/ecology-repair-20261031/first-review/`与`second-review/`，不能因程序核对通过而改记为美术通过。

`export-library.cjs`仅在当前manifest与源码完全匹配、静态形状审查通过后输出`production-candidate-v2/<时间-身份>/`。每个模块包含本地形状、完整端口、独立水路／植物／机关锚点，附原生图像、规则矩阵和来源身份。命名中的candidate表示待审，不表示所有允许配对已人工美术通过。正式使用前须完成允许配对、变化状态、真实镜头和Unity资源接入；不在正式运行期重跑WFC。
