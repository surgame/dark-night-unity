# 洞穴轮廓与大块拼装 · 六方式白模

2026-11-01，CL-01／08独立浏览器候选。按用户“都做一下看看效果”要求，同时比较前述轮廓扩展与大块拼装方式。`index.html`和聊天片段同源，严格正侧视、灰度白模，本片无采掘／破坏入口，不改变正式采集玩法。

## 共同输入与比较边界

作者范围184×86，主洞道分为8个位置固定的形态槽：岩层入口、长岩台、高顶洞厅、弯折岩肩、压顶窄道、下凹洞厅、断层台地、收拢盲端。共用角色胶囊比例和镜头；切换方式保持当前相机，角色在同一横向位置投到新地面，避免被新形状包在岩中。

| 方式 | 实际实现 |
| --- | --- |
| 16型圆角 | 对共同作者轮廓采样二值四角，只读复用原16型半格圆弧和解析碰撞 |
| 256多值 | 同一角点空实，各角取−3／−1／+1／+3，共256配置；按数值插值边界位置，使用固定拓扑的线性片段 |
| 连续轮廓 | 同一作者控制点直接形成跨格单调三次轮廓，保留长直段；采成1/8单位折线供显示与试走共同消费 |
| 大块直拼 | 8个整段形态，固定同族端口，种子选择A／B／C内部形状，直接拼接 |
| 大块＋过渡 | 同一8类形态缩短核心范围，相邻核心之间插入7段宽6单位的五次过渡，可连接不同宽度端口 |
| 大块WFC | 在8个固定角色槽中从160项参数候选真实执行加权最小熵选择、邻接传播及有界重试，相邻端口一致后安装 |

前三套共用完全相同的作者引导，其中16和256的二值角点逐点相同。大块三套共用8类轮廓和相同宏观端口位置，内部轮廓及接口宽度会改变，不能冒充逐点同形比较。显示角色是中性比例胶囊，未替代原主角资源。

256是四角数值配置数，包含几何重复和全空／全实心配置，并非256张独立手画素材，也不代表本图使用了全部配置。256版保留格级折线，连续轮廓与大块版才跨格塑造完整岩肩。

本例是沿主洞道的有限链式样板，不含任意二维生长、分支重排、不同占位块的打包或完整随机地图。换种子改变轮廓参数／端口／候选选择，8个槽的位置与角色不变。

## 大块形状与接口

每类大块有A／B／C三种参数形状，平直顶板／台地、宽弯和局部钝折分别表达岩体；不会给每格套统一半径。160项由形态、左右端口及内部变体派生，原始轮廓控制点只保存一份，不是160份最终美术。

端口有三种宽度，约定上下沿位置和水平端部切向。直拼与WFC使用完全相同的相邻端口；过渡版从一端上下沿插值到另一端，并在解析端点保持零切向变化。最终1/8单位折线为采样近似，不宣称折线处处解析光滑。显示模块分界时，短过渡段只加半透明带，不改变地形。

WFC维护真实候选域、权重、加权熵、观察与传播删减。首尾锁定中等端口，角色和部分左右宽度变化被限域；求解结束逐对检查端口。不把随机换变体当作WFC。最多四次重试，失败抛错；UI保留上一有效世界，不安装无效回退。

## 操作与状态

- 六个按钮在原镜头切换，视图可选全图、入口、洞厅、岩肩、凹厅及接口近看。
- “格网／模块”显示小格或大块边界；关闭后看纯轮廓。“叠加16型”显示同种子旧基线。
- 可拖动观察、滚轮缩放，展开“查看完整大块”看8类当前模块。
- “试走”提供实际胶囊水平移动／跳跃；A／D、方向键、空格及窄屏按钮可用。只核对入口附近，不证明压顶、斜面、全路线或返程成立。
- “换一组”更换种子。“返回入口”只改变本版比例角色／相机。

独立状态键`dark-nights-macro-cave-comparison-v1`和kind `macro-cave-v1`，只保存种子、方式、相机、显示选项和比例角色。初始加载不保存；有意义交互才保存，主机回声不反复重装世界。原洞穴、废弃矿井、层状洞穴的文件与状态键均保留。
