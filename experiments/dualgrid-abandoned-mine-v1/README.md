# 废弃矿井 · 方整结构白模

2026-11-01，按用户“做成比较方方正正的地下废弃矿井”要求制作，归CL-01／08。`index.html`为独立单文件预览；聊天版本同源。原天然洞穴源码、生成文件及原状态键均保留。

## 当前结构

地图为232×128个渲染格，以矩形空腔和水平／垂直巷道构成，沿用16型DualGrid的半格圆角。长直边和直角转折占主导，保持正侧视，不显示地面顶面。

| 层级／位置 | 设计内容 |
| --- | --- |
| 上层 | 入井站、运输主巷、规则支护采场和小料间 |
| 东侧提升井 | 直井连接上中两层，缆线／导向／井底吊笼占位 |
| 中层 | 装卸站、旧泵房、水平运输巷及封闭支巷 |
| 西侧检修井 | 狭长直井连接中下两层 |
| 下层 | 旧巷、矩形采场、深层工作面及封堵端头 |

共9个可聚焦点位。破损支护、断开的侧视轨道、遗留矿车、封板和泵房基座表达人工开凿及废弃状态；全部为灰度结构标记。轨道仅画正侧面一条线，不增加纵深。

## 操作与功能边界

沿用全图、点位聚焦、右键拖动／滚轮缩放、格网、16格型查看、胶囊试走、跳跃和近壁采掘。触屏按钮沿用上一版。“返回入口”保留采掘，“还原矿井”只重置本版。

提升机、吊笼、矿车、支护和泵房均为静态背景占位，没有升降、载人、推车、结构受力或业务碰撞。支护与轨道的部分锚点会只读检查下方岩体，采空后撤下相应标记，不让它们凭空充当地形。封闭支巷的堵段属于真实实心格，可用样板采掘打开，封板本身不另建交互系统。

当前核对不代表两口直井可往返或完整路线通行通过；未加入预装梯具、正式角色数值、塌方、经济、联网或采矿结算。旧泵房没有抽水功能。

## 源码复用与状态隔离

- `layout.js`：新的矩形洞形、堵段、三层布局、9点位和装饰锚点。
- `props.js`：平面的支护、轨道、矿车、封板、缆线与泵房标记。
- `build.cjs`：只读复用`../dualgrid-cave-exploration-v1/`内核，并按其`records/2026-11-01T10-02-10-373Z-build.json`核对源码与原独立HTML的SHA-256。
- 构建仅对本版输出适配组件ID、标题、状态命名及装饰绘制入口，同时将世界范围外显示为实心岩体。原文件不回写。若基线字节变化，构建停止，需先审阅新来源。
- 本版使用`dg-mine-v1`及`dark-nights-dualgrid-abandoned-mine-v1`，与旧版`dg-cave-v1`／`dark-nights-dualgrid-cave-whitebox-v1`分开，避免旧采掘索引套到新地图。

两套目录需要共同保留以便重建，不把生成文件当唯一源码。

```powershell
node experiments/dualgrid-abandoned-mine-v1/build.cjs
```

可额外传入聊天片段的绝对输出路径。当前片段为本聊天目录的`dualgrid-abandoned-mine.html`。独立场景不需要服务器或图片下载。
