# 天然洞穴 · 层状弯折白模

2026-11-01，按用户“比较方正但又有天然弯曲的天然洞穴”要求制作，归CL-01／08。`index.html`为独立单文件预览，与聊天预览同源。前两版天然洞穴和废弃矿井均保留。

## 空间方向

224×124个渲染格。宏观轮廓先用少量较平直的顶板、宽岩台和近直立断面建立层状结构，再以不对称弯折、岩肩和侧向裂隙打断整齐感；不采用重复矩形房间，也不让所有边界持续波动。严格正侧视，没有地面顶面。

| 点位 | 形状与内容 |
| --- | --- |
| 岩层入口 | 短天然裂口落到宽台，侧壁弯曲，主要顶底段较平 |
| 错层岩台 | 连续台地前后错位，局部收顶，下方分出侧枝 |
| 层状洞厅 | 长顶板、宽底面、不对称附壁岩肩 |
| 弯折压顶 | 洞道沿岩层下沉后收窄，折角前后都有短直段 |
| 深部岩室 | 近直立断面和弧形岩肩共同包围大空腔 |
| 曲折裂隙 | 先向左折回再转右下，改变探索方向 |
| 下层凹厅 | 低位横向空间，顶板有平直段，地面浅凹错层 |
| 上折盲隙 | 下层末枝转向上方并在厚壁中收拢 |

`layout.js`中的上下轮廓采用明确控制点及分段平滑插值，裂隙采用宽度变化的折线包络；随后采样为二值逻辑点。实际显示和碰撞仍由共享16型DualGrid产生，端点固定在共边中点，局部圆角为半格圆弧。插值仅决定逻辑采样，不把曲线外观当作额外碰撞或正式坡形。

不包含木架、轨道、矿车或其他人工设施。矿层只画小菱形占位。初稿下层曾回接上方空腔，终稿改为盲隙，保留厚岩体与外围连接；初稿截图留在`records/initial-preview/`。

## 操作

沿用全图／点位聚焦、右键拖动、滚轮缩放、格网与16格型查看。点击“试走”后，A／D或左右方向键移动、空格跳跃，点按附近岩壁采掘；窄屏提供触摸操作。

点位聚焦只移动镜头，角色不传送。“返回入口”保留当前采掘，“还原洞穴”只重置本版。

## 来源与重建

- `layout.js`为本版洞形、8点位、矿层占位和出生位置。
- `build.cjs`只读复用`../dualgrid-cave-exploration-v1/`的格型、胶囊、渲染、状态、交互及视图片段。
- 来源固定为原版`records/2026-11-01T10-02-10-373Z-build.json`中的源码／独立输出SHA-256；变化时停止构建，需先审阅。
- 仅在新输出适配组件ID、名称、状态命名，并将有限地图外缘显示为实心岩体。没有回写原洞穴或矿井文件。
- 使用独立`dg-stratified-v1`和`dark-nights-dualgrid-stratified-cave-v1`，避免前两版采掘索引套入新地图。两个目录共同保留用于重建。

```powershell
node experiments/dualgrid-stratified-cave-v1/build.cjs
```

可另传聊天片段的绝对输出路径。当前聊天片段为`dualgrid-stratified-cave.html`，独立场景无需服务器或图片下载。
