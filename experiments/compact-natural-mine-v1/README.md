# 紧凑天然矿洞 · 洞室组候选

2026-11-02，CL-01／08独立空间重设计。用户认为上一张地图被长暗道拉大，要求接近此前废弃矿井的紧凑多层感，但采用天然洞形、以游戏性为主，并用“初级道路再增加约50%、再增加约50%”表达深入。

## 本次解释与设计目标

将约50%理解为**距同一地面洞口的累计主线建议动线**，目标约为`L／1.5L／2.25L`。这不是每一层单独再造一条更长走廊，也不是每段路都必须精确乘1.5。

它是本轮空间节奏起点，不证明玩家一定感到更深，不转换成已实测的秒数、平衡数值或心理结论。分支、采矿、战斗、观察和停留均未计入。

## 紧凑结构

- 地面入口保留；地下恢复接近废弃矿井的“三层相邻、短口换层、洞室相互靠近”关系。
- 洞形由天然岩檐、较长石台、错位岩肩和短裂口组成，没有轨道、支护、吊笼、泵房等人工设施。
- 上版两块大型回折下行模块退到历史候选，本版不消费它们。层间高差集中在两个短小、带玩点的岩颈／错台中。
- 整体观察包络约82H×58H，主要可探索空间集中在地表下约5H～47H。H为角色碰撞高度，是设计尺，不是正式世界坐标或米。
- 本版主路线从浅层向右、转中层向左、再下探富矿厅；保持原路折返，无强制回环／捷径。

参考[废弃矿井白模](../dualgrid-abandoned-mine-v1/README.md)的层级组织，保留[原纵向候选](../cave-macroblock-design-v1/DEPTH.md)作为比较；没有按统一缩放把旧长图缩小。

## 大块以洞室组制作

| 大块 | 内容 | 设计用途 |
| --- | --- | --- |
| 地表入口块 | 01洞口 | 地面起步后短坡进入地下 |
| 浅层洞室组 | 02试采台、03岩肩错台、04浅层采区 | 通向首个浅层目标的途中已能采、观察和作动作选择 |
| 中层洞室组 | 05分段下探口、06壁内矿厅、07侧巢小室、10高处小矿窝 | 只多走一小段，内容复杂度增加；两个近距离侧室承担可选发现 |
| 深层洞室组 | 08收窄岩颈、09深层富矿厅 | 短风险点之后直接到厚矿体与折返点 |

四个大块包含10处局部玩点，不等于10个小tile。未来可以替换同接口的整套洞室组，并在组内保留已设计的空间关系；不能把整组缩放／拉长来填空。当前只绘制一个作者组合，没有实现随机选择或接口求解。

每组需要独立作者轮廓、入口／出口／可选支口、内容插槽、变化范围及允许镜像。图中的分组矩形只是编排边界，不证明围岩归属、占地排斥和全部共边已经合格。

## 路程递进

`data.js`保存同一条作者建议动线折线，从洞口到三个目标按欧氏线段累计，使用相同角色高度尺度：

| 目标 | 累计建议动线 | 相对浅层 | 比上一个目标增加 |
| --- | ---: | ---: | ---: |
| A浅层采区 | 约55.16H | 1.00L | 基础段 |
| B中层壁矿 | 约82.15H | 1.49L | 约49% |
| C深层富矿 | 约123.25H | 2.23L | 约50% |

高亮线按这条折线显示，没有将路线乘大伪造比较；线为建议动线，不是寻路求解，也不代表实际脚底轨迹或角色可达证明。

目标A之前已经有路边试采、岩台和矿脉线索，不让第一次有效互动等到走完整段。A→B经过短错层口；B→C经过短风险点，主要距离位于有内容的洞室内。

短连接只服务紧邻空间，局部侧支口约3H～4H；长段不再专门用于“制造深度”。这里不签署某个最长空跑秒数，需要后续在真实速度下观察。

## 内容、风险与后续动态

- 矿物仍是独立插槽与壁内潜力，路边小矿和深处厚矿分别表达，不将矿烘进背景。
- 侧巢紧邻壁内矿厅；候选巢位不自动决定激活、伤害、奖励或刷新。
- 收窄岩颈保留塌方候选区，预警／变化／堆积／清障由后续所属切片承接，不在本片自动模拟。
- 普通下探用分段岩肩，避免每层都靠大跳崖；返程、台阶、净空和工具条件尚未实际验证。
- 当前以结构灰度表现；植物、水流等动态不作为拉长地图的理由，后续只在适合的洞室插槽内添加。
