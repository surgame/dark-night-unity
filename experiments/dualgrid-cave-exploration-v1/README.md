# 地下探索 · Dual Grid圆角白模

2026-11-01，按用户“暂不考虑美术风格，搭建DualGrid地下探索HTML，所有地形棱角圆润”的要求制作，归CL-01／08。本目录是独立浏览器样板，不引用或修改正式Game、YYGC、原人物或美术资源。

`index.html`为可直接打开的单文件场景；聊天预览由同批源码生成。当前固定作者地图为248×140个渲染格，使用249×141个二值逻辑样本。严格正侧视，不画路面顶面和纵深。

## 空间安排

| 点位 | 设计目的 |
| --- | --- |
| 缓坡入口 | 短竖口接缓坡，建立下探起点 |
| 钟形洞厅 | 较大的净空，和后续低顶段形成尺度反差 |
| 压顶通道 | 低顶连接段，压缩视野和活动空间 |
| 断层大厅 | 高顶及附壁岩肩，留出主路与高位内容的位置 |
| 深处矿窝 | 主路末端收拢，放置靠近地形边界的矿层白模 |
| 高位侧穴 | 短小高位支线，具体到达方式仍为设计占位 |
| 下行裂隙 | 狭长斜裂支路，改变探索方向 |
| 碎石盆地 | 宽而低的凹形支洞及一个末端小矿窝 |

作者形状由连续上下边界、洞厅扩张、短支洞和附壁岩肩构成，再采样为二值格点。没有把几张独立美术图拼成地图，也未执行WFC或替换正式地图生成器。矿物菱形仅为内容位置，不代表储量或结算。

## 圆角与DualGrid合同

- 四角位序为NW／NE／SE／SW，对应位0／1／2／3，真实使用全部16个二值组合。
- 相邻格共享同一逻辑样本，边口固定在边中点；不为单格随意偏移接点。
- 单角和凹角使用半格半径的四分之一圆弧，半平面使用直线；圆弧到相邻格时切线相接，避免尖角。
- 对角型5／10保留两个分离实心角，不在中心偷偷连接，也不使用全图模糊遮掩接缝。
- 绘制从这16种形状生成图集；碰撞按相同半平面／圆距离公式读取。角色采用独立白模胶囊和有界步进，不冒充正式角色运动实现。
- 圆角不等于任意自由样条：本片仍有格级地形节奏，未制作非中点边口、额外坡形或变形网格。
- 鼠标采掘修改逻辑样本，每个样本最多影响四个渲染格；缓存只更新实际脏格，新增切口继续使用同一圆角格型。

## 操作

- “全图”观察整体结构；点编号或下拉选择点位只移动镜头，不传送角色。
- “试走”跟随白模角色，A／D或左右方向键移动，空格跳跃。
- 试走时点按或按住附近岩壁采掘，作用距离有限；触屏有方向、跳跃和敲击按钮。
- 右键拖动／滚轮缩放。触屏可拖动、双指缩放；拖动进入观察状态，回到“试走”继续角色控制。
- “返回入口”保留采掘结果；“还原洞穴”清除本样板的采掘和发现记录。
- “格网”查看实际样本与渲染格，“16种圆角格型”查看实际图集。

有意义操作后保存角色、相机、发现点位和采掘位图；聊天使用widgetState，单文件使用独立localStorage键。采掘用约5.9KB的Base64位图保存，不因长时间编辑截断格子清单。页面状态不是玩家存档。

```powershell
node experiments/dualgrid-cave-exploration-v1/build.cjs
```
