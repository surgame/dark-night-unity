## 情境与来源

所有情境来自同一真实`rift-expanded`地图。顶部与低处分别选择经过格级围岩检查的局部位置；其余在原近壁露头上另存独立候选，不把地图和精灵整体旋转，不是六张已审核地图。

上述规模、时刻和剩余量均为试参；六例不代表巢穴出现比例。共生区没有因增加矿团数自动提高预算；无巢富矿与侧壁候选使用相同矿体和总量，体现矿与巢非必然绑定。深层／富矿更易伴巢的分布方向继续按D-11，概率没有在本演示中定案。

有巢情境在冻结的第6次采掘后破开预标记壳片，超过一半矿量仍留在区域内。横向、低处和斜壁情境在2.95秒破壳、3.30秒开始接近；顶部失去支撑后立即下落，4.00秒到达落点，再沿地面接近，不套用悬空等待。下落加速度为演示插值，尚非正式重力参数。各情境最多显示一只预置生物，结束停止；回放不会补抽巢位、矿量或新的生物。

## 生成与动作边界

- `DirectionalNestLayouts`只声明有限局部配方与动作意图；`DirectionalNestValidation`用真实材料、保护格和其他R1矿层核对占格、初始封闭、矿／壳／巢体／支撑分离、逐格开挖及破壳前后路径。缺口来自实际接触面，不通过浏览器单独挪坐标交付布局。
- 旧选中矿脉的替换边界仍为`r1-vein-45395`，其他R1矿层参与排除。顶部与低处新增局部矿形也须避开已有矿层；正式作者图和矿床不回写。
- Core分别构造闭壳／开口候选坡形，各矿团转换为现有`TerrainDepositBlueprint`，每床不超过64格、每格正容量且总量守恒。
- 浏览器按Core坡形公式让落地／爬坡／转出姿势的脚底贴面，顶部沿世界竖轴加速。初版按空格中心移动显得悬空，已调整为表面姿势投影；这仅改进演示，不等于角色或幼虫的身体碰撞、最大坡度、台阶能力或导航已验收。
- 作业位置是演示标记；顶部挥镐距离、梯具需求、采掘耗时与玩家运动尚未验收，没有生成或发放梯子。没有给正式幼虫增加跳跃、攀墙、钻土或瞬移能力。
