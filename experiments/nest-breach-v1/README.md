# 薄壳破开与动态出没样板

2026-10-18用户认可近壁矿形，但认为巢穴仍远、单独侧挖会使危险晚于采矿，要求结合“一镐爆开一小片”制作动态演示。本目录是新的CL-01／04离线设计候选；保留近壁三候选及更早演示，不写Game、作者图、素材或运行配置。

## 本批提案

沿用近壁鼓包的同一真实rift-expanded洞壁、20矿格和64储量。把预制巢腔移到矿体旁，仅隔一层脆壳，命中第6矿格时失稳带开3格预标记薄壳；不另挖侧道、不吞掉剩余矿、不在发现时重抽巢穴。

- 第5镐后，下一处矿面短暂显露细裂纹；第6镐在2.95秒打通，留下44／64储量，约69%。
- 本镐采掉1矿格，同时破开3格脆壳，形成连通预置巢腔的小开口；破坏只限该片预留材料，不是矿镐全局范围挖掘。
- 破壳后碎屑散开，幼虫从预藏位置显露；3.30秒开始钻出。约0.35秒的辨认间隔、矿面裂纹及全部时间均为演示试参。
- 比较及时沿原路后退／停在矿前：前者形成距离，后者遭受近身压力；不结算伤害、击退、死亡或经济。
- 此处只放一只预置幼虫，不代表正式出虫总额度、巢穴比例或刷新规则。演示结束不循环生成，回放是同一冻结情境。

“矿格被挖导致相邻薄壳失稳”是本次候选触发，不是已确认正式机制。触发应落在真实接触／支撑面，不能按采矿百分比从远端打开巢穴；具体接触材料、破坏范围、前兆、反应窗口、出虫体型及战斗节奏仍待审阅。正式生成还要保留无巢与其他风险关系，不将此方案强制套到每一处矿。

## 真实输入与验证边界

只读消费`near-wall-mining-snapshot.json`的鼓包和R1来源身份，再调用当前保存配置及现有Core生成器核对地形。新巢腔7格、脆壳3格及地板3格必须在真实可挖岩内，避开矿、其他R1矿层、保护格和原空腔。保留矿体与容量，关闭通路在第6矿格移除后仍封闭，破壳后才可从巢腔连到采掘面。两种材料候选均调用Core重算坡形。

离线BFS给出幼虫出口、近身终点和玩家原路后退的冻结格级路径，每段只跨相邻已空格；路径不证明角色／幼虫身体净空、重力、落脚、梯具或真实运动通过。浏览器回放动作、碎屑和已有CL-04原生姿势帧，无实际AI、感知、攻击／伤害、多人命令、存档或恢复。
