# 近壁盲盒矿团离线样板

按2026-10-18用户要求，比较贴壁浅团、短颈鼓包、邻接双团。目标是相似露头背后有未知规模，矿体靠近洞壁；保留此前R0／R1／R2及五形态演示，不将旧长连接作为常规前置。本目录只供CL-01／04设计审阅，不接入正式Game。

## 同源位置与候选

复用R1冻结输入及真实`rift-expanded`地形、坡形、保护格和其他矿脉。旧选中矿脉`r1-vein-45395`的露头位于空格；本批用其左邻一格实岩（X274、Y141）作三方案共同露头，天然空腔在右侧。明确换到真实壁面，不用旧14格偏移连接远端大矿体。其他56处R1矿脉保留，原图不写回。

| 候选 | 矿格／储量试参 | 主体入岩进深 | 连续与侧巢 |
| --- | --- | --- | --- |
| 贴壁浅团 | 8／16 | 3格 | 一小团，无巢 |
| 短颈鼓包 | 20／64 | 5格 | 2格后显著增厚；侧巢隔2格可挖封岩 |
| 邻接双团 | 21／76 | 4格 | 8格与13格两团，间隔1格薄岩；侧巢隔3格可挖封岩 |

三方案最初均只见一格铁矿，首两矿格容量均为2；之后容量和规模不同。单矿种用于隔离规模比较，不取消地图深层高价值矿种的目标。入岩进深是离露头沿局部法线的最大格数，不是矿格总数、采集耗时或沿主路的地图深度。双团总沿壁跨度8格，不能只凭入岩4格将其误写为整体4格宽。

双团薄岩表面的零星矿斑是冻结表现线索，提示再挖一格，薄岩本身不计矿床储量；不是挥镐时重新抽取第二团。该线索及数值均为待审阅建议，尚未变更正式矿层表现合同。中段侧挖可选：鼓包第8步接近封岩，此时余36储量；双团第10步接近封岩，此时余44。采矿到该步只开放演示中的侧挖按钮，必须逐格挖完封岩才显示巢腔，没有自动穿墙、进度刷怪或经济结算。

## 边界与复现

只读调用现有`PlanetTerrainGenerator.GenerateCandidate`，核对Core、保存配置、作者图及前景身份与R1一致。候选矿／薄岩桥、巢腔、侧壁和原岩地板须避开天然空腔、保护格及其他矿层；不适合的位置拒绝，不裁剪模板或强接远处。每一步静态开挖须邻接已有空腔／已挖格；两个矿团分别构造既有`TerrainDepositBlueprint`，各床不超过64格且容量守恒。

```powershell
dotnet build experiments/near-wall-mining-v1/NearWallMining.csproj --nologo -v minimal
dotnet experiments/near-wall-mining-v1/bin/Debug/net8.0/NearWallMining.dll '<项目绝对路径>' '<R1快照绝对路径>' '<本批独立输出目录>'
```

输出`near-wall-mining-snapshot.json`和`generation.json`。浏览器消费冻结数据，提供同尺度透视比较、逐格开挖和可独立关闭的侧巢；关闭侧巢不改矿量／已挖矿格，撤除附加巢腔与对应坡形。原始天然洞形仍来自真实地图；隐藏信息仅为邻格揭露示意，不模拟光照视野。

巢口和卵复用CL-04两张原生PNG，16像素／格；矿纹是代码示意符号。离线编译0错误／0警告，175项数据／浏览器／原输入保留核对通过，查看了透视、初始露头、薄岩后第二团、侧挖、深色与320宽度。78份旧演示／源码／实际输入／CL-04图源及其他会话Game文件指纹未变，详见[回执](../../docs/evidence/cl01-near-wall-mining-v1.json)。早期自定义网格覆盖hidden导致开挖条未隐藏的问题已修正，失败回执保留。
