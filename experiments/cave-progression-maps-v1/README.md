# 天然洞穴 · 进阶与更进阶空间候选

2026-11-02，CL-01／08，本聊天／Local。承接用户将[紧凑天然矿洞](../compact-natural-mine-v1/README.md)视为新手候选的意见，新增两张更复杂的作者白模；不据此将三档难度或任何候选正式定稿。

## 空间输入

沿用正侧视、地面入口、天然岩檐／岩肩、较平直的落脚台、相邻层带和短换层口。地图按原路返回组织，新增分岔既有近处小窝，也有内部继续分岔的独立探索区。两个新图均为作者明确布置，不是WFC或随机求解输出。

H沿用角色站立碰撞高度的设计尺，不是米或正式Unity坐标。两图整图视野统一142H宽，因此相同容器宽度下比例相同；各自按高度裁去多余底部留白。局部视野统一54H×34H。形状为确定性矢量白模，不产出正式tile、碰撞或美术。

## 进阶：岩肩岔洞

- 主干浅层向右、中层向左、再转深部，9处主干空间中持续有采区、岩台与短风险口。
- 洞口左侧浅岔、右侧巢后矿室、左翼下折矿窝均有第二段可选延伸。
- 高檐露矿和贴壁小窝仍是短支路，避免每次离开主干都承担同样的长距离。
- 六个大块分组是制作组织示意；矩形不构成完整占地、围岩归属或接口合同。

## 更进阶：叠层岔洞

- 主干扩展为12处洞室、五个空间层带，保持短连接和有内容的洞室，不新增专门拉长距离的大回折暗道。
- 浅层左岔内部再次二分，并且其中一支还可延伸；左翼中层支洞同样包含再次选择。
- 上层主干下方有独立双岔，右翼侧巢则接更低的矿室；支路的规模、方向和折返距离不同。
- 若干洞室视觉上相邻，但隔岩、无直接通口；主要交汇厅保留轮廓和位置地标。
- 九个大块分组承接洞室组合；未来随机制作应从有限的洞室组和声明端口入手，不把每间小室作为运行随机tile。

## 交互与来源

两图垂直排列，整图同尺度。各图“观察区域”可选洞室放大，点击洞室或编号也会聚焦。主干参考线默认隐藏，以便先看实际分岔关系；可共同打开参考线或大块分组。独立状态kind为`cave-progression-maps-v1`，不会消费或覆盖旧候选状态。

`data.js`是作者房间、连接、分组和内容用途；`geometry.js`派生天然轮廓、短连接与显示空腔；`view.html`／`app.js`负责展示；`build.cjs`生成聊天片段并核对旧紧凑候选源和片段SHA。`inspect.cjs`只核对展示、作者树数据及明显的绘图穿接，不代表角色通行、碰撞、返程或玩法验收。

路线长度如被记录，指入口到作者主干末端的房间中心连接折线，包含显示连接，不是脚底运动轨迹、采矿／战斗停留或实际耗时。它与此前紧凑图的贴近落脚面的建议折线口径不同，不能直接相除宣称玩法时长或难度提升。
