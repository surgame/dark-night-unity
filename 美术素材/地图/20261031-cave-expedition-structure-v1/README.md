## 跳跃点合同

先明确起跳支撑、空中净空、稳定落点、继续行走面、失误落区与反向走法，再细化美术。起落台和锚点属于空间合同，光照与矿物为独立内容，不烘进后壁。

只读参考当前`Game/Assets/DarkNights/Res/Config/balance.json`：固定跳跃，初速度160、重力320、步速112；当前每格16，理想连续曲线最高40像素＝2.5格，同高落地约1秒、步速位移112＝7格。冲刺倍率读取原配置，但本稿普通跳点不要求极限冲刺。该估算不包含离散步进、身体包络、坡面、头顶碰撞、空控修正、负重或网络；不是实机通行结论。`HeroJumpMotion`仅作公式来源，只读引用。

## 模块与随机制作建议

1. 大洞厅作为跨格预制块保留完整构图；窄道、裂口和小支洞按接口连接。大、中、小空间交替，允许不同洞群有不同支路数量和长度。
2. 内容插槽声明地面／墙面／顶部、净空、来侧材料区、两岸暂存区、接应区、变化影响区与返程条件。搭桥裂隙和配套木梁是一个完整候选包，不分别独立抽签。
3. 同一位置的承重桥与计时晶壳互斥；油火与菌伞落脚互斥；首次窄落点不叠隐藏追击；必经工具材料不能随机在工具门后。
4. 富矿泄气、配重设施与侧巢是可替换候选；按独立接口审核，避免一间房堆全部规则。受光菌伞D03、风洞C07等会改变落脚面的机制暂后置，不放入首张普通跳跃基线。
5. 若后续采用WFC，用于开发端空间接口／跨格占用与内容兼容选择；整张候选审核后冻结，游戏加载结果。该草图为确定性作者布局，没有执行WFC，也不在采矿后重新抽模块或刷新矿物。
