# 多方向地图风格探索

2026-10-29，CL-01／08独立美术候选，负责聊天`01a18820-685c-7ac2-a63a-caf825451d27`。用户要求延续“设计中间版地图风格”，多做几组，包含在原版游戏实机效果上拓展。本轮使用内置生图，六张均待用户视觉评审。

| 候选 | 画面方向 | 适合观察的问题 |
| --- | --- | --- |
| A-pixel-refinement.png | 原版像素强化：保留旧矿工与主要坡面，补齐后壁、矿物和较大的像素团块 | 保留像素风时，减少重复纹理并补上背景层次能改善多少 |
| B-inked-runtime.png | 原版简化手绘：大岩块、少量明暗、冷色背景 | 简化轮廓能否比细密岩纹更清楚，旧像素角色与手绘环境的差异是否能接受 |
| C-painted-runtime.png | 原版厚岩体改绘：沿实机坡面加入厚顶面、墨线与更多景深 | 既有概念图的精细程度放到真实游戏构图后是否仍合适 |
| D-greypine-entrance.png | 灰松洞口：松林天光、灰绿巨岩、暖色露矿与原主角造型 | 延续既有偏好，缩小主角后观察整幅构图和道路顶面 |
| E-layered-shale.png | 层叠页岩：横向长岩板、干燥冷峻洞厅、铜色层理 | 用长线和大块面代替圆岩拼合，减少密集裂缝是否更有效 |
| F-earthen-burrow.png | 黏土夹岩：暖土层、深色夹石、冷色空腔 | 连续土层能否承载主体地形，以较少岩块形成清晰层次 |

前三张的编辑底稿是[2026-09-22历史采矿实机截图](../../../docs/archive/evidence/strata-cave-2026-09-22/player-mining.png)，不是当前版本截图。三张均去掉原调试界面，以便观察地形；保留旧矿工是为了对照原实机。D／E／F沿原主角PNG造型生成画面中的人物，属于AI重绘，不能当作原Spine动画或逐像素原角色导出。

原生输出均为1672×941不透明PNG。完整提示、制作前的尺寸／用途／形状／透明／共边合同在`brief.json`；`manifest.json`记录每张输出、输入、生成来源、原生尺寸、SHA-256和完整提示。PNG与内置生成原文件字节一致；预览只缩放压缩，不修改内容。

这轮只比较固定画面的美术方向。A／B主要布局接近底稿，但不作为逐像素复现；C局部坡面与断口有生成偏差，人物脚下也有简化接触阴影，不能把图片中的平面直接当作碰撞。E虽然大岩层更清楚，材质仍偏写实；F暖土色较强，后续若选用需再与正式照明和调色板对齐。这些都是待评审问题，不把生成完成等同于美术认可。

本轮没有制作16×16生产tile、随机共边、采挖后的新边缘或完整关卡通行；未改Game、作者地图、YYGC、依赖或存档，未启动Unity。另一聊天v6完整地图和Blender候选继续独立保留。

`build_preview.py`从六张已生成原文件保存本目录PNG，并生成聊天内的切换／底稿叠合预览；已有候选内容不同时会拒绝覆盖。运行方式为`python build_preview.py`，需要Pillow；生成文件位于本聊天独立visualizations目录，路径及哈希见`manifest.json`。`preview.template.html`是预览的可编辑模板，原生PNG是本轮交付。
