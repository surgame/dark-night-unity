## 后续模块制作方向

空间类型应先于模块变体。大洞可以占多个制作格，窄路作为连接，同一类型再准备不同轮廓、开口高度和内容锚点；不将所有预制块做成相同大小、相近净高的小矿窝。跨格占用、开口合同、轮廓、共边和最终矿层需在后续明确授权的模块实现中处理，本轮未新增对应算法或资产。
