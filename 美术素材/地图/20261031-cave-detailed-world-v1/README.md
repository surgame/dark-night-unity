## 视图与空间

同聊天visualize目录中的`cave-detailed-world.html`是草图编辑源。聚焦区域、缩放与拖动只改变镜头，始终使用同一批洞腔、平台、桥梁、物体和路线；不切换成独立局部关卡。全图首先呈现大洞、窄路、竖裂、低顶横室、碗形侧盆和遗骸盲端的尺度与轮廓差异。

全图中直接绘制：

- 浅洞J1的断口、起落台、浅凹失误区和投石／发光石位置。
- 大洞内的J2a／b错台、J2c可选上台、相应实岩支撑和上层支路；下层主线与上层货道保持空间关系。
- 承重桥、两岸等待／暂存区、桥下浅层折坡和可能断裂范围。
- 低顶横室中的贴地货槽、两端取放口、干燥会合龛和人货路线。
- 油盆下探区、独立干台、J3跨口、断供候选位和局部油火范围。
- 竖裂中的14格开口、来侧16格配套木梁、两端各一格支撑及较深失足区。
- 遗骸盲端的观察／转身位置、遗物和撤回方向；保留首次取头一次1/3判定的来源，草图不执行概率。
- 深部矿碗中的J4短口、高处暂存台、表面露头、壁内矿团、重矿接应和低处积气候选范围。

蓝线表示人员，橙线／橙色矿物表示货物，绿弧与落脚线表示普通跳点，变化范围以低透明色和边线区分。木梁开口不画普通跳弧。去程与带货情境改变路线强调和木梁部署示意；风险范围是作者查看层，不表示这些事件在同一时刻全部触发。

`world-layout.json`由草图源中的单一布局导出，仅供追溯，不作为第二份编辑源。八区域、七连接、六段跳弧、23处内容记录和七块附着岩台在所有镜头位置保持；42个空气图元包含洞室及分段连接，不计为42个房间。

浏览器核对736／360／320宽、浅色／深色、全图及八次聚焦，共54种布局；文字边界、相互遮叠、横向溢出及地形数量核对通过，无脚本错误。实际点击洞室标题、物体及标签、滑杆缩放、拖动、Ctrl滚轮、风险层切换、带货示意和状态恢复均已核对。目视回读全图、窄屏深色和矿碗放大图；原首轮截图及交互改进前的草图源保留于同聊天`detailed-world-review/`。这批仅核对结构展示和交互，不替代正式通行、物理或美术验收。

输入、草图、导出布局、浏览器回执的完整路径和SHA-256见`manifest.json`。当前浏览器独立回执为同聊天visualize目录的`cave-detailed-world-review.json`，源为`cave-detailed-world.html`；包装预览仅用于核对。
