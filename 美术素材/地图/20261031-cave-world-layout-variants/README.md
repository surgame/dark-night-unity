## 内容点如何落位

A适合逐层拓展的探索：浅层试采与上方露头提供近端选择，中段二级岔路带来薄壳厚矿、不同高度的支洞和可选事件，远端支线再配置厚矿或矿巢候选。各岔口需要有辨识度，避免多个盲端只有外观和步行距离变化。

B更适合作为后续内容规划的基础：试采矿厅周围配置容易理解的露头和短支洞；分叉矿厅组合高位露头、侧壁矿窝及薄壳；深部矿厅组合厚矿与矿巢候选。每个区域有几件不同的事可做，再选择下一处区域，便于控制内容密度和定位返程参照。连接段仍保持窄洞，不将三个厅都做成同样的空大房间。

C适合作为具有特色地貌的矿区或局部区域。隔壁能看到的露头、高位支洞、薄壳后矿体和被岩脊隔开的路线提供不同发现；图中斜面、高差和工作空间只是构图意图，没有验证角色运动或工具距离。

规划建议是以B的局部矿厅作为内容组织节点，按需要在连接段采用A的二级分支，并选少量C的岩脊高差作为地标；尚未据此合并生成第四张图或实施游戏内容。
