# 独立洞穴模块连接候选规范

本规范服务2026-10-31的八个独立玩点作者预览，尚未批准为正式生成器合同；本批仅画接口，不执行拼接或WFC。

## 坐标、比例与变换

- 逻辑格长16，原点在模块左上，X向右、Y向下；画布768×512。角色根在脚底，参考高41。图像原生尺寸与逻辑范围分别登记，不把屏幕像素当游戏单位。
- 外部端口的坐标、平台高度和法线按格登记；内部岩尖、碎石和斜面可有更细的作者轮廓。预览的插槽坐标与最终实岩轮廓需共同复核。
- 后续仅允许刚性平移及已登记的水平镜像，禁止为接上端口拉伸、扭曲、旋转整个模块或只移动素材不移动碰撞／矿物／物体。
- 镜像须同时反射形状、端口法线、材料来侧、锚点、矿层、交互点和变化范围；有方向规则的模块不能自动镜像。

## 端口及接口带

| 字段 | 本批候选约定 |
| --- | --- |
| 端口身份 | `P128`：普通水平洞道，明确地面／顶面间128单位；`CLOSED`：封闭围岩，不建立邻接 |
| 端口位置 | 外边界X＝0或768，地面高度取16整数倍；端口名称及方向单独登记 |
| 共同形状 | 法线相反、P128类型相同，刚性放置后地面／顶面和整个开口剖面重合；高度不同可平移，不能用相同字符串代替完整剖面核对 |
| 接口带 | 边界向内64单位为接口带；该带只包含平直洞顶、地面及对应围岩，起伏和内容从带外开始 |
| 美术边界 | 终版接口带必须来自同一套规范边条或人工修订，材质相位、墨线、透明alpha及密度一致。独立生成图仅是岩体候选，不自动满足共边 |
| 保护与变化 | 接口带不放随机矿团、机关、桥端、裂口或事件变化；动态破坏后的断路属于明确后果，不临时重求解或自动修补 |

后续接入时，先检形状剖面及方向，再检透明边与材质。端口文字相同只提供候选，不证明共边或通行。高厅／竖裂的内部高度不改变普通端口净空；不把“所有模块都能任意相接”作为目标。

## 玩点内部合同

- 普通跳点登记起落实岩、断口与失误落区；木梁裂口单列为需部署工具的通路，不绘普通跳弧。
- 搭梁点必须同时提供来侧材料区、两端支撑和部署体积。本批14格开口配16格木梁，两端各1格支撑；这是可审查候选尺寸，不修改正式平衡。
- 桥点包含桥体、两岸等候／暂存和断裂后变化区；桥是独立物体，不能直接画死在前景里。
- 货槽点包含人物低顶段、贴地送货空间、两端可接近的取放位；不通过缩小货物碰撞制造通行。
- 油盆、遗物、气体和矿物分别声明交互／变化范围，避开本模块接口带；矿物露头与壁内延伸关联，后壁没有烘焙可采矿。
- 单人能顺序完成基础解法，多人可缩短往返或接力；不以常驻灯手、永久托举者或全员同时持有特殊工具为默认条件。

## 图层与后续归属

绘制顺序为完整后壁、矿层、前景岩体、按遮挡关系排序的独立物体／人物、局部光照。桥、阀门、梁、遗物等对象可在人物后方，但仍有独立锚点和身份。

正式前景与矿格仍归SessionTerrain托管的ARDMap；交互物按获批切片沿既有Definition／ObjectInstance／所属Behaviour状态装配。作者预览只展示情境，不拥有正式业务、奖励、概率、网络或玩家存档。

后续WFC若启用，只选开发端初始候选与允许朝向，传播端口／方向／占地／材料及事件排斥约束；形成完整候选后再人工修整和冻结。运行采掘、断桥、拿矿不重跑WFC、不移动模块、不重生材料或矿。本批不执行该求解，也不恢复D-19的生产人物通行门槛。
