# 独立洞穴玩点模块设计

2026-10-31，本地图设计续接聊天／Local负责CL-01／08。按用户要求先回顾窄洞实现、约束连接规范，再分别制作八个玩点的设计效果；本批不连接地图。

## 窄洞方法回顾

来源为`../20261030-modular-cave-playground/`的当前分层样板：

- 作者绘制固定大构图，模块刚性放置，路面不自由拉扯。
- 完整、不含矿物的后壁覆盖空腔和初始实岩背后。
- 透明前景保留原生岩尖、碎石和墨线；实际轮廓与少量放置引导分开。
- 矿格和可交互物单独放置；前后排序不决定其业务身份。
- 角色、工具及受轮廓遮挡的局部光照另绘。
- 旧样板是六种构图／镜像的一维WFC；旧端口用盖片处理部分接缝，未达到生产精确共边。不能直接把这些结果当作二维大地图已实现。

本批延续分层和固定构图，新增每个玩点的独立透明岩体源，复用完整后壁、人物及矿物。桥、木梁、阀门、遗物与重矿保持独立表现。所需交互只用三种作者情境表达，不实现另一套正式游戏状态。

## 本批切片

| 模块 | 主要可见设计 | 三种情境 |
| --- | --- | --- |
| 浅洞试跳 | 3格断口、浅凹落区、来侧探路石 | 观察／试跳／落稳与找回 |
| 错层岩台厅 | 高空腔、两段升台、可选上窝和公共绳锚 | 初到／登台／带货回撤 |
| 承重断桥 | 两岸暂存、独立桥体、桥下浅折坡 | 轻载／负重预警／断后补救候选 |
| 低顶货槽 | 人可通过的低顶、两端放取位、贴地货槽 | 携矿受阻／放下送货／另一端取回 |
| 油盆干台 | 台下油盆、干岩跨口、来侧阀门 | 识别／跨口与断供／局部油火边界 |
| 竖裂木梁口 | 14格开口、来侧16格木梁、两端支撑 | 观察／搬梁部署／公共通路 |
| 遗骸盲端 | 可观察的遗物、转身区、退路 | 观察／首取头／抽动撤离候选 |
| 深部矿碗 | 高处暂存、露头与壁内矿、低位积气 | 初见／破壳露矿／放弃余矿回高处 |

遗骸首取头的一次1/3判定沿用原卡来源，预览只显示候选后果，不抽取概率。桥／气体／油火／绳路等数值与行为均待后续设计，不因效果预览进入正式玩法。

## 资产与规范

制作前约定：每模块逻辑画布768×512，16单位一格，人物参考高41；大图目标1536×1024作为两倍密度源，实际尺寸如实登记，禁止为凑目标尺寸放大。采用内置生图制作大块手绘岩体、透明背景，不用生成图充当16×16规则tile。精确连接按[接口规范](CONNECTOR_SPEC.md)的离散形状合同与接口带制作；生成图保持实际轮廓，差异单独记录，不能宣称生图精确遵守掩码。

`modules.json`为本批局部构图和插槽的编辑源；导图、原生生图、预览压缩图及完整提示各自可追溯。最终采矿切口、正式碰撞和共边资产须在获批接入时按同一形状合同另制，不以视觉图替代。

旧窄洞与大地图方案保持；不改Game、YYGC、依赖、存档或原玩法卡。不执行Unity编译、测试、Play或Player。本批只做独立玩点效果及连接候选规范，CL阶段继续。
