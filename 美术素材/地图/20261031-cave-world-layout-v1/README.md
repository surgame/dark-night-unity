## 整体路线

主线为：01凹谷洞口 → 02浅层岔道 → 03窄洞主段 → 04中部矿厅 → 06断层折返 → 07深部厚矿。中段之后往左下折返，再沿下层向右深入，使上下洞段之间保留完整岩体，形成同一侧视平面里的多层空间。

两条支线分别从02通往08浅层盲端、从04通往05侧向矿窝；均为盲端，沿原路回到主线。较高的05也可能有较高潜在收益，深度以沿路距离与进入难度表达，不以绝对Y坐标定价。近端小矿、窄洞露头、矿厅选择及远端厚矿承担不同探索用途，没有将奖励数值、路线时长或巢穴概率定案。

| 分区 | 规划作用 |
| --- | --- |
| 01凹谷洞口 | 单一自然入口与原路返回参照，地表仅交代灰松谷环境 |
| 02浅层岔道 | 第一处分路，选择短途试采或沿主线深入 |
| 03窄洞主段 | 延用当前已认可的低顶厚岩风格，窄道模块承担主要行进节奏 |

| 07深部厚矿 | 主线远端目标，围岩内的潜在矿体规模未知 |
| 08浅层盲端 | 靠近入口的短途小额收益选择 |

## 预制模块与随机性

本图提供一个骨架模板，先约定分区用途、连接关系及内容预算，再用窄廊、岔口、折返、矿厅、矿窝和盲端等作者大模块承载局部构图。后续可在允许的槽位以端口和邻接约束选择模块变体，同时变化弯折、轮廓和内容锚点；宏观节奏约束应先于局部WFC求解。

开发端生成候选、人工修整和审核，最后冻结成完整预制地图；运行采掘不重跑WFC、不重排模块或矿物。本轮没有新增全图WFC求解器，也没有将这张生图自动转成可玩地图或更新现有一维样板。

前景可挖岩体、稳定后壁、独立矿层及交互插槽保持分工。矿体剖面线是策划透视标记，实机由露头和逐步挖开揭露；不能把图中的完整矿体轮廓直接画进游戏后壁。青色空环只表示物体制作插槽，未新增道具Definition或业务对象；巢位也只是候选，不指定触发、强制生物或伤害。
