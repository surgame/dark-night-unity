## 装配与交互

六种构图各有普通与水平镜像两个登记朝向，共12候选。WFC对16个槽位执行带权最小熵选择、邻接排除与有界回退；A为常规端口，B为低口端口，两端限定A，禁止相同朝向直接相邻。模块按端点刚性平移，不循环填岩或扭曲路面。默认309展示全部六种来源和低口传播，不代表随机分布验收。

绘制顺序：稳定后壁 → 独立矿格 → 前景遮挡 → 角色／工具／光照。原图中空气区域的烘焙矿斑不进入新合成。WFC只提供初始模块与锚点，矿物用独立随机流落位；开挖不重跑WFC、不移动模块、不重抽矿、不重绘后壁。

- A/D或方向键移动，空格跳跃；触屏方向按钮可按住。
- J、采掘按钮或点击附近目标发起采掘。有围岩时先命中围岩，一次落镐不继续结算后一层。
- 图层选择可独立查看后壁、矿层、前景；单看矿层属于制作调试，不改变采掘的距离和遮挡校验。
- 模块素材／WFC过程分别查看分层构图和真实候选排除。

样板用16像素格保存稀疏编辑及独立矿格，原生轮廓与编辑格共同决定显示和近似碰撞。采掘示例使用Reach 64、Damage 10、动作0.48秒、命中比例0.6，来源为现行工具文档；格耐久20与采空计数仅用于演示，不是正式矿床平衡或货袋收益。落镐冻结目标，命中时再检查距离、遮挡与耐久；目标变化则取消，不自动改打后一层。

## 正式设计一致性

正式前景和矿层分别进入SessionTerrain托管的原生ARDMap。矿层拥有矿种、耐久、储量及采空状态，不创建逐格／逐矿床业务对象；背景沿冻结参考提供完整覆盖。可交互道具、巢穴或机关使用独立美术、锚点和现有Definition／对象／所属Behaviour状态，不能画死在后壁里；视觉排序在人物后方不代表没有交互身份。

当前只用矿层验证交互，未新增道具、机关、定义或经济。浏览器没有正式ARDMap、YYGC、库存、容量、奖励、联机或世界存档；样板状态不进入正式Game，不成为第二套正式权威世界。

## 验证与限制

当前输入见 `manifest.json`，移动／触屏见 `verification.json`，分层／采掘见 `layer-verification.json`；评审图和失败回执在 `review-v2/`，六张透明前景的尺寸、字节和SHA-256见分层回执。

已核对前景alpha排除烘焙矿斑、命中顺序、一次落镐不同时伤害后矿、矿格采空、后壁RGBA指纹不变、超距拒绝、真实J与原生触屏采掘、状态恢复及窄屏图层切换。分层场景处理3个已采空矿格和2个围岩格，仅是独立样板的结果。

初次检查的遮挡假设不完整：已露矿会先截住指向后方的射线；斜面同一格局部露出不能仅用中心点判断整格埋藏。现按完整遮挡及先处理露矿、再挖围岩、再采后矿的顺序核对；失败报告保留，未重生成旧冻结证据。

剩余问题：主要轮廓掩码尚未精修细小悬岩／碎石／透明边缘；格级切口没有完整厚断面／凹凸角素材；盖片重复与后壁接缝仍明显。当前是一维洞道，B端口仅一对镜像来源，无二维分支。角色为静态参考图加运动，光照为局部射线示意，不是正式Spine、法线或返光后端。

本片不替换正式生成器，不修改Game／YYGC／依赖／玩家存档，不运行Unity编译、测试、Play或Player。正式接入、采掘手感、美术接受和多人一致性仍需独立实施与验收。
