# 固定美术大模块 WFC 漫游样板

本目录是独立浏览器美术实验，保留旧版 `../20261030-flat-cave-kit/` 连续材质方案。目标是检查固定绘制的厚岩体、低顶通道、坡段和近后壁，经过模块规则组合后是否更接近用户参考图。当前为一维横向洞道，不是正式关卡或 Unity 接入。

## 当前实现

- 内置生图制作一张六模块源图，实际1254×1254；每张原生裁片623×414。生成的原始字节保留，完整提示见 `generation-prompt.json`。
- 六种构图各有普通与水平镜像两个登记朝向，共12个候选。镜像没有独立绘制；不使用上下翻转或任意旋转。
- WFC 对16个槽位执行带权最小熵选择、相邻候选排除和有界回退。端口A为常规接口，B为低口接口；两端限定A，并禁止完全相同朝向模块直接相邻。
- 低口上坡的A→B接口会迫使右邻居选用B→A候选。这个小目录的B接口只有一对镜像来源，选择空间有限，不能代表丰富分支系统。
- 模块按照地面端点做刚性平移，水平镜像同步反射几何；岩面和路面均不循环采样、不沿曲线扭曲。固定岩块裁片覆盖部分接缝，上下深部岩体渐入同色暗部。
- 键盘A/D或方向键移动，空格跳跃；触屏方向按钮支持按住，跳跃按钮触发起跳。镜头跟随，手电是浏览器局部射线遮挡示意。
- “模块素材”查看六张来源，“WFC过程”查看真实选择与候选收缩事件；“模块边界与碰撞”展示槽位边界及样板使用的碰撞轮廓。

默认展示种子309，包含六种来源构图与低口传播，便于人工比较。该选择不代表随机分布或正式内容验收。

## 来源与精度

`make-guide.cjs` 及 `modules.json` 生成严格布局导图，但模型没有保留要求的尺寸、边缘和轮廓。因此不能把该图集视为满足共边合同的正式资源。本片按实际裁片在 `art-profiles.json` 中重新描地面与主要洞顶，沿端点匹配位置，再使用固定裁片过渡。轮廓是浏览器样板近似，不是逐像素碰撞，也不是游戏的整格／12坡形合同。

原人物通过已有 `../20261029-wfc-cave-kit/sources/hero-scale-reference.png` 只读复用，未重画原角色或Spine。当前是静态人物参考图加轻微运动表现，不是正式动画。

人物、手电光罩及碰撞仅用于体验这个样板；不恢复正式喷气、梯具、经济或采掘状态。矿斑仍是源图里的固定绘制，没有矿层、储量或收益。

## 检查与限制

当次结果见 `verification.json`，源图和当前装配源码身份见 `manifest.json`，人工评审画面与失败回执保存在 `review/`。脚本检查覆盖规则、重现性、键盘与触控输入、起跳落地、跨接缝、镜头、换种子、状态恢复和三种视图的窄屏布局；不是Unity运行／碰撞或正式角色通行验收。

仍需评审：

- 接缝处岩块尺度和后壁裂缝会发生变化；固定盖片有重复，边缘尚未达到正式制作精度。
- 一维目录和A/B两个接口类型限制了结构复杂度，尚无真正二维分支、竖井或多槽房间。
- 当前前景和后壁在源图中没有分离，没有实现动态开挖、新切口、矿层与保存恢复。
- 光罩没有法线／真实返光，资产固有明暗也尚未分离为正式受光贴图。

后续先制作一组精确匹配接口、分离前景与后壁的作者模块，以及同风格挖掘切口，再决定扩充库或接入Unity。当前不替换正式生成器，不修改Game／YYGC／依赖／存档，不运行Unity、Play或Player。
