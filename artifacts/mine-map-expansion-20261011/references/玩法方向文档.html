Dark Nights｜矿洞探索与怪物生态：玩法方向文档

版本：v0.1 · 2026-10-10
定位：玩法方向草案，供原型验证；不是最终策划案或技术实施规范。
适用范围：以 2–4 人合作为重点，保留单人可完成主流程的可能性。

01｜方向结论

核心主张：让矿洞成为游戏主角。 玩家因未知而进入矿洞，凭线索发现资源，用工具取得收获，在环境和怪物干扰下决定继续深入还是带矿撤退。怪物的职责是改变采矿与撤离决策，而非把游戏变为高频清怪或纯恐怖体验。

  • 乐趣排序：探索与发现 ＞ 开采与收获 ＞ 风险、意外及自然合作；不把比例视为硬性时间配额。
  • 怪物定位：少量、有鲜明行为、可预判且可反制；普通怪制造干扰，少数强敌改变路线与收益取舍。
  • 地图形态：半开放洞网、分层洞室、环路和隐藏矿室；独立矿物可采，指定岩层才能爆破，不回到任意自由挖空地形。
  • 范围收敛：当前不以基地建设、自由驾驶降落、船体 DIY、自动化流水线、职业分工或完整战斗系统为前置条件。

一句话体验目标： “我们沿着线索找到了意想不到的矿，差点没能把它带回来。”

02｜三级核心循环

尺度 玩家行为 必须提供的反馈
瞬时（10–60 秒） 观察异常 → 判断路径／工具 → 挖掘／采集 → 获得反馈或新线索 操作手感清晰；奖励可见；未知有进一步指向
单次远征（测试以约 12–15 分钟起步） 进入洞网 → 发现矿室 → 采矿／搬运 → 遭遇意外 → 判断继续或撤离 有可讲述的发现、有收益取舍、有撤收决定
跨远征 撤离 → 到交易地点出售／交付 → 购买装备 → 选择下次探索目标 新装备打开新的探索方式，不仅提高数字

边界：飞船当前只承担出发、撤收和装备准备的入口；是否必须前往另一颗星球交差、何时进行收益结算，作为独立经济设计问题留待确认，不应反向拖慢矿洞原型。

03｜矿洞的空间设计

采用“可信主路 + 2–3 条分支 + 少量可发现捷径”的半开放结构。玩家通常知道如何前进，却不能一眼看透所有资源和出口。

  1. 安全起步区：让基础装备玩家尽快发现第一笔矿与一条明显通路，不把开局做成迷路测试。
  2. 差异化岔路：显眼但普通的矿、伴有危险迹象的富矿线索、暂时够不着的空间，分别提供安全与收益取舍。
  3. 可推断的隐藏洞室：墙面晶脉、裂缝漏光、回声、岩粉等线索与真实隐藏内容绑定，不能主要靠盲猜。
  4. 有限地形改造：爆破特定阻挡物以进入隐藏洞室或打通近路；普通地形保留预设轮廓。开采作用于独立矿物对象。
  5. 回程不应全是重走：通路尽量形成环、可解锁捷径；已清理区域原则上不无限刷敌，让团队感受到路线被经营过。

生成原则：先布局目的地、风险和主通路，再生成对应线索与地形伪装。随机性改变发现过程，不应让关键路线不可达，也不应让隐蔽线索成为随机装饰。

04｜矿物与开采设计

类型 主要体验 设计约束
散矿 低门槛的即时收获；保证持续正反馈 拾取快，不造成频繁搬运劳动
矿脉矿簇 顺着痕迹追踪矿床；发现本身有成就感 线索指向真实矿物，开采反馈明确
隐藏富矿室 一次明显的“赚到了”时刻 有发现成本，可安全也可危险；不是每次必刷强怪
少量大型贵重矿 收益与携带负担之间的选择 允许丢弃和之后追回；不能让所有矿都变成拖运任务

可以尝试常规开采／快速开采：后者更快但更响，只有附近存在感震生物时才构成额外风险。噪音是可理解的局部事件，不是无条件召唤怪物的全局进度条。

奖励分布可向可发现的集中矿藏倾斜，散矿仍承担起步与沿途回报；具体价值比例应由试玩数据决定，暂不锁定。

05｜怪物设计原则与组合

怪物应当做什么

让玩家改变计划，而非只是扣血。 每一种怪物至少回答一个问题：它因什么出现？玩家如何提前察觉？有哪些非战斗反制？失败损失什么？威胁何时结束？

采用四条约束：有前兆、可反制、有活动边界、结果可恢复。可用视觉动作与声音双重提示危险，避免只靠惊吓和暗处突袭。

生物（工作名） 行为触发与前兆 玩家选择 承担的玩法作用
偷矿兽（弱） 被掉落的发光矿物吸引；靠近时有轻快动作与叫声 追赶、拦截、诱饵；矿物可追回 低压力骚扰、多人趣事
岩鸣虫（中） 附近持续开采／爆破造成震动；先有敲击、岩壁颤动 停工、转移、引开、击退 影响“挖还是走”的决定
晶巢守卫（强） 靠近富矿巢穴并突破警戒；有可见领地迹象 绕行、声东击西、协作、正面应对 富矿的风险／回报取舍
深层巡猎者（稀有，后续） 出现在高风险深层路线；远处有持续可识别的脚步／轮廓 提前开路、躲避、舍弃重物、撤退 少量高记忆点的撤离高潮

数量与威胁节奏（仅供第一轮调参）

  • 约 15 分钟远征：尝试安排 2–4 次有意义的危险遭遇，而非持续交战；这不是强制刷怪指标。
  • 同区域活跃普通敌人通常 1–3 只；强敌 0–1 只，更多与可选的高价值区域绑定。
  • 怪物主要由巢穴、领地、噪声和探索位置触发；不因时间流逝无限刷怪。
  • 普通怪侧重干扰、掉落或短暂受伤；强敌允许迫使撤退，但必须提供读得懂的攻击前摇和逃生窗口。
  • 战斗是解决方案之一，但不应成为每次采矿前的必做清场任务。恐惧是调味，不是游戏承诺。

注意：不是每个富矿室都有敌人。安全获得一笔意外之财，同样应是玩家会期待的事件。

06｜环境、合作和装备成长

环境优先于怪物堆量。 利用深坑、竖井、裂岩、狭窄通道、声源传播、特殊矿石影响等简单规则产生变化；不优先增加氧气、燃料、散热等长期维护负担。以后可用“每颗星球一种环境规则 + 一类代表性生物 + 一种特殊矿物”构建差异。

合作自然出现：队友标记线索、提供照明、引走守卫、互相营救、协助搬运。避免职业锁定或必须多人同时触发的门槛；单人可完成基本目标，多人提升效率、减少风险并制造意外。

升级重点是能力解锁，而不是单纯增加采矿百分比：

装备方向 带来的新选择
简易探测器 更容易判断隐蔽矿脉方向，但不直接透视全地图
绳索／抓钩 穿越竖井、返回深坑，可能连接新的路线
改良采矿工具 开采更坚硬的独立矿物，获得更大开采效率
特种炸药 处理明确标识的可爆破障碍，开辟支路和捷径
搬运辅助 让少量大型矿物从“难以带走”变成“值得规划运输”

07｜原型范围与验证顺序

P0：证明“找矿 → 挖矿 → 遇到干扰 → 带回去”有趣

用 3–4 个联通洞室、2 类矿物、1 类可信线索、1 种对开采有反应的怪物、1 条可爆破捷径、1 项能力升级，做出完整的最小循环。先不追求丰富素材和多星球内容。

通过信号：玩家知道为什么找到矿；至少有一次主动选择路线或开采策略；遭遇怪物后能通过行动挽回局面；返回时感受到收获，而非纯粹赶路。

P1：验证小队合作与重复可玩性

扩展到 6–8 个洞室、3 类矿、3 种怪物行为、2 类线索、少量大型矿与可选高风险分支，重点测试 2 人和 4 人小队，以及单人兜底体验。

P2：待 P1 成立后再考虑

稀有大型威胁、更多星球生态、复杂地形互动、运输工具和更丰富的装备链。不要以这些系统掩盖 P0 的薄弱环节。

试玩记录什么

观察项 要回答的问题
首次有价值发现所需时间 前几分钟是否已经出现好奇和回报？
线索被发现及正确理解的比例 玩家是观察推理，还是盲目试错？
一局中的真实取舍 有几次自行决定绕路、冒险、丢矿或撤离？
遭遇后的行为 玩家会因怪物改变策略，还是只想尽快把它清除？
空转时间 是否有大量迷路、来回搬运、等队友、无效战斗？
复盘故事 玩家会说“发现了什么、怎么带回来的”，还是只记得怪物数量？

评估方式：记录行为录像、事件日志和一次简短复盘；不要只看问卷评分。遭遇次数与时长都是试验假设，不应过早变成固定 KPI。

08｜风险、边界及待决策事项

可能跑偏的方向 应对原则
怪物频率过高，采矿不断被打断 保留稳定安全区，让危险局部化、可读、可控制
地质线索太模糊，寻找变成猜墙 先生成奖励，再生成可靠线索；小范围试玩验证阅读率
搬运比发现矿石还费时 普通矿自动／快速拾取，大矿只作为少量特殊事件
返程过远，重复路径形成体力劳动 预设环路、少量捷径、清理后相对稳定的返回通道
武器和战斗数值不断膨胀 把怪物做成环境问题，不把击杀作为默认目标
地图可随意挖穿，结构设计失效 独立矿物开采 + 指定岩层爆破，保留洞室拓扑

当前不决策：交差是否必须跨星球、失败后矿物与装备的损失规则、是否有全局时间压力、复杂怪物战斗、自动化开采、长期基地建设。

版本约束：本文件仅描述玩法方向。新地图和矿洞机制应作为可独立测试的实验方案推进，不直接覆盖或淘汰既有地图分支和素材。

最终判断

先把 “玩家看到了线索、找到了秘密、挖出了值钱的东西，并且在意外里把战利品带回去” 这一个体验打磨成立。等这个循环稳定有趣，再决定需要多少怪物、多少星球和多少外围系统。
